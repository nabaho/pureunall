## 어떻게 다시 재나

```
node tools/phone-audit/run.mjs        # 포털 앱 전부를 360·411px 에서, 로그인한 채, 지어낸 자료로
```

- 숫자는 «찾는 그물»이다. 0 이 목표가 아니라, 걸린 것을 갈무리(`tools/phone-audit/out/`)로 보고 사람이 판단한다.
