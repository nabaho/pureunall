# 에고라이트(ego lite) — 검토와 설치 (2026-10-21)

대표 지시: 「에고라이트 검토하고 설치해 줘. 그래서 활용할 수 있게 해 줘.」

---

## 0. 한 줄 결론

**PC 에 까는 «AI 가 같이 쓰는 크롬»이다.** 푸른통합시스템(웹앱)이나 이 원격 상자(리눅스)에는 들어가지 않고,
**Claude Code 가 도는 윈도·맥 PC** 에 깔아야 쓴다. 쓸 만하다 — 다만 **로그인을 통째로 옮기지 말고**,
공개 자료 «읽기»부터 쓴다. 그 까닭이 아래 3절이다.

---

## 1. 무엇인가

| 항목 | 확인한 것 (2026-10-21) |
|---|---|
| 정체 | 크로미움(크롬과 같은 바탕) 브라우저. AI 에이전트(Claude Code·Codex·Cursor)가 **사람이 로그인해 둔 그 브라우저**를 직접 조작한다 |
| 핵심 | 에이전트마다 따로 «Space»(작업 칸)를 받아, 사람이 보던 탭을 뺏지 않고 뒤에서 일한다 |
| 연결 | 앱을 깔면 `ego-browser` 명령과 같은 이름의 **스킬**이 PC 의 모든 에이전트 스킬 폴더에 저절로 들어간다. Claude Code 에서 `/ego-browser 할 일` 로 부른다 |
| 운영체제 | **윈도 x64 · 맥(애플실리콘·인텔)**. 리눅스는 «로드맵»뿐 |

| 공개 범위 | 스킬·연결 도구(`ego-browser`) 소스는 MIT 로 공개. **브라우저 앱 자체는 소스 비공개 «별도 무료 내려받기»** |
| 만든 곳 | CITRO LABS PTE. LIMITED (싱가포르) |
| 저장소 | github.com/citrolabs/ego-lite — 별 약 1.8만, 마지막 커밋 2026-10-19, 스킬 판 2.1.0 |
| 빠르다는 말 | 「47~63% 빠르다」「2.5배」는 **만든 쪽이 잰 수치**다. 독립 검증은 못 찾았다 |

## 2. 푸른통합시스템에 «들어가나»

- **안 들어간다.** 푸른통합시스템은 브라우저에서 여는 웹앱이고, 에고라이트는 그 웹앱을 «여는» 쪽(브라우저)이다.
  폰에서도 안 돈다.
- **이 원격 상자(클라우드 Claude)에도 못 깐다** — 리눅스 미지원, 화면도 없다.
- 그래서 «설치»는 **대표님 PC(윈도)** 에서 사람이 한 번 해야 한다. 원격에서 대신 깔 길은 없다
  (2026-10-21 이 방에서 대표님 PC 의 Claude 세션이 잡히지 않았다).

## 3. ⚠ 검토에서 걸린 것 — 이 집은 주민번호·계좌·급여가 있는 집이다

1. **로그인을 통째로 AI 손에 준다.** 첫 실행 때 「크롬 자료 옮기기」에 «예» 하면
   로그인·쿠키·확장 프로그램이 전부 넘어오고, 에이전트는 그 로그인으로 움직인다.
   대표님 크롬에는 **푸른통합시스템 대표 계정**(모든 고객사의 주민번호·계좌·급여)·메일·은행·홈택스가 있다.
   웹페이지 속에 숨겨 둔 지시문 하나에 AI 가 넘어가면 그 로그인으로 무엇이든 할 수 있다.
2. **만든 쪽 처리방침이 홈페이지 말과 다르다.**
   - 홈페이지: 「설치 때 기록하는 것은 크롬 옮기기 여부 하나뿐」「방문 기록·쿠키는 PC 에만」.
   - 처리방침(2026-09-07 판): **사용 분석이 사용자·기기 식별자와 함께 서버로 간다**, 오류 보고는 **기본으로 켜져 있다**(끌 수 있다),
     주소창 입력은 구글로 갈 수 있다.
   - 같은 방침의 미국(CCPA) 부록 원문: 「We have also "sold" and "shared" device information, browsing and usage data,
     and purchase history to advertising networks and advertising partners」 — 그런데 본문은 「맞춤 광고에 안 쓴다」고 한다.
     이 «browsing and usage data» 가 자기 누리집 방문만인지 브라우저 앱까지인지 방침이 갈라 말하지 않는다.
   - **앱 소스가 닫혀 있어** 「방문 기록·쿠키는 안 올린다」는 말을 우리가 확인할 길이 없다.
3. **웹페이지 내용은 AI 회사로 간다.** 에이전트가 읽은 화면은 Claude(앤트로픽) 등 그 AI 회사로 넘어간다 —
   이건 에고라이트 탓이 아니라 AI 에 일을 시키는 모든 길이 같다. 고객 개인정보가 뜬 화면을 읽히지 않는 것이 기본이다.
4. **되돌릴 수 없는 명령이 있다.** 스킬 문서 스스로 「쿠키 지우기 세 가지는 **프로필 전체**를 지우고 되돌릴 수 없다」고 경고한다
   (그 자리에서 실측한 프로필에 쿠키 3,478개·1,161곳). AI 가 한 사이트만 로그아웃하려다 전부 날릴 수 있다.

→ 위 넷 때문에 **아래 4절의 방식으로만** 깔기를 권한다. 고객 자료가 이 브라우저에 들어가도 되는지는 [담당 노무사 최종 검토].

## 4. 설치 — 대표님 PC(윈도)에서 한 번

### 한 번에 (2026-10-21 「내 컴퓨터에 설치해서 다 전부까지」)

PC 의 pureunall 폴더에서 **`tools\ego-lite\install-ego-lite.bat` 를 두 번 누른다.**
받기 → 서명 확인(Citro Labs 가 아니거나 깨졌으면 멈춤) → 설치 프로그램 열기 → 온보딩이 끝나기를 기다림 →
`ego-browser ready` 확인 → Claude Code 스킬 확인까지 저절로 한다. 사람이 누르는 것은 둘뿐이다:
「PC 보호」 창의 «추가 정보 → 실행», 그리고 온보딩 화면(크롬 자료 «아니요» 권장).

- PC 의 Claude Code 에게 「에고라이트 설치해 줘」 해도 이 파일을 돌린다(`CLAUDE.md` 「에고라이트」 절).
- 아직 PC 에 이 파일이 없으면 먼저 `git pull`.
- ⚠ 클라우드 방에서는 대표 PC 에 손이 닿지 않는다 — 폰에서 맡기려면 PC 의 pureunall 폴더에서
  `claude remote-control` 을 켜 두면 Claude 앱에서 그 PC 세션으로 시킬 수 있다.
- ⚠ 이 스크립트는 리눅스 클라우드 상자에서 **돌려 보지 못했다**(PowerShell·윈도가 없다). 처음 한 번은 화면을 보며 돌린다.

### 손으로 하면

1. **lite.ego.app** 에서 윈도용 설치 파일을 받는다(공식 주소만. 다른 곳에서 받은 파일은 쓰지 않는다).
2. 실행. 윈도가 「PC 보호」 창을 띄우면 «추가 정보 → 실행»(만든 쪽 안내 그대로다).
3. 첫 화면 「크롬 자료를 옮길까요?」 → ⚠ **«아니요»를 권한다.** (3절 1번)
   필요한 사이트만 에고라이트 안에서 **하나씩 따로** 로그인한다.
   ⚠ 은행·홈택스·4대보험 EDI·푸른통합시스템 대표 계정은 **에고라이트에 로그인하지 않는다.**
4. 설정에서 «오류 보고»를 끈다(처리방침상 끌 수 있다). 사용 분석을 끄는 자리는 [확인 필요].
5. **새** 명령창(PowerShell)을 열고 확인한다 — 이미 열려 있던 창은 길(PATH)을 못 본다.
   ```powershell
   Get-Command ego-browser
   ego-browser nodejs -e "console.log('ego-browser ready')"
   ```
   `ego-browser ready` 가 찍히면 끝. Claude Code 를 새로 켜면 스킬이 보인다.
6. 되돌리기: 윈도 «앱 제거»에서 지운다. 스킬은 `%USERPROFILE%\.claude\skills\ego-browser` 에 들어간다 —
   남았으면 그 폴더도 지운다.

## 5. 쓰는 법 — Claude Code 에서

```
/ego-browser 고용24·기업마당에서 이번 달 고용 관련 지원사업 공고를 모아 표로 정리해 줘
/ego-browser 고용노동부 누리집에서 '연차휴가 사용촉진' 최근 행정해석을 찾아 목록만 뽑아 줘
/ego-browser 푸른 홈페이지 공개 화면을 열어 깨진 링크가 있는지 봐 줘
```

| ✓ 맡겨도 되는 것 (로그인 없는 «읽기») | ✗ 맡기지 않는 것 |
|---|---|
| 정부지원금·입찰 공고 모으기 | 은행·카드·홈택스·4대보험 EDI·고용24 기업회원 |
| 고용노동부 보도자료·행정해석, 노동위원회 판정례 찾아 목록 만들기 | 푸른통합시스템을 **로그인한 채** 저장·삭제·이관 |
| 공개 누리집 둘러보기·비교 | 고객 자료(주민번호·임금대장)를 웹 양식에 붙여 넣기 |
| 푸른 홈페이지 «공개» 화면 확인 | 메일 보내기·글 올리기·민원 제출·전자서명 |

- 법령 조문은 `korean-law` MCP 가 더 정확하다 — 에고라이트로 국가법령정보센터를 긁지 않는다.
- **푸른 앱 화면 점검은 에고라이트가 아니다** — `node tools/phone-audit/run.mjs <앱 key>`
  (가짜 파이어베이스로 그려 진짜 서버에 안 쓴다). 에고라이트는 대표님의 «진짜 로그인»을 쓴다.
- 로그인이 필요한 사이트를 맡길 때는 **그 일 하나만** 허락하고, AI 가 «보내기·저장·삭제» 단추 앞에서 멈추고 묻게 한다.
