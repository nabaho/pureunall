# 카톡 법인 업무채팅방 — 매주 하는 일 (한 장)

2026-10-24 · 푸른노무법인 업무채팅방 → 업무관리 «진행 기록»
설계서: `docs/superpowers/specs/2026-10-24-카톡-법인방-업무정리-design.md`

> **왜 매주인가** — 카톡은 방의 사진·파일을 **약 2주** 뒤에 지웁니다. 그 전에 받아 두어야 하고,
> 대화는 한 번에 내보내 올리면 사건번호·업체별로 업무관리에 정리됩니다.
> 카톡을 자동으로 읽어 오는 길은 없습니다(카카오가 막아 두었고, 프로그램으로 카톡을 조종하는 것은 약관 위반입니다).
> **사람이 내보낸 파일을 올리는 반자동**입니다.

## 누가 하나

| 일 | 누가 | 어디서 |
|---|---|---|
| ① 대화 내보내기 · ② 서랍 파일 받기 | 방에 있는 **누구나** (총괄관리자가 직접 하면 가장 간단합니다) | 그 사람의 PC 카톡 |
| ③ 올리기 → 미리보기 → 반영 → 파일 복사 | **총괄관리자만** | 업무관리 › 💬 카톡정리 › 「대화 내보내기 올리기」 |

다른 직원이 ①②를 했다면 **내보내기 .txt 와 받은 파일을 공유 폴더에 두고**, 총괄관리자가 ③에서 그 폴더를 고릅니다.
언제 할지(예: 매주 월요일 오전)와 당번 순서는 사무실에서 정합니다. [확인 필요]

## ① 대화 내보내기 (PC 카톡) — 1분

1. 「푸른노무법인 업무채팅방」을 엽니다.
2. 오른쪽 위 **≡(메뉴) → 대화 내용 → 대화 내보내기 → 텍스트만** 으로 저장합니다.
   [확인 필요 — 메뉴 이름은 카톡 판마다 조금 다릅니다]
3. 저장된 `.txt` 의 위치를 기억해 둡니다. **개인 대화방 파일은 올리지 마세요**(시스템이 «받을 방 목록»과 다르면 거절하지만, 처음부터 섞지 않습니다).

## ② 서랍에서 파일 받기 (PC 카톡) — 2분

1. 같은 방의 **≡ → 톡서랍 → 파일**.
2. 이번 주 올라온 파일을 모두 골라 **저장**합니다. 기본 위치는 `OneDrive\문서\카카오톡 받은 파일` 입니다.
3. **2주가 지나면 받을 수 없습니다.** 올리기 화면의 «카톡 만료 D-N» 이 빨강(D-3 이하·오늘 만료)이면 바로 받으세요.

> 받은 파일 폴더에는 **다른 방 파일도 섞여 있습니다.** 시스템은 대화 기록에 이름이 적힌 파일만 법인방 것으로 보고, 나머지는 건드리지 않습니다.

## ③ 올리기 (총괄관리자) — 5분

1. 업무관리 → **💬 카톡정리** → 위쪽 **「대화 내보내기 올리기」** 탭.
2. **📄 대화 내보내기 .txt 고르기**(또는 끌어 놓기). 이 PC 안에서만 읽습니다 — **«반영»을 누르기 전에는 서버로 아무것도 가지 않습니다.**
   - 「받을 방 목록에 없습니다」가 나오면 → 방 이름을 «알림» 탭의 ⚙ 받을 방과 글자 그대로 맞춥니다.
3. **미리보기 표**를 봅니다.
   - 🔵 **확실**: 사건번호가 업무관리 번호와 글자 그대로 같습니다 → 기본으로 체크됩니다.
   - 🟡 **짐작**: 업체명만 같거나 같은 번호가 업무 여럿 → **기본 해제**. 업무를 골라 직접 체크하세요.
   - **업무관리에 없는 번호**: 「새 업무 창 열기」로 채워 열고 저장은 직접 합니다(자동으로 만들지 않습니다).
   - **근거 없음(미분류)**: 반영하지 않습니다.
   - 「이미 있음」은 지난번에 반영한 것이라 건너뜁니다. 「보강」은 그날 글이 늘어 **새 줄**로 더해집니다(옛 줄은 그대로).
4. **「업무관리에 반영」** → 건수를 확인하고 누릅니다. 가린 원문(최근 30일 글)이 서버에 **30일** 보관되고, 진행 기록에 가린 발췌 한 줄이 더해집니다.
5. 아래 **첨부 파일** 칸에서 **📁 «카카오톡 받은 파일» 폴더 고르기** → 법인방 파일만 «✓ 찾음»으로 뜹니다.
   - 🔴 **민감 의심**(신분증·통장·진단서 같은 이름)은 기본 해제입니다. 확인 후 직접 체크하세요.
   - 🔴 **못 받음**은 톡서랍에서 아직 받지 않은 파일입니다.
6. **고른 파일 복사** → 보낼 폴더(내 PC 또는 공유 폴더)를 고르면 그 아래 `카톡파일/사건번호(또는 미분류)/` 로 **복사만** 합니다. 원본은 지우지 않고, 같은 이름이 있으면 건너뜁니다.

## 끝낸 뒤

- 내보내기 **.txt 는 지웁니다**(주민번호·의뢰인 정보가 든 평문 파일입니다). 시스템은 원본을 지우지 않습니다.
- 받은 파일 폴더의 파일을 정리(삭제)하는 것은 **사람이** 복사 결과를 확인한 뒤에 합니다.
- 컴퓨터에서 크롬·엣지가 아닌 브라우저는 폴더 고르기가 안 됩니다.

## 막힐 때

| 증상 | 까닭 · 할 일 |
|---|---|
| 「서버가 아직 새 기능을 모릅니다 / 원문 보관이 안 됐습니다」 | 서버 함수(`hanaMessageBridge`)가 아직 배포 전입니다 — 아무것도 저장되지 않았습니다. 관리자에게 알립니다. |
| 「방 이름을 찾지 못했습니다」 | 「텍스트만」으로 내보낸 `.txt` 가 아니거나 형식이 다릅니다. 앞 20줄(이름·내용은 가리고)을 개발 담당에게 보내 주세요. |
| 「못 읽은 줄 N개」 | 형식이 조금 다른 줄입니다. 반영 결과에는 영향이 없지만 알려 주세요. |
| 같은 줄이 두 번 | 일어나지 않습니다(같은 내용은 건너뜁니다). 내용이 달라지면 새 줄 «보강»으로만 더해집니다. |

## 부록 A. 직원 안내문 개정 초안 (2026-10-09 안내문의 «30일 뒤 삭제» 문구 갱신) — 초안

> **[초안 — 담당 노무사 최종 확인 후 사용]**
>
> 「푸른노무법인 업무채팅방」의 대화는 업무 진행 상황을 정리하기 위해 다음과 같이 처리됩니다.
> 1. 총괄관리자가 매주 대화 내용을 내보내 업무관리 시스템에서 읽습니다. 사건번호·업체명이 있는 대화는 해당 업무의 «진행 기록»에 한 줄(발췌)로 더해집니다.
> 2. 주민등록번호·카드번호·계좌번호처럼 보이는 숫자는 가려서 저장됩니다.
> 3. 대화 원문(가린 것)은 최근 30일치가 서버에 보관되며 총괄관리자만 볼 수 있고, 30일이 지나면 삭제됩니다.
> 4. 진행 기록은 업무관리의 다른 업무 기록과 같은 기준으로 보관되며, 업무관리를 쓰는 직원이 볼 수 있습니다.
> 5. 개인적인 이야기는 이 방에 올리지 말아 주세요. 사건번호·업체명을 글에 적어 주시면 업무에 정확히 연결됩니다.

## 부록 B. 담당 노무사 최종 확인 항목 (법률 검토는 이 문서가 하지 않습니다)

1. 방 참여자(11명)에게 **고지·동의**가 필요한가 — 개인정보 보호법상 수집·이용 근거와 고지 의무 [조문은 노무사가 확인].
2. 대화에 섞이는 **의뢰인·근로자 개인정보**(민감정보 가능)를 가려서 **30일** 서버에 두는 것이 적정한가.
3. **방에 직원이 아닌 사람**(퇴사자·외부인)이 있는가 — 있으면 «진행 기록을 재직 직원이 모두 본다»와 어긋납니다.
4. 부록 A 안내문의 문구와 시행 시기.
5. 사내 처리 기준 문서(`docs/사진-개인정보-보유기준.md` 꼴)에 «카톡 업무방» 항목을 둘지, 진행 기록(업무 기록)의 보유·파기 기준.
