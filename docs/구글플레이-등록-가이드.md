## 1단계. 업로드 서명키 생성 및 GitHub Secret 등록

> **중요 보안 원칙**: 서명키(`.jks`)와 비밀번호는 공개 저장소(`pureunall`) 안에 절대 넣지 않습니다. 반드시 저장소 바깥의 안전한 보관 폴더(예: 대표님 전용 백업 폴더)에 생성하세요.

1. JDK 17 이상이 설치된 PC에서 아래 명령으로 업로드 서명키를 생성합니다(또는 Android Studio의 **Build → Generate Signed App Bundle / APK**에서 새 키스토어를 만듭니다).
   ```bash
   node scripts/play-store-setup.js --init-keystore --out "C:\Users\user\Desktop\pureun-secrets\portal-upload.jks"
   ```
2. 출력된 4개 값을 GitHub 저장소(`nabaho/pureunall`) **Settings → Secrets and variables → Actions → New repository secret**에 등록합니다.
   - `PORTAL_UPLOAD_KEYSTORE_BASE64`: `portal-upload.jks` 파일을 Base64로 변환한 문자열
   - `PORTAL_UPLOAD_STORE_PASSWORD`: 키스토어 비밀번호
   - `PORTAL_UPLOAD_KEY_ALIAS`: `pureun-portal-upload`
   - `PORTAL_UPLOAD_KEY_PASSWORD`: 키 비밀번호
3. GitHub 저장소 **Actions → 푸른포털 Play 스토어 앱 빌드 (AAB·APK) → Run workflow**를 누르면:
   - Play Console에 바로 올릴 **`pureun-portal-playstore-aab` (`app-release.aab`)**
   - 휴대폰에서 미리 설치해 볼 **`pureun-portal-playstore-apk` (`app-release.apk`)**
   - 워크플로 요약 화면의 **업로드 키 SHA-256 인증서 지문**이 함께 출력됩니다.

## 2단계. 주소창 없는 전체화면 검증 (`assetlinks.json` 루트 배포)

현재 포털 주소는 `https://nabaho.github.io/pureunall/enter.html`이므로, Android 운영체제는 도메인 최상위 경로인 **`https://nabaho.github.io/.well-known/assetlinks.json`** 에서 앱 서명 지문을 확인합니다.

> **주의**: 업로드 키 SHA-256 지문뿐만 아니라, Play Console에 첫 `.aab`를 올린 뒤 **Play Console → 설정 → 앱 무결성(App integrity) → 앱 서명(Play App Signing) → 앱 서명 키 인증서**에 표시되는 **SHA-256 인증서 지문**까지 **두 개 모두** 쉼표로 넣어 주어야 스토어에서 내려받은 앱에서도 상단 주소창이 완전히 사라집니다.

1. 아래 명령으로 루트 저장소(`nabaho/nabaho.github.io`) 배포용 파일을 한 번에 생성합니다.
   ```bash
   node scripts/play-store-setup.js --write-root-site --out "C:\Users\user\Desktop\nabaho-root-site" --sha256 "업로드키_SHA256,플레이앱서명키_SHA256"
   ```
2. GitHub에서 **`nabaho.github.io`** 이름의 Public 저장소를 만들고 생성된 3개 파일(`.nojekyll`, `index.html`, `.well-known/assetlinks.json`)을 올리면 1~2분 뒤 `https://nabaho.github.io/.well-known/assetlinks.json`이 활성화됩니다.
3. 향후 `erp.pureun.kr` 등 자체 도메인을 연결할 때를 대비해 본 저장소에도 `.well-known/assetlinks.json`과 `.nojekyll`이 함께 준비되어 있습니다.

## 3단계. Firebase Auth에 심사관 테스트 계정 만들기 (1회)

Google Play 심사관이 로그인 화면 뒤의 실제 기능을 점검하되, **의뢰인 사건 정보·임금 자료·구성원 명부에는 절대 접근할 수 없도록** 전용 격리 계정을 만듭니다.

1. [Firebase Console (`pureun-erp`)](https://console.firebase.google.com/project/pureun-erp/authentication/users) → **Authentication → Users → 사용자 추가(Add user)** 클릭
2. 아래 이메일과 강력한 임시 비밀번호(영문 대·소문자+숫자+특수문자 12자 이상)를 입력해 추가합니다.
   - **이메일**: `playreviewer@pureun.kr`
   - **비밀번호**: `(직접 지정한 심사 전용 비밀번호 — Play Console에만 입력하고 코드에는 적지 않음)`
3. **절대 하지 말아야 할 것**:
   - 이 계정의 UID를 Realtime Database `uid_roles`나 `data/user_dir`, `data/user_accounts`에 **추가하지 마세요.**
   - `uid_roles`에 없기 때문에 Firebase 서버 보안 규칙이 모든 고객·인사 DB 읽기를 서버 단에서 100% 차단하며, 포털(`enter.html`)은 `playreviewer@pureun.kr`을 자동으로 인식해 에러 배너나 `준비중` 타일 없이 **한글 편집기**와 **공공임단협(1,693개 공공기관 노사 데이터 비교 분석)** 화면을 깔끔하게 열어 줍니다.

## 6단계. 출시 방식 선택 팁 (일반 공개 vs 사내 전용)

1. **누구나 Play 스토어에서 「푸른포털」을 검색해 내려받기 (일반 프로덕션 출시)**
   - **조직(법인) 개발자 계정**(사업자등록번호·D-U-N-S 번호 인증)으로 개설하면 개인 계정과 달리 **「테스터 12명 · 14일 비공개 테스트」 의무 없이** 바로 프로덕션 심사를 신청할 수 있습니다.
   - 만약 **개인 개발자 계정**(2023년 11월 이후 신규 개설)이라면 Google 정책상 프로덕션 신청 전에 비공개 테스트 트랙에서 사내 직원 등 **12명 이상이 14일 연속 설치 유지**해야 프로덕션 버튼이 열립니다.
2. **푸른노무법인 임직원에게만 비공개 배포 (Managed Google Play 비공개 앱)**
   - 외부 일반인 검색 노출 없이 사내 구성원 Play 스토어에서만 내려받게 하려면 Play Console의 **고급 설정 → 관리 Google Play(Managed Google Play)** 를 켜면 별도 공개 심사 지연 없이 수십 분 내에 사내 배포도 가능합니다.
