# 홈페이지 «직원 소개» 정리 — 왜 지금 안 보이나, 어떻게 고칠 수 있게 만드나

작성 2026-10-31 · 대표 물음 「직원에 대한 내용은 없나 왜? 직원 내용도 수정 가능하게 하고
추후에 직원 얼굴과 경력도 넣을 수 있게 만들 것이다. 이 부분 별도로 정리해 달라」

> 이 문서는 정리만 한다. 만드는 일은 대표 결정 뒤에 «목업 → 승인 → 코딩» 순서로 한다.
> 직원 이름은 여기 적지 않는다(사무장·차장·과장·대리·주임 5명).

## 1. 결론

| | 노무사 7명 | 직원 5명 |
|---|---|---|
| 지금 홈페이지(손님이 보는 곳, 제작사 라이믹스) | 게시판 글 — 우리 화면에서 고치고 반영됨 | **제작사 레이아웃 코드에 글자로 박혀 있음** — 우리 화면·관리자 화면 어디서도 못 고침 |
| 새 사이트(우리가 만든 곳, 준비 중) | 우리 자료로 다시 그림 · 매달 퇴사자 자동 빼기(#2833) | 쪽 안에 글자로 들어 있음 — **우리 것이라 고칠 수 있게 만들 수 있다** |

- 화면 «직원» 탭에 「일반직원 (사무장·사무직) — 쪽에 박힌 글자 · 기준 없음」 한 줄만 보이는 까닭이 이것이다.
  사람마다 고칠 «칸»이 아예 없다.
- **지금 홈페이지**는 우리가 직접 못 고친다. 레이아웃 코드는 서버가 쓰지 않기로 정했다
  (한 번 잘못 쓰면 홈페이지 전체 모양이 깨진다). 길은 둘뿐이다:
  ① 제작사에 «직원도 노무사처럼 게시판 글로 바꿔 달라» 부탁(요청서 초안에 이미 넣어 둠, 발송은 대표)
  ② 유지보수 기간이 끝난 뒤 호스팅·FTP 를 넘겨받아 우리가 직접.
- **새 사이트**는 바로 만들 수 있다. 도메인을 새 사이트로 옮기면 손님도 그것을 보게 된다.

## 2. 확인한 사실 (2026-10-31)

- 지금 홈페이지 관리자 화면 15곳을 정찰했다 — 직원 이름이 나오는 곳 0곳. 레이아웃 코드 화면은 403(제작사만).
  → 이름은 제작사 레이아웃 파일 안의 글자다(`people_box › text1/text2`). 4차 정찰, 2026-10-11.
- 새 사이트 구성원 쪽(`site/people/index.html`)에도 같은 5명이 같은 모양으로 들어 있다 —
  한 사람 = 이름(text1) + 직급(text2) 두 칸. **사진·경력 자리는 없다.**
- 노무사 카드는 사진·직책·경력이 있고, 우리 부품(`js/pu-site-people.js`)이 «첫 카드를 본으로 찍어 내는» 방식으로 그린다.
  직원 칸은 이 부품이 지금 건드리지 않는다.

## 3. 새 사이트에서 직원을 고칠 수 있게 — 단계 제안

### 1단계 · 이름·직급 고치기 + 퇴사 자동 빼기 (사진·경력 없이)
- 직원 5명을 우리 자료(`homepage/members`, 구분 = 직원)에 한 사람씩 넣는다.
  **직원 번호(sid)로 푸른ERP 직원과 잇는다** — 이름으로 잇지 않는다(온톨로지 규칙).
- 화면 «직원» 탭에서 노무사처럼 한 사람씩 고친다: 이름 · 직급 · 차례 · 안 올림.
- 「새 사이트에 올리기」와 매달 자동 올리기가 직원 칸(`people_box`)도 다시 그린다.
  퇴사자는 노무사와 같은 규칙으로 저절로 빠진다(#2833 지킴이와 같은 잣대 — 3명 넘게 한꺼번에 빠지면 멈춤).
- 새 사이트 모양은 그대로다(지금 두 칸 그대로 찍어 낸다).

### 2단계 · 얼굴 사진·경력 넣기
- 지금 직원 칸에는 사진·경력 자리가 없다 → **새 카드 모양**이 필요하다. 목업을 먼저 보여 드린다.
  (노무사 카드처럼 눌러서 경력을 펼치는 꼴, 또는 사진+이름+직급만 작게 — 고르실 것)
- 사진은 창고(Storage)에 둔다 — 노무사 사진과 같은 길.
- ⚠ **직원 얼굴·경력은 개인정보다 — 본인 동의를 받은 사람만 올린다.**
  동의 받은 날을 자료에 남기고, 동의가 없으면 사진·경력 없이 이름·직급만 나가게 만든다
  (자문사 로고의 «공개 동의» 와 같은 장치). 동의서 양식·보관 방법 [확인 필요 — 담당 노무사 검토].
- 퇴사하면 사진·경력도 함께 내려간다.

### 3단계 · 손님에게 보이기
- 도메인(fairrunlabor.com)을 새 사이트로 옮기는 날부터 손님이 본다. 그 전까지는 «준비 중» 사이트에서만 보인다.
- 지금 홈페이지에도 같은 것을 원하면 1절의 ①·② 중 하나가 필요하다.

## 4. 대표 결정이 필요한 것

1. 1단계(새 사이트 직원 이름·직급 고치기 + 퇴사 자동 빼기)를 지금 만들까 — 목업부터.
2. 2단계 사진·경력: 넣을 직원 범위(전원 / 동의한 사람만), 카드 모양(목업에서 고름).
3. 동의 받는 방법 — 종이 동의서 / 푸른ERP 에서 본인이 누름 [확인 필요].
4. 지금 홈페이지: 제작사 요청서 발송 여부(직원 게시판화 포함) — 제작사 확인 후 대표가 보낸다.
