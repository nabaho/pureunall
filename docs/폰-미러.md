# 폰 미러 — 진짜 폰 화면을 PC 에서 보며 UI 고치기

대표 지시 2026-10-24: 「내 컴퓨터에 폰을 미러링으로 연결하고 푸른 통합시스템 UI 고칠 수 있게 해 달라」

## 처음 한 번 (사람)

1. **PC** — 저장소 맨 위 `폰미러-켜기.bat` 을 두 번 누르고 **5** (scrcpy 깔기). winget 창이 뜬다. 다 깔리면 창을 닫는다.
2. **폰** — 설정 → 휴대전화 정보 → 소프트웨어 정보 → 「빌드번호」를 **일곱 번** 누른다 → 「개발자 모드를 켰습니다」.
3. **폰** — 설정 → 개발자 옵션 → **「USB 디버깅」 켬**.
4. USB 선으로 PC 에 꽂는다 → 폰에 「USB 디버깅을 허용할까요?」 → **«이 컴퓨터에서 항상 허용» 체크 → 허용**.
5. `폰미러-켜기.bat` → **4** (준비 점검) — `✓ 폰: …` 이 나오면 끝.

## 쓸 때

| 번호 | 하는 일 |
|---|---|
| 1 (기본) | 폰 화면이 PC 창에 뜬다. 마우스로 누르고 넘길 수 있다(사람이). |
| 2 | 지금 폰 화면을 그림으로 남긴다 → PC 의 Claude 가 그 그림을 읽는다. |
| 3 | 폰 **크롬**에 열린 푸른 화면을 잰다(옆넘침·세로깨짐·작은 단추 …) + 크롬 화면 그림. **읽기만** 한다. |
| 4 | 준비 점검 |
| 5 | scrcpy 깔기 |

PC 에서 연 Claude 방(또는 `폰연결-켜기.bat` 으로 연 방)에 이렇게 시키면 된다:
> 「폰 미러로 지금 화면 갈무리하고, 이상한 것 찾아서 고쳐라」

Claude 는 `node tools/phone-mirror.js --shot` · `--measure` 로 보고 재서, 코드를 고친 뒤
`node tools/phone-audit/run.mjs <앱> --font=1.4` 로 다시 재고 PR 을 만든다.

## 지키는 것

- 이 도구는 폰을 **누르지도 치지도 않는다.** 저장·삭제·보내기는 사람이 미러 창이나 폰에서 직접 한다.
- 재기는 **푸른 화면만**(nabaho.github.io/pureunall). 은행·메일 탭은 열어 보지 않는다.
- 갈무리는 `tools/phone-mirror/out/` 에만 — 고객 이름·금액이 찍히므로 저장소에 안 올라가고, 채팅·PR 에 붙이지 않는다.
- 클라우드(웹) 방에서는 폰이 안 닿는다. 대표 PC 에서 연 방에서 쓴다.
- 재기(3번)는 폰 **크롬**에서만 된다(삼성 인터넷은 안 된다). Node 22 이상이 필요하다.
