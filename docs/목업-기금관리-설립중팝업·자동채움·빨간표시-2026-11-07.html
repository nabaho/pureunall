메모 — 이렇게 동작합니다

1. 설립중 기금 화면 — 틀 고정 세 겹을 없애고 표 한 판 + 팝업. 팝업은 «지금 할 일» 띠, 12단계 체크(4묶음), 탭 셋. 팝업 안에서도 체크·서류 묶음 열기·기금 열기가 그대로 됩니다.
2. 자동 채움 — 기업정보(참여사·대표자·출연금 등)가 들어오거나 서류(사업자등록증·확인서 등)를 받아 값이 바뀌면, 그 기금의 서식이 저절로 새 값으로 다시 채워집니다. 지금은 사람이 서식 탭에서 열어야 채워지는데, 값이 바뀐 서식은 목록에서 «자동 채움 완료 · 🔴 N칸 확인»으로 바로 보입니다. 값이 모자라면 «자료 모자람»과 빈 칸 목록만 보여 줍니다.
3. 빨간 표시 — 마지막으로 사람이 확인한 값과 비교해, 새로 들어온 칸은 빨강, 바뀐 칸은 빨강 + «전 값»을 옆에 작게 보입니다. [확인] 한 번이면 그 서식의 빨강이 모두 검정으로 돌아갑니다(기금 확인함과 같은 기록).
4. 인쇄는 흑백 — 빨강은 화면 검토용입니다. 인쇄·PDF·한글 파일로 내보내는 글자는 전부 검정이고, 전 값 표시도 나가지 않습니다. 확인하지 않은 빨강 칸이 남아 있으면 인쇄 전에 «아직 확인 안 한 칸이 N곳 있습니다 — 그래도 인쇄?»라고 한 번 묻습니다(기존 인쇄 관문과 같은 자리).
5. 사람이 쓴 값은 기계가 못 덮습니다 — 기금 확인함의 기존 원칙 그대로입니다. 사람이 손으로 고친 칸은 자동 채움이 건드리지 않고, 새 자료와 다르면 빨강으로만 알려 줍니다.
