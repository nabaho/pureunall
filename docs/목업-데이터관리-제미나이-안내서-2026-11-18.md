## 1. 붙여 넣을 부탁 글 (그대로 복사)

```text
첨부한 HTML 은 노무법인 내부 프로그램 «데이터관리»(대표 한 사람만 보는 화면)의 목업이다.
숫자와 이름은 전부 지어낸 것이다. 이 목업의 «디자인»만 더 보기 좋고 읽기 쉽게 다시 만들어 줘.

[결과물]
- HTML 파일 «하나»로 줘. CSS 와 JavaScript 는 그 파일 안에 넣는다.
- 외부 라이브러리·CDN·웹 글꼴 링크(three.js, Chart.js, Google Fonts 등)를 쓰지 마라. 3D 와 그래프는 지금처럼 캔버스로 직접 그린다.
- 지금 있는 기능(탭 이동, 3D 돌리기·확대, 칩 거르기, 표로 보기, 현황판 거르기, 연결 지도 고르기·중심 보기·찾기, 채팅 보내기)은 하나도 빼지 마라.

[바꿔도 되는 것]
- 배치·여백·카드 모양·모서리·그림자·글자 크기와 굵기·아이콘(그림글자)
- 왼쪽 대시보드의 모양, 위쪽 막대의 모양
- 3D 막대·구슬·산맥·고리·건물의 모양과 조명, 연결 지도 점·선의 모양
- 움직임(애니메이션) — 단, 사용자가 «움직임 줄이기»를 켜면 멈추게 한다

[꼭 지킬 것]
1. 숫자·이름은 지금처럼 지어낸 것만 쓴다. 실제 사람·회사 이름을 넣지 않는다.
2. 색은 아래 목록 안에서만 고른다. 뜻: 초록 = 입금·정상, 노랑 = 주의, 빨강 = 위험·넘침. 빨강·노랑을 장식으로 쓰지 않는다.
   회색 #f8fafc #e2e8f0 #cbd5e1 #94a3b8 #64748b #475569 #1e293b / 파랑 #eff6ff #bfdbfe #60a5fa #2563eb #1e40af
   초록 #f0fdf4 #bbf7d0 #4ade80 #16a34a #166534 / 노랑 #fffbeb #fde68a #fbbf24 #d97706 #854d0e
   빨강 #fef2f2 #fecaca #f87171 #dc2626 #991b1b / 사람·종류 구분색 #1e3a8a #0e7490 #a21caf #c2410c #4d7c0f #be185d #5b21b6 / 흰색 #ffffff
3. 글자와 바탕의 대비는 4.5:1 이상으로 한다.
4. 표의 한 칸은 «한 줄»이다. 두 줄로 쌓지 않는다. 넘치면 «…»로 자르고 마우스를 올리면 전문(title)이 보이게 한다. 값이 없는 칸은 빈 줄을 그리지 않는다.
5. 사람 표처럼 고를 수 있는 목록은 맨 왼쪽에 ☐ 고르기 칸(약 28px), 그다음 번호 칸(약 36px)을 둔다. 번호는 «지금 보이는 순서»다.
6. 폰(화면 너비 600px 이하):
   - 375px 너비에서 가로로 밀리는 곳이 없어야 한다.
   - 입력칸 글자는 16px 이상이다. 확대(줌)를 막지 않는다.
   - 메뉴·탭은 한 줄로 둔다(옆으로 밀어 보기).
   - 넓은 표는 줄마다 두 줄짜리 카드로 바꾼다. ☐ 와 번호는 카드 왼쪽 끝에 그대로 둔다.
   - 양옆 여백은 8~14px, 상자는 한 겹만 쓴다.
7. 왼쪽 대시보드는 PC 에서 세로 메뉴, 태블릿(900px 이하)에서 그림 단추만, 폰에서 위쪽 한 줄 띠가 된다.
8. 3D·그래프마다 «표로 보기»를 남긴다. 탭은 키보드 화살표로 옮겨 가고, 단추·캔버스의 aria-label 은 그대로 둔다.
9. 화면에 글자를 넣을 때는 지금처럼 esc() 로 이스케이프한다. 바깥 값을 innerHTML 에 그대로 넣지 않는다.
10. id 와 data-* 이름(예: id="board", data-v, data-mk, data-open, data-gi, data-g)은 바꾸지 않는다. 스크립트가 그 이름으로 찾는다. 꼭 바꿔야 하면 스크립트도 함께 바꾼다.
11. 문구(낱말·설명)는 바꾸지 말고 모양만 바꾼다. 특히 잠금 화면의 «대표 전용 · 이 컴퓨터 · 질문마다 서명 · 15분 자리 비우면 잠김» 뜻은 그대로 둔다.
12. 표 안에 넣는 숫자칸(input)도 폰에서는 16px 이상이다. 표 제목 옆 배지는 폰에서 화면 밖으로 밀리지 않게 줄을 접는다.
13. 색칸(히트맵) 위 작은 숫자는 칸 색과 상관없이 4.5:1 을 넘기게 흰 글자에 짙은 테두리를 두른다.
14. 파일 고르기 단추를 <label> 로 만들면 tabindex="0"·role="button" 을 붙이고 Enter·Space 로도 열리게 한다. 창(모달)은 열면 «닫기»로 포커스를 옮기고, 닫으면 연 단추로 돌린다.
15. 숫자를 글자로 박지 않는다(예: «미수 10곳»). 같은 화면의 자료에서 세어 넣는다.
```
