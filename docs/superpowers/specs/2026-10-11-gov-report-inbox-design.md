# 컨설팅보고서 — 받은 서류함(메일 첨부 후보 · 서류 줄 연결 · 열어 보기) 설계

- 작성일: 2026-10-11 · 상위: `2026-10-10-gov-report-track-design.md`(서류 진행 기록) · `2026-10-11-gov-report-hwp-preview-design.md`(한글 미리보기)
- 대표 지시(2026-10-11 「남은 일 순서대로 진행」). 조사 결과(2026-10-11)로 정한 사실:
  - 푸른이알피 `pucards/coMail`·`pucards/sentDocs` 에는 **첨부 이름도 id도 없다** — 목록만 되고 다시 가져올 수 없다.
  - 첨부를 다시 가져오는 길은 **메일함 거울**(`mailbox/msgs/{slug}/{uid}` — `an`=첨부 이름 최대 5개, `a`=건수, `u`=uid, `s` 제목, `d` 날짜, `f/e` 보낸이)과 서버 함수 `readMailAttachment {slug,uid,part}`·`readOldMail {key,index}`(지난 메일)다.
  - 업체 귀속은 **이름이 아니라 메일 주소**로 한다(`js/pu-co-thread.js` `addrsOf`·`matchRow` — 업체관리 메일 주소 3칸·이알피 연락처). 동명 업체 오연결을 막는다.

## 1. 범위 (1차 — 작게)

한다
- **서류 칸 창(③ 서명본 · ④ 별첨 · ⑤ 제출)에 「📥 받은 서류 후보」** 목록을 더한다: 그 업체의 주소로 오간 메일 중 **첨부가 있는** 것(기간: 첫 회차 −30일 ~ 마지막 회차 +90일 — 보고서 창 `grpCollect` 와 같은 기간. 노무사 확인 사항)을 날짜 내림차순으로 보인다. 줄마다 보낸이(받은/보낸 구분)·날짜·제목·첨부 이름(거울의 `an`, 최대 5개)·종류 딱지(PRIV 해당 시 「개인 자료 · 목록에만」).
- **「연결」**: 후보 한 건을 지금 열려 있는 서류 줄(칸 창에서 고른 `key`)에 붙인다. `scal_docs/{co}/{rid}/items/{key}` 줄에 **`link`** 한 덩어리를 더 쓴다(§3). **사람이 눌러야만** 연결된다 — 자동 연결 없음. 연결한 사람·시각은 줄의 `by`·`at` 이 이미 남긴다.
- **「열어 보기」**: 연결된(또는 후보) 첨부를 **누를 때 한 건씩 순서대로** 서버에서 받아 앱 안에서 연다 — 한글(.hwp·.hwpx)은 한글 미리보기 창, PDF·이미지·표(xlsx)는 같은 방식의 간단 미리보기. 받은 바이트는 **어디에도 저장하지 않는다**(브라우저 메모리에서만, 닫으면 버림).
- 연결 해제: 칸 창에서 「연결 지우기」(`link` 만 지운다 — 서류 줄 상태는 그대로).

하지 않는다(다음 단계)
- 대시보드 왼쪽의 전역 「📥 받은 서류함」 목록(전 업체 모아 보기) — 이번에는 «칸 창 안»에서만.
- 첨부를 우리 저장소(Storage)에 복사해 보관 · 30일 삭제 안내 · 「반납 대상일 수 있음」 딱지(§13-①, 기술보호 — 협력재단 확인 대기).
- 이름 기반 후보(주소가 안 맞는 메일) 제안 — 주소 일치만.
- AI 가 첨부 내용을 읽어 분류하는 일(개인 자료를 AI 로 보내지 않는 원칙 — 설계서 §6-2-1).

## 2. 후보 만들기 (읽기만)

- 읽는 곳: `pucards/mailbox/msgs/…`(메일함 거울, 읽기 STAFF·로그인 직원) + 지난 메일 거울(`…/old/msgs`)의 **머리글 행만**. 첨부 바이트·본문은 후보 단계에서 읽지 않는다. 읽기 실패는 칸 창에 「메일함을 불러오지 못했습니다」 + 다시 시도(다른 칸 기능은 그대로).
- 업체 귀속: `PuCoThread.addrsOf(co)`(업체관리 주소 + 이알피 연락처 주소)가 보낸이/받는이에 있으면 후보. 한 주소가 두 업체에 있으면 먼저 등록된 쪽(기존 규칙 `status/2026-10-05-mail-owner-erp-addr.md`). **주소가 하나도 없는 업체는 「메일 주소가 등록돼 있지 않아 후보를 못 찾았습니다 — 업체관리에서 주소를 넣어 주세요」.**
- 거르기: 첨부 건수(`a`)가 0 이면 뺀다 · 기간 밖 뺀다 · `an` 이름이나 제목이 `PuGovReportBuild.PRIV_RE`(급여·근태·명부·4대·원천·주민·통장·연말정산)에 걸리면 **줄은 보이되 「개인 자료 · 목록에만」 딱지를 붙이고 「연결」·「열어 보기」 는 막는다**(복제하지 말고 `PRIV_RE` 를 가져다 쓴다).
- 기술보호 사업 줄: 「기술보호 자료」 딱지를 붙인다(열어 보기는 허용, 연결은 허용 — 보관·삭제는 2차).
- 최대 후보 수 50(날짜 내림차순). 넘으면 「50건만 보입니다」.

## 3. 연결 저장 — 규칙 변경이 필요하다

`scal_docs/{co}/{rid}/items/{key}` 줄에 선택 필드 하나를 더한다.

```
link: { src:'mail', key:<문자열 1~80>, name?:<문자열 ≤100>, date?:'YYYY-MM-DD' }
```

- `key` = 서버에서 그 첨부를 다시 가져오는 데 필요한 값의 압축 문자열: 일반 폴더 `i:<slug>:<uid>:<part>` · 지난 메일 `o:<popKey>:<index>` (80자 이내). 해석은 순수 함수가 한다(만들기·풀기·검증). 알 수 없는 꼴은 «열 수 없음»으로만 다룬다.
- 규칙: `link` 는 `hasChildren(['src','key'])`, `src` 는 `'mail'` 만, `key` 문자열 1~80, `name` ≤100, `date` 는 기존 `SCAL_DOCS_DAY`, 그 아래 `$other:false`. **줄 수준 `$other:false` 때문에 규칙을 올리기 전에는 `link` 가 든 쓰기가 통째로 거절된다.** 규칙 JSON 두 개를 생성기에서 다시 만들고, **게시는 대표 승인 뒤에만** 한다(2단계·서류 기록과 같은 방식: 게시 전에는 «연결» 단추가 눌리되 저장이 거절돼 「저장하지 못했습니다 — 규칙 게시 또는 권한 확인」, 값은 그대로).
- 호환: 지금 `grSaveCell` 은 줄 전체를 `.set` 한다 → 상태만 고치는 저장이 **기존 `link` 를 지우지 않도록** `link` 를 이어 받아 같이 쓴다(테스트로 고정).
- 모듈(`js/pu-gov-report-track.js`): `normRec`·`patchFor`·`validate` 에 `link` 가지를 더한다(잘라내기·잘못된 값 버리기·`LINK_KEY_MAX=80`·`LINK_NAME_MAX=100`·`LINK_SRC`). `__proto__` 같은 이름 방어(2단계 교훈)는 그대로.

## 4. 열어 보기 (서버에서 한 건씩)

- 호출: 기존 서버 함수 `readMailAttachment`(일반)·`readOldMail`(지난) — 로그인 ID 토큰 `Authorization: Bearer`. 공용 `js/rules-v2/mail-orig.js` 의 `PuRulesMailOrig.makeCall/fetchOriginal`(첨부 목록 조회 → 이름이 같은 첨부 받기 → sha256 확인, IMAP·POP3 둘 다)을 **가져다 쓴다**(새로 짜지 않는다). 첨부 상한 20MB(서버 413) — 20MB 넘으면 확인창.
- **동시 호출 금지**: 한 번에 하나만(지난 메일 POP3 가 동시 호출에 막힌다). 열어 보는 중이면 다른 「열어 보기」 단추는 잠긴다. 지난 메일은 30~60초 걸릴 수 있다 → 「불러오는 중… (지난 메일은 1분쯤 걸립니다)」.
- 열기: 확장자·종류로 가른다 — `.hwp·.hwpx` → `PuHwpPreview.open`, `.pdf` → pdf.js 로 쪽 그림(`vendor/pdf.min.js`), 이미지 → blob URL `<img>`, `.xlsx·.xls` → 첫 시트 앞 200행 표, 그 밖 → 「이 형식은 앱에서 열 수 없습니다 — 메일함에서 받아 주세요」.
- 다운로드는 하지 않는다(크롬이 이 사이트의 반복 다운로드를 막는다). 바이트는 저장·업로드 안 함, 닫으면 `revokeObjectURL`·참조 해제.
- 실패 문구: 시간 초과 「메일 서버 응답이 없습니다 — 잠시 뒤 다시」 · 권한/로그인 「로그인을 확인해 주세요」 · 첨부 없음 「메일에서 그 첨부를 찾지 못했습니다(지워졌을 수 있습니다)」. 어느 경우든 칸 창 상태는 그대로.

## 5. 개인정보

- 후보 목록·연결에는 **업체 이름(칸 창 제목)·보낸이 표시이름 또는 주소·날짜·제목·첨부 이름**만 나온다. 본문은 읽지 않는다.
- 후보·연결 저장 모두 **사람이 누른 것만**. `link.name` 은 첨부 파일 이름(≤100자) — 파일 이름에 사람 이름이 들어 있을 수 있음을 칸 창에 한 줄 안내(2단계 메모 안내와 같은 자리).
- PRIV 딱지 건은 연결·열어 보기를 막는다. AI 로는 아무것도 보내지 않는다.
- 공개 저장소: 검사·문서에는 합성 이름(가나상사·홍길동·example.com)만.
