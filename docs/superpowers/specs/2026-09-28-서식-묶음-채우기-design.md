# 서식 묶음 채우기 — 설계

- 작성: 2026-09-28
- 지시: 대표노무사 (2026-09-27) 「서식들 내용들은 한번에 모두 자동으로 입력되게 하고 싶은데 어떻게 해야하나」 → 목업 9개(상황 3 × 안 3) → 「추천대로」
- 결정: 상황 1 = 1-A + 1-C, 상황 2 = 2-B + 2-A, 상황 3 = 3-B + 3-C. 만드는 순서 2 → 1 → 3. 받는 파일 기본 = 압축(.zip), 집단체불만 양식별 합본 PDF 선택.
- 바탕: 양식 한 장 「채워서 받기」(js/pu-contract-forms.js `openFill`, 값 규칙 js/pu-form-cardfill.js, 한글·엑셀 채우기 docs-esign.html `formHwpFill`)가 이미 있다.

## 1. 세 단계

| 단계 | 상황 | 어디서 | 무엇 |
|---|---|---|---|
| **A** (이번) | 2 근로자 사건 묶음 | 문서관리 › 계약서 양식 | 묶음 세트 저장(2-B) + 목록 체크(2-A) → 한 사람 기준으로 N개를 한 번에 채워 .zip |
| B | 1 업체 계약 묶음 | 이알피 › 계약관리 | 계약 안 「서류 묶음」 판(1-A) + 목록에서 여러 계약(1-C). 계약 자료(계약번호·금액·기간)로 채움 |
| C | 3 집단체불 여러 명 | 문서관리 › 집단체불 위임장 | 진행판(3-B) → 내는 모양 고르기(3-C: 사람별 폴더 .zip / 양식별 합본 PDF / 둘 다 + 연명부·체불내역) |

B·C 는 A 의 부품(세트, 여러 양식 채우기, 압축)을 그대로 쓴다. 각 단계는 앞 단계를 머지한 뒤 따로 계획한다.

## 2. A 단계 — 설계

### 2-1. 세트 자료

`data/contract_form_sets` = `{ v: [세트…], rm: [지운 기본 세트 id…], u }` — 계약서 양식과 같은 통표·거래 방식(서버 최신본 위에 한 건만 고친다).
기존 규칙 `data/$other`(재직 직원 읽기·쓰기)가 받는다 — 규칙 배포 필요 없음.

```js
{ id: 'fs-…', name: '체당금 접수 세트', formIds: ['fm-case-cd-01', …], kind: 'case', side: 'worker', groupName: '체당금', at, by }
```

- 기본 세트 하나: 「체당금 접수 세트」 = 체당금 기본 양식 4종. 지우면 `rm` 에 남겨 다시 안 생긴다.
- 세트에 든 양식이 지워졌으면 그 id 는 건너뛴다(세트는 안 깨진다).

### 2-2. 화면

- **목록 체크(2-A)** — 목록 줄마다 체크 칸. 계약유형을 바꿔도 체크는 남는다(업체계약 CMS 신청서를 사건 묶음에 섞을 수 있다).
- **아래 막대** — 하나라도 체크하면 목록·종이 아래에 「N개 선택 · [세트로 저장] [N개 채워서 받기] [선택 풀기]」.
- **세트 고르기(2-B)** — 칩 줄에 「📚 세트」 고르기 칸. 고르면 그 세트 양식이 체크되고 막대가 뜬다. 「세트 관리…」에서 이름 바꾸기·지우기.
- **묶음 채우기 창** — 지금의 「채워서 받기」 창을 넓힌다:
  - 회사(이알피 업체관리) · 담당자(기업정보함) · 근로자를 «한 번» 고른다.
  - 채울 자리는 N개 양식의 합집합. 칸마다 쓰이는 양식 수를 보인다(「착수금 · 위임약정서」).
  - [묶음 받기 .zip] — 한글·엑셀 원본이 있는 양식은 채운 원본, 없는 양식은 채운 본문(.txt). 파일 이름은 `01_양식이름_회사_근로자.hwp` 처럼 번호를 붙여 겹치지 않게.
  - [하나 골라 열어 보기] — 양식 하나를 골라 채운 모습을 본다.
  - 빈 칸은 지금처럼 밑줄. 받기 전에 「빈 칸 N곳」을 알린다.
- 양식 하나일 때는 지금 「채워서 받기」와 똑같다.

### 2-3. 지키는 것

- 채운 값은 저장하지 않는다 — 내려받는 파일에만 들어간다(지금 원칙 그대로).
- 주민번호 등은 브라우저 밖으로 안 나간다 — 압축도 브라우저 안(vendor/jszip)에서 만든다.
- 사용자 값은 innerHTML 에 조립하지 않는다. ES5.
- 세트 저장은 거래 한 길(`changeSets`) — 통째 set 금지.

### 2-4. 부품 (순수 함수, 검사 가능)

- `setsOf(doc)` — 저장본 + 기본 세트(지운 것 빼고).
- `changeSets(db, fn)` — 서버 최신본 위에 고치기.
- `bundleMarkers(items)` — 양식들의 채울 자리 합집합 `[{ key, forms: [양식 이름…] }]`(나온 차례).
- `bundleFileNames(items, V)` — 번호 붙은, 겹치지 않는 파일 이름.
- `zipName(title, V)` — `세트이름_회사_근로자.zip`.

### 2-5. 검사

- 세트: 기본 세트가 들어오고, 지운 기본 세트는 안 돌아오고, 서버 최신본 위에 한 건만 고친다.
- 합집합: 겹치는 칸은 한 번, 어느 양식에 쓰이는지 모두.
- 파일 이름: 같은 이름 양식 둘이어도 안 겹친다, 금지 글자 없음.
- 화면 구조: 목록 줄 체크 칸, 막대, 세트 고르기, 묶음 창이 여러 양식을 받는다.
- 눈으로: 가짜 데이터 시험 화면(1,600×820, 375px)에서 체당금 세트 → 한 사람 → .zip 4개 파일.
