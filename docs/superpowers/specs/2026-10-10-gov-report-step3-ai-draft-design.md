# 정부컨설팅 보고서 3단계 — AI 초안 설계

> **2026-10-10 변경** — 전송 경로를 Claude 프록시에서 기존 Gemini readDoc 경로(`PuAiCall`)로 바꿨다. 프록시 주소(`aiProxyUrl`)가 한 번도 설정되지 않아 동작하지 않았기 때문이다. 이제 로그인이 필요하고 월 사용 한도가 적용되며, 동의 문구는 「외부 AI(Google Gemini)」다. 아래 본문의 프록시·Claude 모델 순서 서술은 이 변경으로 대체된다.


- 작성일: 2026-10-10 · 상위 설계서: `2026-10-05-정부컨설팅-보고서자동화-design.md` (§6-3·§9·§11·§13 위험 ⑦)
- 결정(대표 「추천대로」 2026-10-10)
  - 범위: **회차별 칸 + 종합 칸** 모두 초안을 쓴다.
  - 기술보호: **기본 끔, 노무사가 켜면 사용**(켜도 회차 메모만 보낸다).
  - 길: **기존 Claude 프록시**(업무관리·fund 와 같은 `aiProxyUrl`)를 브라우저에서 부른다.
    서버 함수(로그인 확인·월 한도)는 사용량이 커지면 옮길 다음 길로 남긴다.

## 1. 무엇을 하나

보고서 작성 창(A안)의 **✨ AI 초안** 단추를 누르면, 이미 모아 둔 자료(회차·메일·보낸 서류)로
비어 있거나 전에 AI 가 쓴 칸에 문안을 넣는다. 노무사가 고치고 확정하는 흐름은 2단계 그대로다.

채우는 칸

| 묶음 | 칸 (report 안 이름) |
|---|---|
| 회차마다 | `rounds[i].inquiry` 문의 · `diagnosis` 진단 · `advice` 자문 · `result` 성과 · `next` 향후 |
| 종합 | `summary.inquiryDiag` · `review` · `action` · `etc` · `adviceAll` · `overall` |

그 양식이 쓰지 않는 칸은 보내지도 받지도 않는다(양식 지도 `PuGovReport.FORMS` 기준).

## 2. 보내는 것 · 안 보내는 것

보낸다
- 회차: 날짜 · 방문/사무 · 메모(`scal_scheds` memo) · 이미 사람이 쓴 칸 값(맥락으로)
- 업무관리 자료(`feed`): 메일 제목 · 본문 앞부분(최대 1,500자) · 보낸 서류 **이름**
- 기관 작성기준 문구(양식별 `guide`, 없으면 공통 문구)와 칸별 글자 수 한도

안 보낸다
- `priv:true` 자료(급여·근태·명부·4대·원천·주민·통장·연말정산 — `PRIV_RE`)
- 첨부파일 원본, 사진, 도장
- 업체 이름 · 대표자 · 담당자 이름 → 보내기 전 「해당 기업」·「대표자」·「담당자」로 바꾸고, 받은 글에서 되돌린다
- **기술보호**: 켰을 때도 회차 날짜·메모만. 메일·서류·기술 자료는 보내지 않는다.

가리기(보내기 직전, 모든 글에)
- 주민등록번호, 전화·팩스, 계좌로 보이는 숫자열, 메일 주소, 사업자등록번호 → `[가림]`

동의
- 처음 쓸 때 「업체 자료가 외부 AI(Anthropic)로 전송됩니다 — 가림 처리 후」 동의 창. 브라우저에 기억(`gov_ai_ok`), 업무관리·fund 와 같은 방식.

## 3. 요청과 응답

- 모델: 업무관리와 같은 순서(큰 모델 → 실패 시 작은 모델). max_tokens 8000, 시간 제한 90초.
- system: 역할(노무사 보고서 초안), 작성기준, **입력에 없는 사실·날짜·숫자를 만들지 말 것**,
  기록 없는 회차는 정확히 `기록 없음 — 입력 필요`, 칸별 글자 수 한도, **JSON 만** 답할 것.
- 응답 꼴: `{"rounds":[{"i":0,"inquiry":"…",…}],"summary":{"overall":"…",…}}`
- 읽기: 첫 `{` 부터 마지막 `}` 까지 잘라 JSON 으로 읽는다. 못 읽으면 한 번 더 묻고, 그래도 못 읽으면 오류 안내.

## 4. 칸에 넣기

- 넣는 칸: **비었거나**, **전에 AI 가 넣고 사람이 손대지 않은** 칸만. 사람이 쓴 칸은 덮지 않는다.
- 표시: AI 가 넣은 칸은 `src[칸]='ai'` → 화면에 「AI 초안」 딱지. 사람이 고치면 `src` 가 사람으로 바뀌고 딱지가 없어진다.
- 되돌리기: 직전 AI 넣기 한 번을 되돌린다(넣기 전 값 보관).
- 점검(경고만, 막지는 않음)
  - 입력에 없던 **날짜·숫자**가 결과에 나오면 그 칸에 「확인 필요」 경고.
  - 글자 수 한도 초과 칸 경고.
  - 이름 되돌리기 뒤에도 `[가림]` 이 남은 칸 경고.
- 저장은 하지 않는다 — 사람이 「💾 임시 저장」·「✔ 확정」을 누를 때만(2단계 그대로).

## 5. 오류

| 상황 | 안내 |
|---|---|
| 프록시 주소 없음 | 「AI 프록시가 설정되지 않았습니다 — 포털 ⚙ 설정」 |
| 동의 안 함 | 아무것도 보내지 않음 |
| 시간 초과·네트워크 | 「AI 응답이 없습니다 — 잠시 뒤 다시」, 칸은 그대로 |
| JSON 못 읽음(재시도 뒤) | 「AI 답을 읽지 못했습니다」, 칸은 그대로 |
| 기술보호 + 꺼짐 | 단추 비활성, 「이번 건 AI 사용」 켜기 안내 |
| 확정된 판(잠김) | 단추 비활성 |

## 6. 만들 것

- `js/pu-gov-report-ai.js` (순수 함수, 브라우저·node 겸용)
  - `fieldsFor(formKey, fileKeys)` — 그 양식이 쓰는 칸 목록
  - `mask(text, names)` → `{text, back}` / `unmask(text, back)`
  - `buildRequest(report, feed, formKey, opts)` → `{system, messages, sent}` (`opts.techguard`, `opts.limits`)
  - `parseDraft(text)` → `{rounds, summary}` 또는 오류
  - `applyDraft(report, src, draft)` → `{report, src, undo, filled:[칸]}`
  - `checkDraft(draft, sentText, limits)` → 칸별 경고
- `gov-consulting.html`
  - ✨ 단추 연결(`grpAiDraft`), 진행 중 표시, 기술보호 켜기 스위치, 「AI 초안」 딱지·경고, 되돌리기
  - 프록시 부르기는 업무관리 `aiCall` 과 같은 꼴을 이 화면에 둔다(공용 모듈 정리는 이번 범위 밖)
- 검사: `tests/gov-report-ai.test.js`(모듈), `tests/gov-report-ui.test.js` 에 가짜 프록시로 단추 흐름
  — 가림이 빠짐없이 되는지, 기술보호 때 메일이 안 나가는지, 사람이 쓴 칸을 덮지 않는지를 반드시 본다.
