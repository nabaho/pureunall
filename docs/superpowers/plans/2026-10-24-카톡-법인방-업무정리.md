# 카톡 법인 업무채팅방 → 업무관리 진행 기록 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 총괄관리자가 PC 카톡 «대화 내보내기» `.txt`(+받은 파일 폴더)를 올리면, 업무관리 💬 카톡정리 안에서 사건번호·업체별로 묶어 미리보고, 확인한 것만 진행 기록으로 넣고, 가린 원문을 30일 보관하고, 법인방 첨부 파일을 사건 폴더로 복사한다.

**Architecture:** 읽기·묶기·맞추기는 브라우저 순수 모듈 `js/pu-kakao-export.js`(UMD, DOM 없음)에서 한다. 화면은 `work.html` 💬 카톡정리의 새 탭. 원문 30일 보관은 기존 `hanaMessageBridge` 에 총괄관리자 전용 동작 `kakaoImport` 를 더해 `kakaoWork/notes` 에 담는다(알림 길과 같은 자리·같은 삭제). 진행 기록은 `addLog` 와 같은 자리에 줄 열쇠를 내용으로 정해 한 번의 다중 경로 `update` 로 쓴다.

**Tech Stack:** 순수 JS(빌드 없음), Firebase RTDB(`work_erp`, `kakaoWork`), Cloud Functions(`functions/kakao-work-server.js`), `node --test`, File System Access API.

**Spec:** `docs/superpowers/specs/2026-10-24-카톡-법인방-업무정리-design.md` (이하 «스펙»)

## Global Constraints

- 카톡 클라이언트 자동조작·DB 복호화·스크래핑 **금지**. AI·외부 전송 **없음**.
- 한국어 주석·화면 글자·커밋. 노무 용어(급여→임금, 직원→근로자).
- 검사는 «지금 값»이 아니라 «규칙»을 박는다(`tests/test-pin-guard.test.js`). 값 자체가 규칙인 것(30일·14일·400건·280자)만 같은 줄에 `검사고정-허용` 과 까닭을 적는다.
- `.js` 를 고치면 부르는 쪽 `?v=` 를 올린다(`scripts/check-cache-version.js`). 새 스크립트는 `?v=1`.
- 기존 셈 한 벌 `js/pu-kakao-work.js` 와 서버 사본 `functions/kakao-lib/` 은 **건드리지 않는다**(`maskSensitive`·`roomAllowed`·`noteKeySource`·`findDue`·`KEEP_DAYS` 는 불러다 쓴다).
- 목록 맨 왼쪽은 ☐ 고르기 칸 + 번호(보는 번호, 저장 안 함). 한 칸은 한 줄. 폰은 폰 구간(`@media (max-width:…)`)에서만 두 줄 카드, 입력칸 16px 이상.
- 색은 27색 팔레트 안(기존 `.kkc` 칩 색을 그대로 쓴다). 목업 파일은 저장소에 두지 않는다.
- 원본 보존: 파일은 **복사만**, 덮어쓰기 없음, 진행 기록은 덮어쓰지 않고 새 줄만 더한다.
- 서버 배포·병합은 사용자 승인 없이 하지 않는다. PR 제목에 `[보류]` 를 붙여 자동 병합을 멈춘다.
- 손댄 기록은 `status/2026-10-24-kakao-export-worklog.md` 새 파일 하나(뿌리 `STATUS.md` 표에 덧붙이지 않는다).

## Review Focus

1. **개인 대화방 파일·머리글 없는 파일**: 방 이름이 목록 밖이거나 머리글이 없으면 «읽기 전에» 거절하고 아무것도 화면에 올리지 않는다(Task 1·5).
2. **겹치는 주간 내보내기·같은 파일 두 번**: 새 줄 0, 내용이 달라지면 옛 줄 유지+새 줄(Task 2·5).
3. **오전 12시·오후 12시·자정 직후 글**: 날짜가 하루 어긋나면 열쇠와 30일 칸이 모두 틀어진다(Task 1).
4. **같은 사건번호가 여러 업무에 있거나 한 글에 번호 둘**: 자동으로 정하지 않고 후보를 보인다(Task 3).
5. **파일 이름에 경로 문자(`..`·`/`·`\`)·이미 있는 같은 이름·수천 줄짜리 전체 내보내기**: 거절·건너뜀·30일 밖 건너뜀과 400건 나눠 보내기(Task 3·4·6).
