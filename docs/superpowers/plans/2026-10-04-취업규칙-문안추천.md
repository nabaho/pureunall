> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ✏️ 검토·개정(rules.html)의 조문 편집 칸에 «💡 우리 문안» 상자를 붙인다. 모은 자료의 같은 조 주제 문안 가운데 **가장 최근 · 비슷한 회사 · 가장 많이 씀** 세 덩어리를 보이고, 「이 문안 넣기」로 「변경 후」 칸에 채운다.

**Architecture:** 고르기는 순수 모듈 `js/rules-v2/lib-recommend.js`(`pick`)가 한다. 그리는 글은 `js/rules-v2/view-recommend.js`, rules.html 은 잇기만 한다. 자료·묶기는 📚 와 같은 `PuRulesV2TopicsView.model`, 위반 표시는 같은 `warnsOf`(view-topics 에서 내보낸다).

**Tech Stack:** 빌드 없는 브라우저 JS(ES5 꼴 모듈, `window.X` + `module.exports`), Firebase compat 10.13.2, node:test.

**Spec:** `docs/superpowers/specs/2026-10-03-취업규칙-새로짓기-design.md` §8 (8-1~8-5)

### Task 1: 고르기 — `js/rules-v2/lib-recommend.js` + `warnsOf` 내보내기

**Files:** Create `js/rules-v2/lib-recommend.js`, `tests/rules-recommend.test.js`; Modify `js/rules-v2/view-topics.js`(+ 그것을 싣는 rules-v2.html 의 `?v=`), `tests/rules-v2-view-topics.test.js`(필요하면)

**Interfaces:**
- Consumes: `PuRulesV2TopicsView.model(data, texts, companies, stdText, today, criteria)` → `{topics, byTopic:{[topicKey]: groups}}`. 덩어리 `g = {key /*normKey*/, text /*{회사}·{근로자} 자리표시 글*/, members:[{docId, companyId, companyName, final, date, label, title, body}], finals, places /*회사 수*/, last}`.
  `PuRulesV2Topics.normKey(body, coName)`, `PuRulesV2Sites.band(n)`.
- Produces: `window.PuRulesV2Recommend = { pick, LABELS }`
  - `pick(groups, ctx)` → 길이 0~3 배열, 차례는 늘 최근 → 비슷한 → 많이, 빈 갈래는 빠진다:
    `[{ why:'recent'|'similar'|'most', group:g, rep /*그 덩어리에서 보일 대표 member*/, similar /*why==='similar' 일 때만: [{companyId, companyName}]*/ }]`
  - `ctx = { curBody /*지금 「현행」 본문*/, curCoName /*지금 회사 이름*/, companyId /*지금 회사 id 또는 ''*/, band /*'' 이면 모름*/, bizType /*'' 이면 모름*/, coById /*{id: company}*/ }`
  - `LABELS = { recent:'가장 최근', similar:'비슷한 회사', most:'가장 많이 씀' }`
- `view-topics.js`: `warnsOf(g, M, size)` 를 api 에 더한다. `size` 가 없으면 지금 `SIZE`('10인이상'). 📚 의 쓰임은 그대로.

**규칙(테스트가 볼 것):**
1. 후보는 `normKey(ctx.curBody, ctx.curCoName) !== g.key` 인 덩어리만(지금 글과 같은 덩어리 빼기).
2. **recent**: `finals>0` 인 덩어리가 있으면 그 가운데 «★최종본 member 의 date 최댓값»이 가장 큰 것, 없으면 `g.last` 가 가장 큰 것. `rep` = 그 date 의 member.
3. **similar**: `ctx.band` 와 `ctx.bizType` 이 둘 다 있을 때만. 각 덩어리에서 «`companyId` 가 있고, `ctx.companyId` 가 아니고, `coById[id]` 의 `band(employmentInsuredCount) === ctx.band` 이고 `bizType === ctx.bizType`» 인 **서로 다른 회사** 수를 센다. 1 이상인 것 중 가장 많은 것(같으면 `finals` → `last`). `similar` 에 그 회사들. `rep` = 그 회사들 member 중 ★ 먼저 → 최근.
4. **most**: `places` 가장 큰 것(같으면 `finals` → `last`). `rep` = members[0](이미 ★ → 최근 차례).
5. 세 갈래는 서로 다른 덩어리 — recent 가 고른 것은 similar·most 후보에서, similar 가 고른 것은 most 후보에서 뺀다.
6. 덩어리가 없거나 후보가 없으면 `[]`.
