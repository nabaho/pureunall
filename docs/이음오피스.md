# 이음오피스(IeumOffice) — 대표 PC 설치 (2026-11-17)

> 대표 지시 「이음오피스 내 PC 에 다운받고 실행 가능하게 해라」

- 무엇: 워드·엑셀·PPT·PDF·한글(HWP·HWPX)을 한 창에서 열고 고치는 무료 오픈소스 데스크톱 오피스(Apache-2.0, 한글 편집은 rhwp).
  공식 저장소 github.com/pblsketch/ieumoffice · 누리집 ieumoffice.com. 2026-11-17 기준 v0.13.0(베타).
- 까는 법: 대표 PC 에서 `tools\ieumoffice\install-ieumoffice.bat` 를 두 번 누른다.
  공식 저장소의 최신 릴리스에서만 `IeumOffice-Setup-*.exe` 를 받고, 크기·지문(SHA256)을 확인한 뒤 설치 창을 띄운다.
  ⚠ 설치 파일에 코드 서명이 없다(제작자 README) — 「Windows의 PC 보호」 창의 «추가 정보 → 실행»은 사람이 누른다.
- 이미 깔린 뒤에는 앱이 GitHub 릴리스를 보고 스스로 업데이트한다.
- ⚠ AI 기능: 켜면 문서 내용이 연결한 회사(Claude·ChatGPT·Gemini·OpenRouter 등)로 간다. 무료 AI 는 보낸 내용이 그 회사의 학습에 쓰일 수 있다.
  고객 주민번호·임금대장·사건 문서에는 AI 를 쓰지 않는다. 설정 → AI 에서 끌 수 있다.
- 클라우드 방(Claude)에서는 PC 에 닿지 않아 대신 깔 수 없다 — 이 파일을 PC 에서 돌리거나, PC 에서 연 Claude 방에 맡긴다.
