| 겹 | 무엇이 막나 | 누가 거나 | 지금 |

## 1단계 — 코드로 한 것 (이 PR)

- **AI 지우개(사진 AI 편집)에 한도를 달았다.** 여태 셈도 한도도 없었다(그림 모델 = 가장 비싼 종류).
  - 판독과 **같은 지갑**(이번 달 한도, `ai_read_budget`)에 센다. 한 장 = 판독 15번(≈ ₩60)으로 친다(`functions/photo-edit.js` `EDIT_READ_WEIGHT`).
  - 한 사람 **하루 20장**(`EDIT_DAY_PER_USER`). 셈 자리 `ai_user_day/` 는 서버만 쓴다(규칙에 없음 = 브라우저 접근 불가).
  - 이번 달 한도를 넘었거나 셈을 못 읽으면 **부르지 않는다.**
  - 구글이 «200 으로 답한» 수만 센다 — 재시도(429)는 요금이 아니다.
- **판독의 «사람이 누른 것은 무제한»을 막았다.**
  - 한도까지: 누구나. 한도 넘으면: 사람이 누른 것만. **한도의 1.2배 넘으면: 모두 멈춤**(`functions/doc-read.js` `budgetGate`).
  - 더 써야 하면 대표님이 포털 💰 에서 한도를 올린다(관리자만 고칠 수 있다).
  - 셈을 못 읽으면 자동 판독만 멈추고, 사람이 누른 것은 통과(일이 통째로 서지 않게).

⚠ 서버 함수라 **배포해야 적용된다** — `readDoc`·`photoEdit` 두 함수만 이름을 찍어 올린다
(`docs/배포-클라우드에서.md` · GitHub 작업 「Firebase 배포」).

## 콘솔에서 사람이 걸 것 — 순서표 (권장 1순위 · 약 30분)

코드 한도는 «코드가 지켜야» 작동한다. 아래는 회사 쪽에서 강제로 막는 «진짜 상한»이다.
화면 메뉴 이름은 바뀔 수 있다 — 다르면 이 문서를 고친다.

1. **구글 클라우드 — Gemini API 하루 요청 상한**
   console.cloud.google.com → 프로젝트 `pureun-erp` → «API 및 서비스» → «Generative Language API» → «할당량 및 시스템 한도»
   → «Requests per day»(하루 요청 수)를 **3,000** 정도로 낮춘다(평소 실사용의 수 배 — [확인 필요] 최근 하루 최대치를 보고 정한다).
2. **구글 클라우드 — Vision API 하루 상한**
   같은 자리에서 «Cloud Vision API» → 하루 요청 수 **100** 정도(코드가 이미 달 1,000장에서 멈추지만 이중으로).
3. **파이어베이스 웹 키 제한**
   «API 및 서비스» → «사용자 인증 정보» → 「Browser key (auto created by Firebase)」 → «API 제한사항» →
   Firebase 에 필요한 것만 남기고(Identity Toolkit·Token Service·Realtime Database·Firebase Installations 등) **Generative Language·Vision 은 빼기**.
   «웹사이트 제한»에 `nabaho.github.io/*` 와 쓰는 도메인만.
   ⚠ 빼기 전에 목록을 갈무리해 두고, 바꾼 뒤 포털 로그인이 되는지 바로 확인한다(잘못 빼면 로그인이 멈춘다).
4. **구글 결제 — 예산 알림 확인**
   «결제» → «예산 및 알림» → 예산이 있는지, 50·90·100% 알림이 대표님 메일로 가는지, Pub/Sub 주제가 연결돼 있는지(`billing-alert` 함수가 받는 것) 확인.
5. **Anthropic 콘솔** (클로드 «AI 프록시»가 쓰는 키)
   console.anthropic.com → «Settings» → «Limits» → 월 사용 상한(spend limit)을 건다. [확인 필요] 프록시가 어느 계정의 키를 쓰는지.
6. **OpenAI 콘솔** (깃허브 Codex 작업)
   platform.openai.com → «Settings» → «Limits» → 월 예산 상한.
