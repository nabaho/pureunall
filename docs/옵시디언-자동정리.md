# 옵시디언 자동 정리 — AI 작업 기록 → 보관함 → LLM 위키

`tools/obsidian-sync/` (2026-10-18). 내 PC 의 클로드 코드·코덱스·챗지피티 기록을 옵시디언 보관함에 자동으로 쌓고,
쌓인 것을 AI 가 위키로 정리하게 한다. 저장소 안에서 돌지만 **보관함은 저장소 밖**에 둔다.

## 세 층
```
보관함/
  raw/sessions/<원본>/날짜 제목 id.md   ← 원자료. AI 대화 기록(민감정보 가림). 고치지 않는다
  raw/erp/…                            ← 원자료. 푸른이알피 «옵시디언 업무요약» 단추가 만든다(아래 «이알피 연결»)
  daily/날짜.md                        ← 그날 작업 목록(표시 사이만 자동, 바깥은 손글씨)
  wiki/index.md · log.md · projects/ · clients/ · concepts/   ← AI 가 정리, 사람이 바로잡음
  wiki/_pending.md                     ← 아직 위키로 정리 안 된 원자료
  CLAUDE.md · AGENTS.md                ← 위키 규칙(없을 때만 만든다 — 고쳐 쓰면 그대로 둔다)
```

## 쓰는 법 (내 PC 에서)
```
git pull
node tools/obsidian-sync/sync.js --vault "D:\푸른업무"            # 클로드 코드 + 코덱스
node tools/obsidian-sync/sync.js --vault "D:\푸른업무" --dry-run  # 먼저 건수만 보기
```
- `--vault` 대신 환경변수 `OBSIDIAN_VAULT` 도 된다. 옵시디언에서 그 폴더를 «보관함으로 열기».
- 다시 돌려도 안전하다 — 바뀐 세션만 같은 파일에 갱신한다(`.obsidian-sync-state.json`).
- 거르기: `--exclude 고객사이름`(프로젝트·제목에 들어 있으면 제외, 여러 번 가능) · `--since 2026-10-01` · `--min-turns`.
- **위키 정리**: 보관함 폴더에서 `claude` 를 열고 «정리해줘». `CLAUDE.md` 의 절차대로 `_pending.md` 를 읽어
  `wiki/` 를 고치고 `log.md` 에 `ingest | 경로` 를 남긴다. 「점검해줘」는 근거 없는 문장·모순·끊긴 링크를 찾는다.

## 이알피 연결 (2026-10-19 한 보관함으로 합침)
푸른이알피 왼쪽 메뉴의 「📝 옵시디언 업무요약」 단추(`js/pu-obsidian.js`)가 이제 **같은 보관함**(이름 `푸른업무`)의 `raw/erp/` 에 노트를 만든다.
- 보관함 이름이 `푸른업무` 가 아니면: 이알피를 연 브라우저 콘솔에서 `localStorage.setItem('pu_obsidian_vault','내보관함이름')` (또는 보관함 폴더 이름을 `푸른업무` 로).
  이름을 못 찾으면 옵시디언이 «보관함을 찾을 수 없다» 고 하며 노트가 안 생긴다 — 같은 내용이 클립보드에 남으니 붙여넣으면 된다.
- 다음에 `sync.js` 를 돌리면 `raw/erp/` 노트가 `daily/날짜.md` 하루 목록과 `wiki/_pending.md` 에 함께 잡힌다 → 「정리해줘」 대상.
- ⚠ 이미 만들어 둔 보관함의 `CLAUDE.md` 는 덮어쓰지 않는다 — 구조 표의 `raw/erp/` 한 줄은 직접 보태거나 파일을 지우고 `sync.js` 를 한 번 더 돌려 새 틀을 받는다.
- 별개로 `work.html` 의 «옵시디언 금고로 내보내기»(사람·사업장 장 파일)는 고른 폴더에 쓰는 다른 기능이라 건드리지 않았다.

## 챗지피티
챗지피티는 바깥에서 읽어 올 길이 없다 — **내보내기 파일**을 쓴다.
설정 → 데이터 제어 → 데이터 내보내기 → 메일로 온 zip 을 받아
`node tools/obsidian-sync/sync.js --vault … --chatgpt "C:\다운로드\…\.zip"` (zip 또는 conversations.json).
새로 쓴 대화를 넣으려면 내보내기를 다시 받아 같은 명령을 돌린다(이미 넣은 대화는 그대로 두고 바뀐 것만 갱신).

## 자동으로 돌리기 (대표 PC 에서 직접 등록 — 도구는 등록하지 않는다)
- **클로드 코드가 끝날 때마다**: `~/.claude/settings.json` 의 `hooks.SessionEnd` 에
  `node <저장소>/tools/obsidian-sync/sync.js --vault "D:\푸른업무"` 를 건다.
- **매일 밤**: 윈도우 작업 스케줄러 — `schtasks /create /sc daily /st 22:00 /tn 옵시디언정리 /tr "node <저장소>\tools\obsidian-sync\sync.js --vault D:\푸른업무"`.

## 안전 — 이 집에는 고객 자료가 있다
- 가리는 것: 주민·외국인등록번호 · 사업자번호 · 전화 · 계좌 · 이메일 · 토큰·비밀키 · `password=` 류 값.
  **도구 실행 결과(파일 내용·명령 출력)와 AI 의 «생각»은 아예 안 옮긴다.** 그래도 대화 글 속의 **고객사 이름·사건 내용은 남는다** —
  보관함은 개인 PC 의 폴더로만 두고 공유 폴더·클라우드 동기화·공개 저장소에 올리지 않는다.
- 보관함이 이 저장소 안이면 실행을 거절한다(이 저장소는 사이트로 배포된다).
- 원본(`~/.claude`·`~/.codex`·내보내기)은 읽기만 한다. 위키 규칙 파일·색인·손글씨는 덮어쓰지 않는다.
- 위키 규칙에 «고객사별로 장을 나누고 서로 섞지 않는다·법령은 원자료에 있는 것만 옮긴다·개인정보는 위키로 옮기지 않는다» 를 적어 두었다.

## 한계 (확인한 것 / 못 한 것)
- 클로드 코드 기록 읽기는 실제 기록 파일(이 세션)로 돌려 확인했다. **코덱스 기록·챗지피티 내보내기는 실제 파일로 확인하지 못했다** —
  공개된 모양을 따라 «아는 것만» 읽는다. 첫 실행 뒤 `--dry-run` 건수와 노트를 눈으로 확인할 것.
- «내 컴퓨터의 모든 업무» 중 **AI 대화가 아닌 것**(브라우저·문서 작업·메일 등)은 수집하지 않는다. 이알피 업무요약은 `js/pu-obsidian.js` 가 따로 한다.
- 클라우드(웹·폰)에서 돌린 클로드 코드 세션은 그 컨테이너에만 기록이 있어 내 PC 에서 읽을 수 없다.
- 위키 정리는 AI 가 하므로 사람이 가끔 훑어 바로잡아야 한다.
