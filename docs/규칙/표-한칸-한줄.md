## 표의 한 칸은 «한 줄»이다 — 자리가 넓으면 절대 두 줄로 만들지 않는다 (대표 지시 2026-08-30)

> 「한줄로 정리해라 빈공간이 많다 넓을경우 2줄로 절대 만들지마라
>  데이터 정보넣을때 줄의 공간이 넓으면 2줄로 만들지 마라」

거래내역 적요 아래에 **「0」만 적힌 둘째 줄**이 322줄 내내 붙어 있었다.
엑셀에서 딸려온 잔액인데 값이 없다 — **아무것도 안 알려 주면서 표 높이만 두 배로** 만들었다.
게다가 오른쪽에는 빈 자리가 넉넉한데 칸을 `maxWidth:140px` 로 조여 두고 세로로 쌓고 있었다.

| ✗ 이렇게 하지 말 것 | ✓ 이렇게 한다 |
|---|---|
| `h('div',null,memo), h('div',null,note)` | 한 `flex` 줄에 `span` 둘, `gap` 으로 띄운다 |
| 빈 값도 자리를 채워 그린다 | `erpNoteWorth(v)` 로 «말을 하는 값»만 그린다 |
| 좁은 칸 + 세로 쌓기 | 칸을 넓히고, 넘치면 `…` + `title` 에 전문 |
| 곁들이 표에 `marginTop` 으로 줄 내리기 | 같은 줄에 `inline-block` 으로 나란히 |

**왜 중요한가**: 한 줄만 두 줄이 되어도 **표 전체가 그만큼 길어진다.**
322줄짜리 표에서는 화면 한 장에 보이던 것이 반으로 줄고, 대표는 같은 것을 보려고 두 배로 스크롤한다.
「빈 값이라 어차피 안 보인다」가 아니다 — **안 보이는데 자리는 차지한다.**
