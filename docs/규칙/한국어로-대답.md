# 대답은 늘 한국어로 (대표 지시 2026-11-07)

Claude·Gemini·ChatGPT·Antigravity 가 영어로 대답하면 다시 「한국어로」를 쳐야 하고, 그만큼 토큰도 더 듭니다.
그래서 세 겹으로 막습니다.

## 1. 저장소 (자동 — 이 저장소를 여는 방 전부)

| 도구 | 읽는 파일 | 넣은 것 |
|---|---|---|
| Claude Code | `.claude/settings.json` · `CLAUDE.md` | `"language": "korean"` · 머리 한 줄 |
| Codex·Copilot | `AGENTS.md` | 머리 한 줄 |
| Gemini CLI·Antigravity | `GEMINI.md` | 한국어 줄 + 「규칙은 `AGENTS.md`」 |

- `GEMINI.md` 는 짧게 두고 규칙 본문은 `AGENTS.md` 를 가리킨다 — 같은 규칙을 세 번 쓰지 않는다.
- 최상위 `*.md` 는 배포에서 지워진다(`deploy-pages.yml`) — `GEMINI.md` 도 인터넷에 안 올라간다.
- 지킴: `tests/korean-everywhere.test.js`

## 2. 내 컴퓨터 개인설정 (한 번만 — 저장소 밖 폴더에서도 한국어)

저장소 폴더에서:

```
node scripts/korean-everywhere.js            ← 보기(아무것도 안 바꿈)
node scripts/korean-everywhere.js --apply    ← 실제로 바꿈
```

| 도구 | 바뀌는 파일 |
|---|---|
| Claude Code | `~/.claude/settings.json` 에 `"language": "korean"` (다른 설정은 그대로) |
| Gemini CLI·Antigravity | `~/.gemini/GEMINI.md` 끝에 「대답 언어」 단락 |
| Codex CLI | `~/.codex/AGENTS.md` 끝에 같은 단락 (`AGENTS.override.md` 가 있으면 그쪽) |

- 바뀌는 파일은 먼저 `파일.bak-날짜시각` 으로 남긴다. 여러 번 돌려도 같다.
- `settings.json` 이 깨져 있으면 덮어쓰지 않고 멈춘다(종료코드 2).
- 열려 있던 창은 다시 열어야 적용된다.
- ⚠ Antigravity 가 `~/.gemini/GEMINI.md` 를 전역 규칙으로 읽는다는 것은 Google 공식 문서가 아니라 사용 후기·해설 글로 확인한 것이다. 적용이 안 되면 Antigravity 의 Customizations → Rules → Global 에 아래 3번 글을 붙여 넣는다.

## 3. 앱·웹 (손으로 — 계정 설정이라 코드로 못 바꿈)

붙여 넣을 글:

```
항상 한국어로 대답해 주세요. 영어로 묻거나 영어 자료를 보여 줘도 설명·요약은 한국어로 해 주세요. 코드·명령어·고유명사 원문은 그대로 두어도 됩니다.
```

| 앱 | 넣는 자리 (메뉴 이름은 판마다 조금 다를 수 있음) |
|---|---|
| ChatGPT (웹·앱) | 프로필 → 설정 → 개인 맞춤 설정 → 맞춤형 지침 |
| Claude (claude.ai·앱) | 설정 → 일반(프로필) → 「Claude 가 응답할 때 고려해야 할 개인 선호 사항」 |
| Gemini (gemini.google.com·앱) | 설정 → 저장된 정보(나에 대한 정보) |
| Antigravity | Customizations → Rules → Global (2번이 안 먹을 때만) |

- 화면 글자(메뉴) 언어는 각 앱 설정의 「언어」에서 한국어로 고른다 — 대답 언어와는 따로다.
