# 컨설팅 12개 앱 — 화면 틀 하나 · 왼쪽 대시보드 공통

> 대표 지시(2026-11-28): 「상공회의소처럼 동시에 여러 가지, 같은 형태의 컨설팅인데 기관이 여러 개로 나뉘거나
> 비슷한 컨설팅을 몇 회 나눠 한 경우는 왼쪽 대시보드를 만들어 정리하고, 나머지는 다 일치하게.
> 기술보호컨설팅 고친 걸 기준으로 전체를 일치시켜라.」 · 「모든 앱 싹 다 똑같이 통일해서 깔끔하게」

대상: 기술보호 · 현장클리닉 · 상공회의소 · 기초인사노무 · 평가보상 · 공공기관 · 출산육아 · 사회적기업·씨앗 ·
6차산업 · 근로감독 · 민간노조 · 특화·위탁 (공용 엔진 `js/pu-consult-view.js` + 카탈로그 `js/pu-consult-catalogs-a/b.js`)

## 지킬 것
1. **HTML 틀은 하나다.** 12개 `*.html` 은 앱 이름·아이콘·키(제목·h1·h2·동기화 단추 설명·탭 이름·대시보드 이름·코치 주소·boot)만 다르다.
   한 앱만 고치지 말고 12개를 같이 고친다. 앱마다 다른 것은 **카탈로그 값**으로 낸다(HTML 을 갈라 치지 않는다).
2. **기술보호 기준(가벼운 화면)이 공통 기본이다** — 연도별 자료함 탭·트랙/상태/연도 선택칸·RAG 실무코치 단추·도구 메뉴 재스캔·«변경됨» 띠를 두지 않는다.
   연도는 연도 알약(또는 왼쪽 대시보드 연도 상자) 한 곳, 진행상태는 KPI 알약 한 곳. 끌 앱만 카탈로그에 `slimUi:false`.
3. **왼쪽 대시보드는 «자료»로 켠다** — 사업이 실제로 들어 있는 세부 트랙(기관·지역·갈래)이 둘 이상일 때만 켜지고, 하나면 접혀 한 단 화면(기술보호 모양)이 된다.
   `hasLeftDashboard:true` = 늘 켬(상공회의소·6차산업), `leftDash:false` = 늘 끔. 문구는 `leftDash:{ by:'기관' }` 또는 headLabel·allLabel·scopeAll.
4. **켜지면 같은 고르기를 두 군데 두지 않는다** — 위쪽 트랙 알약줄·연도 알약줄·KPI 앞 범위 칩을 숨기고, 한 트랙을 고른 동안은 줄마다 같은 트랙 칩도 걷는다.
   사업도 후보도 없는 트랙은 목록에 올리지 않는다(사람이 추가한 지역·지금 고른 트랙은 남김). 트랙마다 연도 칩을 또 늘어놓지 않는다(연도 상자 한 곳).
5. **목록 화면(사업 현황·미등록 후보)에서만 보인다** — 진행·체크·보고서 작업실은 넓게 쓴다. 미등록 후보 탭에서는 연도 상자를 숨긴다(후보 수신 연도 알약이 따로 있다).
6. **«새 지역 추가»는 `regionManageable:true` 앱만**(상공회의소).
7. **보고서 탭 일반 원고 접기는 `govReportForm:true` 앱만**(기관 서식이 컨설팅보고서에 있는 기술보호·현장클리닉·상공회의소). 기관 서식이 없는 앱은 원고가 곧 산출물이라 펴 둔다.
