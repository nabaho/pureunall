# 서류 · 목록 화면 기본 표준 형태 (`pu-harass` 규격)

> 대표 지시(2026-11-28): 직장 내 괴롭힘·성희롱 조사(`pu-harass.html`), 안전보건체계구축(`safety.html`), 일터상생혁신(`ilteo.html`), 산업일자리전환(`jobtrans.html`) 및 앞으로 추가·개선되는 모든 프로그램은 KPI·진행단계·검토 바를 **여러 줄이나 들쭉날쭉한 가변 폭 알약으로 만들지 않고, 반드시 1줄(단일 행) 동일 폭 균등 셀(일렬 통일)**로 정리한다.

## ① 상단 3단 슬림 구조 (1줄 균등 셀 원칙)
1. **상단 1줄 통합 KPI·트랙 스트립 카드 (`.card.hi-top-strip` / `.card.sf-top-strip` / `.kpis`)**:
   - **단일 1행 배치**: 트랙 줄과 KPI 줄을 2줄로 포개지 않고 **단 한 줄(`flex-wrap: nowrap; width: 100%`)**에 핵심 트랙·KPI 셀을 통합 배치한다.
   - **셀 크기 일렬 통일**: 모든 셀은 `flex: 1 1 0; min-width: 0; min-height: 32px` (또는 `grid-template-columns: repeat(N, minmax(0, 1fr))`)로 **가로 폭과 세로 높이를 완전히 동일하게 통일**하여 왼쪽 끝부터 오른쪽 끝까지 빈틈없이 정렬한다.
   - **셀 내부 1줄 구성**: 각 셀 안에서도 두 줄로 쌓지 않고 **좌측 항목명(`span`) · 우측 수치(`b`, `tabular-nums`)** 1줄 가로 배치(`justify-content: space-between`)로 표시하며, 클릭 시 즉시 필터링·토글(`.k-on`)된다.
   - **모바일(`<=768px`)**: `overflow-x: auto; flex-wrap: nowrap; min-height: 36px` 가로 스크롤 1줄 스트립으로 유지한다.
2. **독립 필터 카드 (`.card > .bar`)**:
   - 검색창 + 수행트랙/구분/상태/연도/담당 `<select>` + 조건 활성 시에만 보이는 **`↺ 초기화`** 버튼 + 우측 주요 액션(`+ 신규/새 사건`, 표준 빈 양식 버튼)
3. **목록 표 카드 (`.card > table.t`)**:
   - 각 열 머리글(`<th>`)에 열 단위 정렬·다중 체크 필터 팝오버(`.th-flt-btn`)를 지원하고, 결과 0건 시에도 `<thead>`를 유지한다.

## ② 목록 표 열 분리 · 수직 정렬 원칙
- **기업명·사건명 칸(`td.ti`) 옆에 연도나 진행상태 배지를 무분별하게 줄바꿈으로 쌓지 않는다.**
- 각 속성은 **독립 열**로 세워 세로줄이 일직선으로 정렬되게 한다:
  `☐` · `번호` · `연도/사업장명(td.ti)` · `진행상태/수행구분(badge — 완료 .c-direct / 진행중 .c-direct-ing)` · `진행현황(.pbar 점 뭉치 + 핵심 수치)` · `메일·자료(📧 N · 🗂️ N 배지)` · `주요 수행 이력/연동` · `열기(data-k="act")`
- 완료·직접보고 행은 `tr.perf-direct` 왼쪽 초록 포인트 띠(`inset 3px 0 0 var(--green-m)`)로 구분한다.
- 모바일(`<=768px`)에서는 Row 1(`☐ № 사업장명 · 연도 · 진행상태`), Row 2(`업종·트랙 · 진행현황 · 메일·자료 · 열기 버튼`) 2줄 카드로 전환한다.

## ③ 서류 · 진행 · 보고서 검토 작업실 구성 (검토 바 1줄 균등 셀 통일)
- **1줄 작업 전환 바 (`.bar`)**: 대상 선택 `<select>` + 진행상태 배지(`.c-direct` / `.c-direct-ing`) + 구분 칩 + 우측 포털 링크(`ERP`·`기업정보함`) 및 설정 버튼.
- **1줄 균등 단계·검토 리본 (`.ws-steps`, `.tpl-pills`, `.pill-row.uniform-row`, `.rv-subtabs`)**: 부가 설명 줄(`<span>`)을 세로로 쌓지 않고(`title` 툴팁으로 이동), 모든 단계·검토 탭 셀을 **1줄 동일 폭·동일 높이(`min-height: 32px`)**로 일렬 정렬한다.
- **보조 안내 접기 (`<details class="sub-fold">`)**: 규모별 의무·세부 참조 안내는 기본 접힘으로 두어 세로 공간을 아낀다.
- **좌우 2단 작업실 (`.ws-split`)** 및 상단 헤더 커밋 표식(`#releaseShaChip` / `meta[name="pu-release"]`).
