# 서류 · 목록 화면 기본 표준 형태 (`pu-harass` 규격)

> 대표 지시(2026-11-28): 앞으로 서류·사업장·사건 목록을 정리하거나 새 화면·개선을 만들 때는 기본적으로 **직장 내 괴롭힘·성희롱 조사(`pu-harass.html` / `js/pu-harass-view.js`)** 형태를 표준으로 유지한다.

## ① 상단 3단 슬림 구조
1. **상단 통합 스트립 카드 (`.card.hi-top-strip` / `.card.sf-top-strip`)**:
   - 1행: 수행 트랙 알약 바(`.scope-bar`, `.scope-btn` + `.on` / `.ok`)
   - 2행: 클릭형 초소형 1줄 인라인 KPI 배지(`.kpis > .kpi` — `flex-direction: row`, 굵은 수치 + 짧은 라벨, 클릭 시 즉시 필터링·토글 및 `.k-on` 강조)
2. **독립 필터 카드 (`.card > .bar`)**:
   - 검색창 + 구분/상태/연도/담당 select + 조건 활성 시에만 보이는 **`↺ 초기화`** 버튼 + 우측 주요 액션(`+ 신규/새 사건`, 표준 빈 양식 버튼)
3. **목록 표 카드 (`.card > table.t`)**:
   - 상단 중복 제목/배너 카드 생략(또는 간결 유지), 바로 깔끔한 정렬 표 배치.

## ② 목록 표 열 분리 · 수직 정렬 원칙
- **기업명·사건명 칸(`td.ti`) 옆에 연도나 진행상태 배지를 이어 붙여 들쭉날쭉하게 만들지 않는다.**
- 각 속성은 **독립 열**로 세워 세로줄이 일직선으로 정렬되게 한다:
  `☐` · `번호` · **`연도(td.yr)`** · **`사업장명/사건명(td.ti)`** · **`진행상태(td.st — 수행완료 .c-direct / 진행중 .c-direct-ing)`** · `업종·트랙/유형(badge)` · `진행현황(.pbar 점 뭉치 + 핵심 수치)` · `메일·자료(📧 N · 🗂️ N 배지)` · `주요 수행 이력/연동(td.wide)` · `열기(data-k="act")`
- 완료·직접보고 행은 `tr.perf-direct` 왼쪽 초록 포인트 띠(`inset 3px 0 0 var(--green-m)`)로 구분한다.
- 모바일(`<=768px`)에서는 Row 1(`☐ № 사업장명 · 연도 · 진행상태`), Row 2(`업종·트랙 · 진행현황 · 메일·자료 · 메모 · 열기 버튼`) 2줄 카드로 전환한다.

## ③ 서류 · 진행 · 보고서 작업실 구성
- **1줄 작업 전환 바 (`.bar`)**: 대상 선택 `<select>` + 진행상태 배지(`.c-direct` / `.c-direct-ing`) + 구분 칩 + 우측 포털 링크(`ERP`·`기업정보함`) 및 설정 버튼.
- **1줄 단계 리본 (`.ws-steps`)**: 설명 문구를 뺀 1줄 클릭형 진행 단계 버튼(`1. ~ N.`).
- **보조 안내 접기 (`<details class="sub-fold">`)**: 규모별 의무·참조 안내는 기본 접힘으로 두어 세로 공간을 아낀다.
- **좌우 2단 작업실 (`.ws-split`)** 및 상단 헤더 커밋 표식(`#releaseShaChip` / `meta[name="pu-release"]`).
