# 공용 상태 파일 STATUS.md

> CLAUDE.md 에서 글자 그대로 옮긴 원문이다(2026-11-07, 토큰 아껴 쓰기).
> 지킬 것의 핵심은 CLAUDE.md 에 있고, 여기는 그 까닭·사례·명령 설명이다. 둘이 어긋나면 CLAUDE.md 가 이긴다.

## 어느 방이든 — 공용 상태 파일 `STATUS.md`
이 저장소는 **여러 방(세션)이 동시에** 고친다 — 2026-09-03 실측으로 작업트리 20개,
사흘간 합쳐진 PR 139건. AI 개인 메모리는 계정마다 다르므로 **공용 상태 파일이 유일한 기준**이다.

- **시작할 때**: 저장소 뿌리의 `STATUS.md` 를 읽고, `gh pr list --state open` 으로 지금 열린 것을 본다.
- **끝낼 때**: 손댄 앱의 줄과 「남은 일」을 고쳐 **같은 PR 에 함께** 넣는다.
  따로 커밋하면 다음 사람이 옛 줄을 읽는다.
- ⚠★ **손댄 기록은 `status/` 에 «새 파일 하나»로 적는다** — `status/날짜-가지이름.md`
  (2026-09-07 부터). `STATUS.md` 안의 표에 덧붙이지 **말 것.**
  까닭: 여러 방이 같은 끝줄에 덧붙이다 **부딪혔다** — PR #1087 은 3줄 덧붙였을 뿐인데
  막혔고, 최근 STATUS.md 커밋 29개 가운데 **14개**가 그 표를 만졌다.
  이름이 겹치지 않으므로 두 방이 같은 순간에 끝내도 부딪힐 수가 없다.
  한 화면으로 몰아 보려면 `node scripts/status-log.js`.
  ⚠ 「2. 지금 손이 필요한 것」 은 **그대로 STATUS.md 에 고친다** — 거기서 부딪히는 것은
    «뜻이 있는» 부딪힘이라 사람이 봐야 한다. 자동으로 합치면 어긋난 안내가 조용히 남는다.
- ⚠ **가지 목록으로 「남은 일」을 세지 말 것.** 쥐어짜 합치기(squash) 때문에 이미 합쳐진
  가지도 `--no-merged` 에 그대로 뜬다 — 34개로 보였으나 실제로 남은 것은 둘이었다.
  남은 일은 **열린 PR** 과 **PR 이 한 번도 없던 가지**로 본다.
- `STATUS.md` 의 「되풀이된 실수」 절은 **새 방이 코드를 만지기 전에** 읽는다.
  한 장씩 저장하기 · 헛도는 검사 · 이름으로 회사 맞추기 등, 이 저장소가 여러 번 밟은 자리다.

앱별로 더 자세한 기록부가 있는 곳: `fund-erp/STATUS.md`(기금) · `payroll-STATUS.md`(급여관리) ·
`work-STATUS.md`(업무관리). 뿌리 `STATUS.md` 는 그것들을 가리키는 «한 장짜리 지도»다.
