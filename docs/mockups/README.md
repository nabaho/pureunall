# 목업은 지웠습니다 (2026-09-18)

이 폴더에는 「이렇게 만들까요」를 보여 드리던 목업 **317장**이 있었습니다. 전부 지웠습니다.

## 왜 지웠나

목업은 대부분 **살아 있는 화면을 그대로 떠서** 만들었습니다. 그래서 공개 저장소에
이런 것들이 그대로 들어와 있었습니다.

- 부당해고·산업재해·임금체불 **사건 당사자의 실명**과 사건번호
- 뉴스레터 **받는 분들의 실명 명단**
- 의뢰인 회사 이름 · 대표자 이름 · 사업자등록번호 · 전화 · 이메일

이름을 한 장씩 갈아 끼우는 길도 있었지만, 317장에서 **반드시 몇 개를 빠뜨립니다.**
빠뜨린 한 줄이 사건 당사자의 이름이면 그것으로 끝입니다.

## 잃은 것과 안 잃은 것

- **안 잃은 것**: 무엇을 왜 그렇게 만들기로 했는지는 `status/` 의 기록과
  검사 파일의 머리 주석에 글로 남아 있습니다. 목업은 그 결론에 이르는 그림이었을 뿐입니다.
- **잃은 것**: 옛 검사·기록의 주석에 적힌 `docs/mockups/….html` 경로는 이제 빈 자리를
  가리킵니다. 그 파일들은 배포본에도 안 올라가서 주소로는 원래 안 열렸습니다.
