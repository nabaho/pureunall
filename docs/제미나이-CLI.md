# 제미나이 CLI — 구독(Ultra)으로 코딩에 쓰기 (2026-11-18)

> 대표 지시 「제미나이 연결 가능하게」 — 안티그래비티 토큰이 떨어졌을 때 월 구독 범위에서 제미나이로 코딩.

- 까는 법: 대표 PC 에서 `tools\gemini-cli\install-gemini-cli.bat` 를 두 번 누른다.
  Node.js 가 없으면 winget 으로 깔고 → 공식 패키지 `@google/gemini-cli` 를 깔고 → pureunall 폴더에서 `gemini` 를 연다.
- 첫 실행의 로그인은 사람이: **「Login with Google」** → Ultra 구독 계정. ⚠ 「Use Gemini API key」는 고르지 않는다(건당 요금).
- pureunall 폴더에서 열면 `GEMINI.md` → `AGENTS.md`(푸른 규칙)를 읽는다. main 직접 금지 · 새 가지 → 검사 → PR.
- 다음부터는 명령창에서 pureunall 폴더로 가 `gemini` 만 치면 된다. 푸른 AI 라우터(docs/푸른AI-라우터.md)의 코딩명령창에서도 「Gemini CLI」로 고를 수 있다.
- ⚠ 고객 주민번호·임금대장은 넣지 않는다(구글 서버로 간다).
