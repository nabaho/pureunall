# 메인 화면 뒤 카카오 화면 재등장 — 인증 URL·세션 복원 경쟁 (2026-10-22)

- 제보: 아무 조작이 없어도 메인 화면이 잠깐 보인 뒤 포털 로그인 화면과 카카오 계정 화면이 번갈아 나타남.
- 코드에서 재현한 경로: 노란 단추를 누르면 카카오 인증 URL을 비동기로 받아 온다. 그 응답을 기다리는 동안 기존 Firebase 세션 복원이 끝나면 `onAuthStateChanged`가 포털 메인을 먼저 그렸다. 뒤늦게 카카오 URL이 오면 `PuKakao.goLogin`이 카카오 계정 화면으로 이동한다. 한 번 누른 요청의 결과가 메인 표시 뒤에 실행될 수 있어, 두 번째 조작이 없어도 재진입처럼 보인다. 실제 휴대전화에서 이 경로가 몇 번 일어났는지는 기기 기록이 없어 확정하지 않는다.
- 수정: 카카오 인증 URL 요청 중에는 인증 상태 알림이 들어와도 메인을 먼저 그리지 않는다. 같은 단추의 중복 요청도 막는다. URL 요청이 실패했는데 저장된 로그인이 복원돼 있다면 포털을 연다. 카카오 복귀·직원 권한 검사는 그대로 유지한다.
- 검증: URL 요청을 미뤄 둔 상태에서 Firebase 사용자를 먼저 복원하는 실행 검사, 중복 요청 방지, URL 요청 실패 뒤 포털 복귀 검사. 전체 `tests/*.test.js` 2,195개 파일 및 캐시·공백 검사 통과. 실제 휴대전화 실행 방식(홈 화면 아이콘·일반 브라우저·카카오톡 내부)과 화면 녹화 답변을 기다린다.
