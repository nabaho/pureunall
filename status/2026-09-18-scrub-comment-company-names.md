## ★★★ 짧은 이름은 «표와 함께»만 바꾼다

두 글자 이름을 맨 글자로 바꾸면 **보통 말이 깨진다.**

```
「대성」  → 「(유)대성」·「주식회사 대성」 만 바꾼다
「가야」  → 「㈜가야」 만  (「가야 할」·「가야지」 는 그대로)
「수성」  → 「(주)수성」 만  (「감수성」·「대구 수성구」 는 그대로)
「에이」  → 안 바꾼다      (「에이전트」 가 깨진다)
「천성」  → 「천성가축약품」·「「천성」」 처럼 따옴표와 함께만
```

## ⚠⚠ 이번에 밟은 것 — 검사 28개가 깨졌다

이름을 바꾸면 **검사가 조용히 뜻을 잃거나 그 자리에서 깨진다.** 밟은 꼴 여섯:

1. **사이가 벌어진 꼴** — `'  경보 엔지니어링 '` · `'성 진 테 크'` · `'㈜ 유원 에프앤비'` ·
   `'㈜ 대한 정밀'`. 붙여 쓴 것만 찾으면 **입력은 그대로인데 기대값만 바뀐다.**
2. **정규식 속 꼴** — `/\(주\)이비/` 는 괄호가 `\(` 라 글자 찾기로 안 잡힌다.
3. **이름의 «일부»를 치는 검사** — `q:'화담'` · `filt(…,'맥스')` · `'  노리  '` ·
   `colQuery:'화담'`. 이름을 바꾸면 그 «일부»도 함께 바꿔야 한다.
4. ★★ **가짜끼리 부딪힘** — 「이비」를 「다온비」로 바꿨더니 이미 있던 「다온원」과
   앞 두 글자가 같아져, `q:'다온'` 이 **두 곳을 물었다.** 「벼리비」로 바꿨다.
   같은 일이 「롯데리아 → 가나리아」와 「충남사회서비스원 → 가나사회서비스원」에서도 났다
   (닮은 이름 판정이 둘을 같은 곳으로 봤다). **가짜 이름도 서로 달라야 한다.**
5. **이름 길이가 잣대인 곳** — `_koOnly('마바F3')` 가 두 글자라 `MLK_MIN_MATCH` 에 못 미쳐
   제안이 아예 안 떴다. 한글 세 글자를 지키되 「가나다라마바사」가 든 검사를 피해 지었다.
6. **글자 차례(정렬)** — `'두번째급여,다온원'` 이 `'다온원,두번째급여'` 로 바뀐다.
   사람 이름을 바꾸면 «누가 먼저 나오나»를 보는 검사도 함께 본다
   (`'강'` 으로 찾는 검사가 있어 「강태민 → 강벼리」로 성을 지켰다).
