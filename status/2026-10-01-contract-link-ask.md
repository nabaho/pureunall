# 계약 저장 — 업체 연결을 «그 자리에서» 묻는다 (되돌아가는 문제)

- 대표 지시 2026-10-01 「온톨로지 방식 때문에 계속 오류… 직원이 체크를 어떻게 해야 하는지 판단이 안 되어 계속 되돌아간다」 → 「진행」.
- ★ 뿌리: 계약 «창»의 저장 길이 업체 검증(erpValidateContractCompany)을 먼저 했다. 「연결 보류로 저장」을 묻는 곳(erpAskDeferCompanyLink, 09-14 김보람 건의)은 목록 쪽 save 에 있어 창에서는 한 번도 닿지 않았다 → 토스트 한 줄 + 기업정보 탭으로 튕김.
- erpAskCompanyLink(창의 검증 «앞»):
  - 업체를 못 고름 → 지금까지의 물음(연결 보류로 저장 / 업체 고르기).
  - 이름만 다름(업체는 사람이 고름, 사업자번호 안 어긋남) → 「고른 업체 이름으로 맞추기」 / 「업체 다시 고르기」.
  - 사업자번호 다름·업체 둘로 걸림·없는 업체·보류+업체 → 무엇이 어긋났고 무엇을 하면 되는지 창으로. ⚠ 보류로 덮지 않는다(contract-defer-company-link ②).
- 검증 함수는 그대로 막는다(이관·재검사가 같은 문).
- 검사: tests/contract-link-ask.test.js(실제 pu-ontology.js 로 돌림, 창의 묻기를 빼면 실패 확인) · ontology-company-write 상자에 popConfirm.
- ⚠ 실제 화면으로는 못 봤다.
