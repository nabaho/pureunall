# 2026-10-19 · 폰 메일 읽기 화면 «깔끔하게»

대표 지시(폰 캡처 둘, 첫 수정 #2680 배포 뒤): 「메일 화면 깔끔하게」

## 캡처에서 거슬린 것 → 고침 (`pu-cards.html` 의 `.dmr` 규칙)
| # | 거슬린 것 | 고침 |
|---|---|---|
| ① | 붙는 맨 위가 «두 줄»(오가는 길 + 답장·전달…)이라 내릴수록 화면 1/9 이 막힘 | 붙는 것은 «오가는 길 한 줄»(‹ 목록 · ▲ · ▼ · 🖨)뿐. 답장·전달 줄은 본문과 함께 올라감 (`.rtop` 을 `display:contents` 로 풀어 `.rgt` 만 sticky) |
| ② | 첨부 단추 넷이 좁은 칸에 눌려 「미 리 보 기」처럼 글자가 세로로 쌓임 | 첨부 = 카드 한 장 — 위에 파일 이름 통째, 아래에 단추(가로, 넘치면 다음 줄, 줄바꿈 금지) |
| ③ | 떠다니는 🏠·즐겨찾기·백업·「새 버전」이 본문 글자를 덮음 | 읽는 동안만 비킴(`body:has(.dmr)`), 목록으로 나가면 도로 나옴 |
| ④ | 「열어봄」 줄 끝에 「다」 한 글자만 남음 | 딱지와 안내 «문장 통째»가 줄을 바꿈 |
| ⑤ | 답장·삭제 줄이 옆으로 밀리는데 «더 있다»는 표시가 없음 | 오른쪽 끝을 흐리게(마지막 단추는 끝까지 밀면 흐림 밖으로) |
| ⑥ | 제목·본문 좌우 여백이 어긋남 | 제목 17px/줄간격 1.4, 본문 좌우 여백 0 |

PC 읽기 화면은 안 건드림(`.dmr` 는 폰 전용 덮개 안에서만).

## 검사
- `tests/mail-door-stays-in-mail.test.js` — 붙는 줄 규칙을 새 구조(`.rgt` 만 sticky · `.lft` 는 안 붙음 · 순서)로 되겨누고, 첨부 카드 · 떠다니는 것 비키기 규칙을 추가. 전체 묶음 통과.
- 화면: 실제 `mbReadHtml()` 마크업(검사용 대역으로 얻음)에 실제 CSS 를 375px 틀에 얹어 전/후 같은 장면 비교(스크롤 전·후).

## 남은 일 / 모르는 것
- 진짜 로그인·메일로 폰에서 눌러 본 것은 아님. 배포 뒤 폰 확인 필요.
- 답장·삭제 줄(`.lft`)의 단추가 많아(10개 안팎) 옆으로 밀어야 보인다 — 흐림으로 알릴 뿐 «더보기 ⋯» 로 접지는 않았다. 접을지는 대표 결정.
