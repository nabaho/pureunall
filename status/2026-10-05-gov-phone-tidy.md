# 2026-10-05 정부컨설팅 일정관리 — 폰 화면 정리

대표 지시: 「폰화면에 정부컨설팅일정 너무정리가 안된다 깔끔하게 불필요한부분은 정리하고 볼수 있게 목업해달라」 → 목업 승인 「이대로 고쳐라」

- 머리 3줄 → 1줄(앱 이름·저장 점·🔔·⋯·이름 첫 글자) + 탭 한 줄.
- 🔑 비밀번호·로그아웃·📊 통계·⚙️ 환경설정·💾 백업·복구(관리자)·🔄 최신 확인·⭐ 즐겨찾기·🏠 포털 → ⋯ 펼침 메뉴.
  ⋯ 줄은 원래 단추를 «눌러 준다»(mMenu) — 같은 일을 두 벌 만들지 않았다.
- 사업장 목록 → 맨 아래 손잡이(📋 사업장 N곳 · 마감·주의 N) → 올라오는 판(z 420, 창 .mb 500 아래). 폰에서는 늘 접힌 채 시작.
- 고르는 칸 한 줄(월·주·일 + 담당 + 사업). 연도 칸은 숨기고 「2026년 10월」 글자를 누르면 연도 고르개.
- 요약 4칸은 한 줄 딱지. 떠 있던 백업·복구·새로보기·🏠·즐겨찾기 손잡이는 폰에서 숨김. 오른쪽 아래 ＋ = 사업장 추가.
- PC(769px~)는 그대로 — 브라우저로 1280px 에서 로그아웃·통계·목록 자리 확인.
- 검사: `tests/gov-phone-tidy.test.js`(돌연변이 6개 모두 잡힘). `tests/mobile-top-compact.test.js` 는 ⋯ 묶음 끝을 span 을 세어 찾도록 고침
  (소제목 span 이 들어오자 첫 </span> 에서 멈췄다) + 폰 로그아웃이 ⋯ 안에 있는지 확인.
- 남은 일: 로그인한 실제 폰에서 사업장이 많을 때(24곳) 판 높이·손잡이 딱지를 대표가 확인.
