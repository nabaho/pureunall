# 2026-11-16 — 계약서·견적서 원스톱 자동 정리·작성 & 쉬운 양식 만들기 (`docs-esign.html` · `pu-contract-easy.js` · `pu-contract-forms.js`)

## 배경 및 대표 지시
- **문제점**: 계약서등관리(`docs-esign.html`)에 6개 분류·80여 종 양식·27개 하위 세트가 나뉘어 있어, 담당자가 모든 분류와 양식을 일일이 클릭해 찾아야 했고(왼쪽 메뉴도 전 분류 세트가 동시에 펼쳐져 38줄로 과밀), 새 계약서 양식을 만들 때도 기존 문서의 회사명·날짜·금액을 수작업으로 지우고 `{{변수}}`를 외워 넣어야 했음.
- **대표 지시 (2026-11-16)**: *"계약서 관리에서 사람이 모든 계약서를 클릭해서 찾아야 한다 이건 너무 찾기 어렵다 이부분 어떻게 자동화하고 쉽게 담당자가 계약서 양식을 만들 수 있는지 한번 검토해달라 최대한 쉽게 한번에 내용을 모두 정리해서 넣을 수 있게 해야 한다. 모든 양식을 찾는 건 너무 힘들다 최대한 한번에 정리할 수 있게 만들어라"*

## 검토 결론 및 구현 내용
1. **`⚡ 한 번에 서류 만들기` — 양식 찾을 필요 없는 원스톱 자동 정리·추천 (`js/pu-contract-easy.js`, `js/pu-contract-forms.js`)**:
   - 상단 빠른 실행 막대(`.pcf-qbar`)에 한 줄 입력창과 `⚡ 한 번에 서류 만들기` 단추 배치.
   - 카톡·메일·메모 한 줄(예: `(주)가나상사 직장내괴롭힘 조사 35명 2026-11-20~2026-12-31 440만원 부가세별도`)만 붙여넣거나 22종 대표 업무 카드 하나만 누르면 **맞는 견적서 + 계약서 + 위임장·부속서류 묶음이 자동 체크**되고(`전체` / `견적서만` / `계약서·위임장만` 원클릭 전환), 금액(`1000만원`·`1,000만원`·`1천5백만원`·`55만5천원`·`5천원` 등 한글 금액 자동 변환, 별도 추출된 착수금 보존)·부가세·기간·인원·의뢰처(이알피·기업정보함 대표자·사업자번호·주소 자동 연동)가 **한 화면 통합 입력표**에 한 번에 정리되어 바로 채우기·내려받기·인쇄·메일 발송으로 이어짐.
   - 미입력 금액·기간은 0원이나 임의 기본값으로 채우지 않고 비워 두어 서식 밑줄이 그대로 살아남도록 규칙 준수.
2. **`✨ 쉽게 새 양식 만들기` — 자동 `{{변수}}` 변환 & 10초 표준 조항 조립 마법사 (`js/pu-contract-easy.js`)**:
   - **파일·문안 자동 양식화**: 쓰던 `.hwpx/.hwp/.docx/.pdf` 파일이나 기존 문안을 넣으면 사업자번호(푸른노무법인 고유 번호 보존), 주민번호(하이픈 유무·연속 나열 불문 비소비 전방탐색으로 13자리 전원 자동 가림), 계약기간, 작성일, 금액, 지정한 예전 회사명·대표자·근로자명을 원클릭으로 표준 `{{변수}}`로 일괄 변환. 개인정보 보호를 위해 파일 선택 시에는 브라우저 메모리 안에서 본문만 추출하고 서버 업로드를 수행하지 않으며, 사용자가 `빈 공용 서식 원본 파일임 확인`에 명시적으로 체크하고 저장할 때만 원본을 첨부·보관하도록 안전장치 적용. 기존 양식 수정 창(`openModal`)에도 `🪄 날짜·금액·사업자번호 → {{변수}} 자동 변환` 단추 추가.
   - **조항 체크 10초 조립**: 파일이 없어도 문서 기본 틀(`위탁·자문계약서` / `견적서` / `사건 위임약정서` / `변경합의서`)과 조항 체크박스(`과업범위`, `보수·부가세`, `성공보수`, `연 12%의 이자`, `1년 자동연장`, `비밀유지`, `공인노무사 명단 연동` 등)만 고르면 완성된 표준 양식을 자동 조립하고, 상위 분류 및 동종 하위 세트까지 자동 추천하여 한 번에 트랜잭션(`changeForms` + `changeSets`) 등록.
3. **전 분류 통합 검색 & 왼쪽 사이드바 자동 정리 (`js/pu-contract-forms.js`)**:
   - 어느 분류를 보고 있든 `전체 양식·세트 한 번에 찾기` 검색창에 단어를 치면 **6개 분류 전체 양식과 27개 하위 세트**를 동시에 찾아 상단에 관련 동종 세트 바로가기와 전 분류 일치 양식을 즉시 표시.
   - 왼쪽 사이드바는 현재 보고 있는 활성 분류 1곳만 하위 세트를 자동 펼치고 나머지 분류는 깔끔하게 접어 두어(38줄 → 18줄) 하단 메뉴(`보낸 견적서 관리` · `확정 계약서 관리` · `원본 보관함`)가 한 화면에 모두 보이도록 개선.
