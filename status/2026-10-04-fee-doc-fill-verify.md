# 경력관리 — 회의·비용관리 서류 만들기 마무리 확인 (2026-10-04)

- #1854 로 이미 합쳐진 것(서류 만들기·저장 서류·내 계좌·동의 □ 자동)을 화면에서 눌러 확인:
  회의·비용관리 › 서류 만들기 → 이력서 화면을 빌려 쓰고 담을 곳이 「비용 서류」, 탭은 기관 양식 채우기만.
  저장 서류 → 비용 서류 탭만. 이력서관리 › 서류 보관함 → 비용 서류 탭 숨김, 서류 만들기 → 이력서로 되돌아감.
- 고장 넣기 8가지 중 «마케팅 동의 거르기»를 검사가 못 잡았다 — 시험 문장이 애매해 다른 규칙에 먼저 걸렸다.
  뒷말 꼴 문장(「□ 마케팅 정보 수신에 동의함 □ 동의하지 않음」)을 더해 이제 잡는다.
