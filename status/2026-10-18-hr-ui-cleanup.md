- 재는 도구: `node tools/phone-audit/run.mjs hr` (360·411px) · PC 1366px 전후 갈무리 견줌.

## 무엇이 문제였나 (실측)
- 본문 상자(`main`) 24px + 흰 판(`.page`) 10px 이 겹쳐 폰 양옆이 **34px 씩** 비어 있었다(411px 화면의 1/6).
- 급여관리 사람 카드가 이름 줄 + 색 상자 셋이라 **한 사람 95px**, 첫 화면에 넷.
- 근로자명부는 숫자 칩 줄과 상태 탭 줄이 «같은 일»(재직·휴직·퇴직 거르기)을 두 줄에서 했다.
- 숨어 있던 흠: 폭이 넓어지자 급여관리 「🛠 도구 · ✅ 확정」이 **화면 밖으로** 밀렸다(묶음의 flex 바탕이 0 이라
  앞 줄 틈에 0px 로 끼어 앉음). 휴가관리 머리 둘째 줄 「⚠️ 재산정 미완료」가 판 밖에서 잘렸다.

## 고친 것 — 모두 폰(≤768px) 구간, 인사관리 창(`?app=hr`)에만
| 화면 | 전 → 후 |
|---|---|
| 공통 | `<head>` 첫 스크립트가 `html.pu-app-hr` 표식 → `main` 양옆 0 · 흰 판 끝까지 · 안쪽 12px(태블릿 641~768 은 24px — 손잡이가 25px) |
| 급여관리 | 지급 안내 두 줄 → 한 줄(설명은 title) · 숫자칸 두 줄 상자 → 한 줄 칩 · 사람 카드 95px → **두 줄 카드 약 50px**(1줄 번호·이름·직책·**실지급**, 2줄 지급·공제·상태) · 도구 묶음 flex 바탕 «제 폭» |
| 근로자명부 | 숫자 칩 줄 + 상태 탭 줄 → **한 줄**(탭에 숫자를 얹음) · 역할 칩은 다시 누르면 풀림(「전체」 칩 뺌) · 입사예정·계약 만료 상자 여백·날짜(월-일) 줄임 |
| 휴가관리 | 연차 표가 폭의 3/4 만 쓰던 것(폰 공통 `.page table{display:block}`) → 폭을 채움 · 머리 오른쪽 묶음 낱개로 꺾음 |

| 근태관리 | 달력의 테두리 상자 한 겹 걷음 · 칸 안 표시 「🏖…」 → 그림만 또렷이(전문은 title) |
| 증명서 | 이름표 위·칸 아래 두 줄 → 이름표를 칸 왼쪽에(한 칸 = 한 줄) · 테두리 상자 걷음 |
