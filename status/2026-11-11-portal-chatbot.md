# 2026-11-11 — 푸른포털 시스템 길잡이 채팅방 & 연결도 지도 (`enter.html` `#chatFab` · `js/pu-chatbot-kb.js` · `js/pu-chatbot.js`)

## 요청 및 결정 사항
- 포털(`enter.html`) 첫 화면에서 내부 직원이 **`의뢰인 업무` · `자료함` · `영업관리` · `내부관리` 4대 영역을 어떻게 사용하는지**와 **앱 간 데이터 연결도(온톨로지)**를 상호 질문(티키타카)으로 아주 쉽게 한눈에 이해할 수 있는 **시스템 길잡이 채팅방** 구축 (+ 노동법·정부지원금·근로복지기금 법령/유권해석 통합 AI 질의응답 및 `fund.html` 전문 챗봇 딥링크 연동).
- 위치 및 형태: 포털 상단 머리줄(`.pbar`)의 `💬 건의하기`(`#sgFab`) 바로 왼쪽에 파란 `🤖 길잡이 챗봇`(`#chatFab`) 단추를 두고, 클릭 시 드래그 이동형 플로팅 채팅방(`#puChatWin`)으로 열기.

## 주요 구현 내용
1. **실무 연결도 지도 · 4대 영역 입출력 사전 · 멀티턴 RAG 엔진 (`js/pu-chatbot-kb.js`)**:
   - `js/pu-ontology.js`의 실제 데이터 주인·읽기 계약을 그대로 반영한 **6대 실무 연결도(`PORTAL_FLOWS`)**(`핵심 기본 흐름`, `계약·수임·입금`, `정부컨설팅 5단계`, `고객사 지원금 매칭`, `기금·규정·문서`, `영업관리·홍보·인사`)와 **4대 영역 24개 앱 입출력표(`PORTAL_ROWS_GUIDE`)**(`언제 쓰나` / `← 받아오는 곳` / `→ 이어지는 곳`) 수록.
   - `system`(4대 영역 가이드, 온톨로지 3대 연결 원리, 신규 거래처 수임 1~5단계 순서, 24개 개별 앱 사용법·연결도), `labor`(연차, 주52시간·가산수당, 2024.12 전원합의체 통상임금, 퇴직급여, 해고·구제신청, 기간제, 직장 내 괴롭힘, 모성보호, 취업규칙, 최저임금, 산재), `govaid`(주요 고용장려금·컨설팅), `fund`(`fund_kb.js` 전체 유권해석 자동 병합) 수록.
   - **멀티턴 대화 기억 & 개인정보 이중 마스킹**: 현재 질문뿐 아니라 직전 대화 맥락(`opts.history` 최대 3턴)까지 `maskPersonal()`을 통과시켜 지시어 꼬리질문(`"그럼 거기서 초안 수정은?"`)을 자연스럽게 이어 가면서도 개인·기업 식별정보와 프롬프트 펜스(`<<< >>>`)를 완벽히 차단.
   - `parseReply()`: 환각 인용 ID · 환각 연결도 ID(`flowId`) · 권한 밖 앱 키(빈 배열 `[]` 포함) 자동 제거 및 후속 꼬리질문(`followUps`) 정제.
2. **한눈에 이해되는 상호 질문 채팅방 UI (`js/pu-chatbot.js`)**:
   - **대화 말풍선 내 시각적 화살표 연결도 카드(`.puc-flow`)**: 답변과 관련된 실무 흐름을 `[📷 사진첩·카메라] ➔ [📇 기업정보함] ➔ [🏢 푸른이알피] ➔ [📋 업무관리 ↔ 메일]` 형태의 클릭형 상자로 함께 보여주어, 어느 단계든 누르면 즉시 그 앱의 연결 방식을 이어서 설명.
   - **꼬리질문 티키타카(`💡 이어서 물어보기`, `.puc-fups`)**: 매 답변 아래 2~3개의 추천 후속 질문 단추를 제시해 직원이 무엇을 물어볼지 고민하지 않고 클릭만으로 깊이 파고들 수 있도록 구성.
   - **상단 `[🔗 연결도]` 전용 탭 (`mode: 'map'`)**: 포털 3대 연결 원칙(원본 주인 `푸른이알피` · `사업자번호/고유번호 몸통` 연결 · `원본 무변경`)과 6대 흐름도, 4대 영역 24개 앱 입출력표를 한 화면에서 열람하고 바로 질문하거나 권한 범위 내에서 앱을 열 수 있도록 제공.
   - 첫 화면에 **한 줄 핵심 흐름 요약 + 4대 영역 원클릭 카드 + 전체 연결도 배너 + 신입 필독 시나리오** 배치, 푸른 27색 팔레트·모바일 `16px` 입력 확대 방지·`resetOnLogout()`(`STATE.epoch` 증가) 준수.
3. **포털(`enter.html`) 및 기금관리(`fund.html`) 연동**:
   - `enter.html`: `.pbar` 내 `#sgFab` 왼쪽 `#chatFab`(`🤖 길잡이 챗봇`, 380px 이하 아이콘 축소), `window.portalLaunchApp` 권한·준비중·PC전용 검증 실행, 로그아웃 초기화 연동.
   - `fund.html`: `?chat=1` 진입 시 `openFundChat()` 자동 실행 후 주소창 파라미터 정리.
