파이어베이스 함수는 **로그인된 자리에서만** 올라간다(CLAUDE.md 도 「firebase CLI 는 이 PC 에

## 그래서 한 줄로 만들었다

```
node scripts/nas-backup-deploy.js            ← 무엇을 할지 «보여만» 준다
node scripts/nas-backup-deploy.js --deploy   ← 실제로 올린다
```

손으로 할 일이 셋이었다(열쇠 만들기 · 서버에 넣기 · 함수 올리기). 셋 다 여기서 한다.
`scripts/rules-deploy.js` 와 같은 자리·같은 결이다.

## 못 박은 규칙 (검사가 지킨다)

- **기본은 «보여만» 준다** — 실수로 돌려도 아무 일이 안 일어난다
- **함수 하나만 올린다**(`--only functions:nasBackupExport`) —
  전부 다시 올리면 열쇠가 빠진 함수가 그 자리에서 멎는다(메일·급여)
- **열쇠가 이미 있으면 다시 만들지 않는다** — 새로 만들면 나스에 넣어 둔 옛 열쇠가
  «조용히» 죽고 다음 주 새벽에야 안다
- **열쇠를 파일로 안 남긴다.** 서버에 넣을 때도 명령줄이 아니라 `--data-file -` 로 —
  명령줄 인자로 주면 같은 PC 의 다른 프로그램이 `ps` 로 그대로 본다
- **올린 뒤 실제로 한 번 받아 본다** — 「올렸다」와 「된다」는 다르다
- 끝에 **나스 스크립트에 붙여넣을 두 줄을 그대로 찍는다**(`URL=` · `NAS_KEY=`) —
  이름이 어긋나면 붙여넣어도 안 되므로 검사가 두 파일을 견준다
