# 컨설팅보고서 UI 재정리 3단계: 「오늘 할 일」 첫 화면 (2026-10-12)

계획 `docs/superpowers/plans/2026-10-12-gov-report-today.md` · 목업(저장소 밖): C 오늘 할 일 중심. 대표 「섞어서 진행」·「2 3 단계 순서대로」.

## 만든 것
- **첫 화면 = 오늘 할 일**: 사업을 안 골랐을 때 탭 둘 — 「🎯 오늘 할 일 N」(기본) · 「📋 전체 현황」(지금의 숫자 칸·거르개·전체 표 그대로). 사업을 고르면 탭이 사라지고 2단계 사업 대시보드. 왼쪽 목록 맨 위 「🎯 오늘 할 일」 단추로 돌아온다. 마지막 탭은 브라우저에만 기억(`gov_home_tab`).
- **사업별 카드 띠**: 이 해에 업체가 있는 진행 사업 카드 — 사업 이름 (수행기관) · 단계 누적 막대 · 「업체 N곳 · 막힘 n / 기한 14일 안 n / 정상」. 누르면 그 사업 대시보드.
- **할 일 묶음 (한 업체·사업 = 한 줄, 급한 종류가 이김)**: 🔥 급함(제출 기한 지남 · 막힌 단계 · 종료 14일 넘은 미작성) / ⏳ 챙기기(서명 회신 7일 넘게 기다림 · 계약 종료 7일 안) / 📝 이번 주(초안 7일 넘게 묵음). 줄마다 「서류 열기」 → 그 사업을 고르고 목차 창. 대형 사업의 지난 계약 종료도 «기한 지남»으로 급함에 올라온다. 묶음마다 8줄 + 「더 보기」.
- **📬 받은 서류 묶음**: 「📥 확인」을 눌러야 메일함을 읽는다(첫 화면은 자동으로 안 읽음). 확인 뒤엔 연결 안 된 건수 + 처음 5건 + 「서류 칸 열기」.
- 오른쪽 «⏰ 챙길 것» 구역은 오늘 할 일 탭에서만 숨김(같은 내용이 가운데에 있음). 양식 서고·받은 서류 확인은 그대로.
- 순수 모듈 `js/pu-gov-report-today.js`(`PuGovReportToday`) · **새 DB 칸·쓰기·규칙 없음**.

## 안전장치(검토에서 나온 것)
- 기록·사업 목록·이음표·계약 중 하나라도 못 읽으면 막힘·서명 대기·기한 줄을 만들지 않고 원인별 안내 한 줄만 둔다 — 가짜 «급한 일이 없습니다»·«정상» 없음. 사업 목록을 못 읽으면 카드 자리에 「다시 시도」.
- 할 일 계산은 연도·날짜·자료 버전이 같으면 다시 하지 않는다(거르개 입력으로 반복 계산 안 함).
- 종결 사업은 할 일·카드에서 빠지고, 「서류 열기」는 종결되지 않은 이알피 사업을 먼저 고른다.

## 알아 둘 것
- 카드의 «기한 14일 안 n»(지난 것 포함)과 목록 «기한 임박»(7일 안)은 기준이 다르다.
- 대형 사업의 기한은 이알피 계약 종료일이라 «제출 기한» 문구가 정확히 맞지 않을 수 있다.
- 같은 쌍의 막힘은 «기한 지남» 줄에 가려진다(우선순위: 제출·막힘·미작성·서명 대기·기한 임박·초안).
- 합성 자료로 화면 모양 확인(PC). **실제 로그인 화면은 확인 못 함**.
