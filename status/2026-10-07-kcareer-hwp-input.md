# 2026-10-07 · 경력관리 — 한글 서식의 «표 밖 줄»도 칠 자리로 (fix/kcareer-hwp-input-1007)

대표 제보: 「이력서관리·회의비용관리에서 한글 hwp hwpx 입력이 여전히 잘 안 된다」

## 실측
- 7번 폴더 실제 서식 40개로 돌려 봄 — 동의서·서약서·확인서는 표 없이 「성    명 : ____」 **줄**로 적는다.
  칸 지도가 표만 보아 **칠 자리 0개** → 입력판에 칸이 안 뜨고, 채우기도 서명 줄 이름만 들어갔다.
- 글상자(drawText) 안 줄도 같았다(「못 칩니다」 경고만).
- 한 칸에 라벨이 여럿(「기관명 : … 부서명 : …」)이면 입력판에 칸이 하나뿐 — 친 글자가 첫 자리에 몰렸다.
- 날짜·서명 줄 채우기가 「&」 를 두 겹으로 감쌌다(`&amp;amp;`) — 옛 결함.

## 고친 것
- `js/kcareer-hwpxfill.js` — `paraPairs`·`paraSlots`·`paraPut`(줄을 「라벨 : 값」 짝으로; 시각·주소 콜론은 짝 아님;
  「(인)」 꼬리 남김) · `paraPlain` 으로 두 겹 감싸기 고침 · `signLineFills`
- `js/kcareer-formmap.js` — 줄 자리를 `문단빈칸`(채움)·`문단글자`(사람이 고칠 때만)로 지도에 올림.
  서명 줄 이름은 서명 줄 채우기에 맡김(도장까지). 서명 줄에 이름을 넣으면 `sign` 표시.
- `kcareer.html` — 입력판이 라벨 여럿인 칸에 «라벨마다» 입력칸 · 칸 지도에 「본문 줄 / 글상자 줄」 표시
- 검사: `tests/kcareer-para-slots.test.js`(되돌려 6곳 모두 우는 것 확인) ·
  `tests/kcareer-overlay.test.js` 가 함수를 «앞 4200자»로 자르던 것 → 함수 끝까지(줄을 보탤 때마다 헛깨졌다)
