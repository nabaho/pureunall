# 경력관리 서류 만들기 — 도장 찍을 자리 고르기

- 대표 지적 2026-09-29 「권형하 도장을 넣고 싶은데 … 자동으로 넣어도 잘 안들어간다. 도장만 넣기 따로 하고 싶은데」.
- 실측(천안어린이꿈누리터 제안서 평가위원 후보자 등록 신청서): (인) 자리 3곳 — 작성자 · 평가위원 후보자(서약서) · 작성자.
  옛 방식은 «맨 처음 한 곳»에만 찍고 멈춰 서약서 자리에는 안 들어갔다.
- 고침(대표 승인 목업): 🖋 도장 찍기 → 자리가 둘 이상이면 「도장 찍을 자리 고르기」 창(처음엔 모두 체크).
  고른 자리(_rhStampPick)는 자동 저장·되돌리기·초기화를 따라간다. 다시 누르면 같은 창 — 모두 끄면 뺀다.
  자리가 하나면 옛날처럼 바로 · 채우기 뒤 저절로 찍을 때는 묻지 않는다(한 곳).
- 모듈: `KcareerHwpStamp.findSpots` (자리 전부 + 앞 글자). findSpot 은 그대로.
- 확인: 세 곳 찍은 파일을 rhwp 재조판 → 한글(COM) PDF 로 뽑아 세 곳 모두 도장이 보임.
- 알아 둘 것: 우리 그림 조각은 `<hp:img>` 라 «한글은 날것 그대로는 못 연다». 완성본은 rhwp 가 `<hc:img>` 로
  다시 써서 열린다. rhFinalizeHwpx 가 실패해 날것이 나가면 한글에서 안 열린다 — 도장·사진 모듈을 hc:img 로 바꿀 일이 남았다.
