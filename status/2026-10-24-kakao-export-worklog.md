## 한 줄 요약
첫 판(PR #2737 의 옛 커밋)을 만드는 사이, 다른 세션이 같은 💬 카톡정리에 **대화 저장본 읽기·원문 보관·받을 파일**을 main 에 먼저 합쳤다
(`14553b8e`, `status/2026-10-24-kakao-export-files.md`). 같은 서버 동작 `kakaoImport` 를 다른 입력 모양으로 써 충돌해, 대표 결정(10/26 「main 서버 배포 + 내 PR 재작업」)으로
**main 것을 쓰고, 고유한 «사건번호·업체별 묶기 → 업무관리 진행 기록»만 그 위에 얹었다.** 이 PR 에는 서버 코드가 없다.

## 이 PR 이 하는 것
- 💬 카톡정리에 셋째 탭 **«📋 진행 기록»** — 💬 대화 탭 미리보기 창의 **«📋 진행 기록으로 정리»** 로 넘어온다(읽은 줄 = main 의 `parseExport`, 이미 가려짐).
- 사건번호(업무관리 번호·심급 사건번호·업무명 속 번호와 «글자 그대로» 같음)·업체명으로 묶어 미리보고, **확인한 것만** 업무관리 진행 기록에 한 줄씩(한 번의 쓰기). 서버를 안 부른다.
- 덮어쓰지 않음: 같은 내용 건너뜀 · 늘면 «보강» 새 줄 · **사람이 지운 줄은 다시 안 올림**(`work_erp/kxoff/{업무}/{줄}` 표식 — 업무 기록 ✕ 와 같은 쓰기에 남김).
- 한 글에 사건번호가 둘이면 사건별 묶음에 각각 · 바로 뒤 번호 없는 글은 미분류. 폰 411px «두 줄 카드».
- 모듈 `js/pu-kakao-export.js`(순수: `fromLines`·묶기·요약·열쇠·업무 맞추기), 검사 `tests/kakao-export-{group,match}.test.js` · `tests/kakao-worklog-screen.test.js`.
