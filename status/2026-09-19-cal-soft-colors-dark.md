# 2026-09-19 · 푸른 캘린더 — 색을 «옅게」로, 어두운판(수동)을 넣는다

대표 지시 2026-09-19 「색깔이 너무 눈에 불편하다 어떻게 색조절하는게 좋은가
그리고 어두움 모드 도 한번 검토해달라」 → 견본 넷을 보여 드림 → 「2번 수동」

## 무엇이 불편했나

사람마다 정한 색(이알피가 고른 것)을 칸 전체에 **원색 그대로 채우고** 있었다.
하루에 대여섯 줄이 늘어서면 회색·청록·노랑·주황·분홍이 나란히 부딪혀 눈이 시렸다.

## 고른 것 — 「2번: 옅게 칠하고 왼쪽에 띠」

색 **값**은 안 바꾼다(`colorOf`, 이알피가 정한 것 그대로) — 그리는 **법**만 바꿨다.

- 바탕은 사람 색을 흰(밝은판) 또는 짙은 판색(어두운판)에 가깝게 **섞는다**
  (`mixHex`, 밝은판 85% · 어두운판 78%).
- 사람 색은 **왼쪽 띠 3px**에 원래 색 그대로 남는다 — 「누구 색인지」는 여전히
  한눈에 잡힌다. 구글·노션 달력과 같은 방식.
- 글자는 늘 `var(--ink)`(밝은판 짙게 · 어두운판 밝게) — 어느 색이 와도 4.5:1 이상
  읽힌다(실측, 아래 검사).

## 어두운판 — 수동만

**자동(시스템 설정을 따라가는 `prefers-color-scheme`)은 안 넣었다** — 「2번 수동」
지시대로 머리줄 단추(🌙/☀️)로만 켠다. 이 기기에서만 기억한다(`localStorage`,
`pu_cal_theme`) — 사람 계정이 아니라 화면 취향이라 device-local 이 맞다.

- `--panel`(카드)이 `--bg`(바탕)보다 **밝다** — 밝은판의 관계(카드가 바탕보다 밝다)를
  그대로 뒤집어 지켰다.
- 색은 전부 **지금 쓰는 팔레트 27색 + 흰/검** 안에서만 골랐다 — 새 색 없음
  (`color-palette-apps.test.js` 가 확인, 예외 목록 안 늚).
- 「오늘·공휴일·찾음」 칸은 어두운판에서 **옅은 칠을 안 쓴다** — 밝은판의 `#fffbeb`/
  `#fef2f2` 를 그대로 옮기면 그 위 글자가 안 읽힌다. 대신:
  - 오늘 → 칸 테두리를 파랗게 두른다(`.day.today` outline) + 날짜 동그라미(기존 그대로)
  - 공휴일 → `.ev.hol` 칩(이알피와 같은 분홍·빨강, **값을 안 바꿨다**)이 이미 표한다
  - 찾음 → `outline:#fbbf24`(기존 그대로, 어느 배경에서도 잘 보인다)

## 손댄 자리

| 자리 | 무엇을 |
|---|---|
| `chipHtml` | 채우기 → 옅게 섞기 + 왼쪽 띠 (`mixHex` 새로 만듦) |
| `calendarHtml` / `weekHtml` | 칸 배경을 판(theme)에 따라 갈라 계산 |
| CSS `:root` | 흰 배경 16곳을 `var(--panel)` 로(밝은판 값과 같아 안 바뀜) · 어두운판 뿌리 색표 추가 |
| CSS 덧붙임 | `.allchip.on`·`.chip`·`.note`·`.werr`·`.dchip`·`.linklike`·`.issued` 등 어두운판 색 |
| 머리줄 | 단추(`#themeToggle`) 추가, `#me`와 `#logout` 사이 |
| 부팅 | `themeInit()`이 `localStorage`를 읽고 켠다 |

## 검사

`tests/cal-dark-mode.test.js` **새로 만듦**(8건):
1. `mixHex` — 원색을 그대로 안 쓴다
2. `chipHtml` — 채우지 않는다(왼쪽 띠 + `mixHex`, `textOn` 안 씀)
3. **대비** — 실제 자료의 사람 색(구글 기본 색표 열 가지 + 극단값)으로 섞어도
   4.5:1 이상 읽힌다(밝은판·어두운판 둘 다)
4. 왼쪽 띠는 원래 색 그대로(섞인 색이 아니다)
5. 어두운판은 **수동**으로만 — `@media (prefers-color-scheme` 이 없다
6. 켠 채로 기억한다(`localStorage`) — 판을 바꾼 뒤 `render()` 로 다시 그린다
7. 어두운판 뿌리 색표도 팔레트 27색 + 흰/검 안
8. 어두운판에서 오늘·공휴일 칸을 옅게 칠하지 않는다

**이빨 확인 아홉 가지 모두 걸림.** 전체 **18,319건 통과**.

## 확인한 것 (실브라우저, 진짜 자료)

- 밝은판: 칩이 옅어지고 왼쪽 띠로 사람이 구분됨, 글자 또렷
- 어두운판: 단추 한 번으로 전환, 팝업(펼침 창)·넣고 고치는 창·폼 입력칸까지 전부 어두운판 색
- 오늘(9/19) 칸에 파란 테두리, 토글 두 번(어둡게→밝게) 정상 왕복
