# 휴대전화 카카오 로그인 저장소 지연 제거

- 2026-10-10 휴대전화 측정: 카카오 서버 812ms, Firebase 로그인 678ms, 저장 방식 준비 30,659ms. 재방문 인증 복원 기록 317초는 백그라운드 대기가 포함됐을 가능성이 있어 별도 확인이 필요하다.
- `enter.html`에서 화면을 열 때마다 `setPersistence(LOCAL)`을 기다리던 동작을 제거하고, Firebase가 이미 저장한 인증 상태를 즉시 관찰한다.
- 카카오 복귀 시 유지 켬은 기본 LOCAL을 다시 설정하지 않는다. 이전에 SESSION을 선택한 기기에서 유지 켬으로 전환할 때만 LOCAL 전환 완료를 기다린다. 유지 끔은 SESSION 설정 완료 후 로그인한다.
- 비밀번호 로그인 성공 시 적용한 저장 방식을 기록해 이후 카카오 전환에서 이전 선택을 알 수 있게 했다. 저장 방식 표시는 인증표나 비밀번호가 아닌 `local`/`session` 값만 저장한다.
- 관련 회귀 테스트를 추가·수정했다. 실제 휴대전화에서 배포 후 같은 진단 화면의 `저장소` 및 `인증 복원` 시간을 다시 비교해야 한다.
