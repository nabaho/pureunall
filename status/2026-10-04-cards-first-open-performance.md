# 기업정보함 첫 화면 성능 진단 반복 해결

## 증상

- 일반 사용자가 기업정보함을 열 때마다 `기업정보함이 처음 뜰 때 느린 까닭` 팝업이 반복될 수 있었습니다.
- 이전 실행에서 긴 작업을 감지하면 다음 실행에 전체 함수 초시계를 자동으로 붙였고, 이 계측 비용이 다시 긴 작업을 만들 수 있었습니다.
- 화면에 표시된 `mbWhoKey 230,818번`, `mbAllRows 33번`은 실제 오류가 아니라 이 개발용 초시계가 집계한 호출 횟수였습니다.

## 해결

- 일반 사용자 화면에서는 성능 관찰기, 전체 함수 초시계, 진단 팝업을 시작하지 않습니다.
- 개발자가 주소에 `prof=1`을 명시한 경우에만 성능 진단을 실행합니다.
- 브라우저에 남아 있는 옛 자동 계측 표(`pucards_prof_next`)는 제거하고 다시 사용하지 않습니다.
- 최근 반영된 메일 목록 한 벌 캐시와 담당자 키 캐시는 그대로 유지합니다.

## 확인

- `node --test tests/cards-prof-only-when-slow.test.js tests/mail-dash-speed.test.js`
- 일반 URL에서는 진단 비활성, `?prof=1`에서는 진단 활성, 옛 자동 계측 표 제거를 자동 검사합니다.
