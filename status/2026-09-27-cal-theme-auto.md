# 2026-09-27 · 캘린더 화면 밝기 — 자동 · 밝게 · 어둡게

대표 지시 「폰에서 화면변동 자동화 기능 만들고 선택할 수 도 있게해라」.
2026-09-19 「수동만」 결정을 이 지시로 바꿨다.

- 단추(머리줄, 폰은 ☰ 안) 하나를 누를 때마다 🌗 자동 → ☀️ 밝게 → 🌙 어둡게.
- 자동 = 폰·컴퓨터 밤 모드를 따른다. 바뀜 알림 + 화면이 다시 앞에 올 때(앱 전환·잠금 풀기) 한 번 더 본다
  (미리보기에서 바뀜 알림이 안 오는 경우가 있었다).
- 처음 여는 사람: 폰은 자동, 컴퓨터는 밝게(예전 그대로). 고른 것은 이 기기에만 기억(`pu_cal_theme`).
- CSS @media 로 바꾸지 않는다 — 칸·칩 인라인 색이 반쯤만 바뀐다. 스크립트가 data-theme 을 달고 다시 그린다.
- 검사 `tests/cal-theme-auto.test.js`, `cal-dark-mode ⑥` 은 새 규칙으로 고침.
