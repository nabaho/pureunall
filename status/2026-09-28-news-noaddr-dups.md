# 뉴스레터 «주소 없는 곳» — 회사 단위로 접기 · 설정 꼬리 두 줄

대표 지시 2026-09-28
- 「주소 없는곳에 중복되는경우가 많다 이부분 어떻게 정리해야하나 니가 검토해서 정리방법 해결해달라」
- 「천안본사 서산지사 두줄로 나누고 주소전화 등 열을 일치시켜달라」

## 실측 (살아 있는 업체 원장, 읽기만)

- 업체 672줄(활성 404 · 사무대행 166 · 종료 102). 사업자번호가 같은 묶음 221개(535줄).
- ⚠ 이 집은 같은 회사를 **자문·급여·기금마다 한 줄씩** 둔다 — 유형이 다른 두 줄은 정상이다.
- 「주소 없는 곳」 279곳 가운데
  - **108곳** — 같은 회사(같은 사업자번호·같은 유형)의 **다른 줄에 주소가 있어 이미 받는다**. 헛경보였다.
  - **79묶음(158줄)** — 같은 회사가 두 줄씩, 둘 다 주소 없음. 월 자문료는 79묶음 모두 같다.
  - 접고 빼면 **정말 주소가 없는 회사는 92곳**.
- 겹친 짝의 번호 꼴: co-c + co-real(33) · co-p + co-real(17) · co-imp + co-p(14) · co-adv + co-c(13) …
  여러 번의 가져오기가 같은 회사를 새 줄로 만든 흔적이다.
- 업체관리 「🔀 중복 정리」는 사업자번호로도 묶으므로 이 짝들이 거기 떠 있어야 맞다.
  «다른 회사»로 표시해 둔 것은 한 묶음뿐(co_merge_skip).

## 정리 방법 — 두 겹

1. **뉴스레터 (이번에 고침, 원장은 안 고친다)** — `Core.사업장에서명단` 이 「주소 없는 곳」을 접어 내준다.
   - 열쇠 = **사업자번호(종사업장까지) + 유형**. 이름으로는 안 묶는다(온톨로지 규칙).
   - 다른 줄로 이미 받는 곳은 목록에서 빼고(`이미받는겹침`), 두 줄 이상은 한 줄로(`겹친줄`).
   - 대표 줄 = 업체관리 중복 정리가 남길 쪽과 같은 잣대(살아 있는 것 › 담당 › 번호 › 자동 아님 › 먼저 만든 것).
     명함을 여기 담아 두면 나중에 합칠 때 빈 칸 채우기로 그대로 이어진다.
   - 화면: 접힌 줄에 「같은 회사 N줄」 딱지, 위에 «무엇을 빼고 접었는지» 한 줄, **「↧ 합칠 목록 엑셀」**.
   - 받는 명단은 한 줄도 안 바뀐다(보여 주는 것만 접는다).
2. **뿌리 (대표님이 누르실 일)** — 업체관리 › **🔀 중복 정리**. 「합칠 목록 엑셀」이 회사·사업자번호·
   업체 번호들을 적어 준다. 자문료가 걸린 원장이라 자동으로 합치지 않는다.

## 설정 꼬리

천안 본사·서산지사를 한 격자에서 **[이름 | 주소 | 전화]** 두 줄로. 칸 id 는 그대로라 저장 길은 안 바뀐다.
