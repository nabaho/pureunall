## 만든 것

**①「내 업무」** — 머리에 「🧹 치울 것 N」, 목록 아래에 **자문·급여 N건 접힌 줄**(대표 결정).
지우지도 끝내지도 않는다. 눌러서 편다. 업체관리에서 끝나면 저절로 빠진다.

**②「🧹 치울 것」 새 화면** — 세 덩어리, 줄마다 **☐ + 번호**(대표 지시 2026-10-05 · 모든 프로그램).

| | 할 수 있는 일 |
|---|---|
| ① 엑셀에서 옮겨 온 것 | **고른 것 종료** · 🔗 푸른이알피와 짝짓기. **반년 넘게 멈춘 것을 미리 골라** 둔다 |
| ② 이알피가 열어 둔 것 | **종료 단추 없음**(일부러) · 줄마다 「이알피에서 열기 ↗」 · 고른 것 목록 복사 |
| ③ 원본이 없는 것 | **고른 것 종료** · 줄마다 기록이 몇 줄인지 |

- **대표는 전 직원**, 나머지는 자기 것(칩으로 바꾼다). 멈춘 464건이 열 사람에게 흩어져 있다.
- 한꺼번에 종료는 **한 번에 보낸다**(반쯤 하다 멈추지 않게) · 그사이 남이 닫은 줄은 건너뛴다 ·
  이알피에 **안 민다**(`pe_nosync`) · 종료 화면에서 **↩ 재개**로 돌아온다 · **기록은 한 줄도 안 지운다**.
- 미리 고르는 것은 「오래 멈춘」 것뿐이다 — **기록 없는 것은 미리 안 고른다**(갓 들어온 새 업무일 수 있다).
- 고른 것은 화면을 떠나거나 보는 범위를 바꾸면 비운다.
