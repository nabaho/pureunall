# 로그인 직후 다시 튕김 — 늦은 로그아웃 신호 차단 (2026-10-22)

- 제보: 카카오 로그인 뒤 포털 메인 화면이 잠시 보였다가 로그인 화면으로 돌아가며 다시 카카오 계정 화면까지 반복됨.
- 확인한 코드 경로: 여러 앱 탭의 `pu-authsync`는 `pu_auth_logout_at` 저장소 알림을 받으면, 그 시각을 새 로그인 시각과 비교하지 않고 무조건 `signOut()`과 포털 이동을 실행했다. 휴대전화의 잠든 탭에 옛 알림이 늦게 도착하면 새 세션까지 끊을 수 있다. 포털의 카카오 인증 시작은 로그인 단추 클릭 한 곳뿐이므로, 이 경로만으로 카카오 계정 창이 자동으로 다시 열렸다고 단정하지 않는다.
- 수정: 저장소 알림도 탭 복귀 검사와 같은 순서 비교를 사용한다. 새 로그인보다 뒤의 실제 로그아웃은 즉시 전파하고, 그보다 앞의 신호는 무시한다. 공용 JS를 싣는 화면의 캐시 번호를 함께 올렸다.
- 검사: 새 로그인 뒤 도착한 옛 알림은 세션을 끊지 않고, 그 뒤 새 로그아웃 알림은 끊는 회귀 검사를 추가했다. `tests/*.test.js` 2,195개 파일 전체 통과, 캐시 검사·공백 검사 통과. 실제 휴대전화에서 저절로 카카오 계정 창이 재등장하는지, 사용자의 화면 종류·조작 여부 답변과 배포 후 재현 확인이 필요하다.
