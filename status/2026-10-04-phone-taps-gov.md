# 2026-10-04 · 「추천대로」 — 정부사업신청 폰 규칙 · select 는 그대로 둔다

- 가지: `fix/phone-select-and-taps`
- 왜: 대표 지시 「추천대로」 (남겨 둔 둘 — ① select 일곱 군데 ② 작은 단추·gov.html)

## ★ select 일곱 군데는 «그대로 둔다» — 앞선 방들이 이미 겪었다

올리려고 자리를 열어 보니 **이미 16px 로 올렸다가 되돌린 흔적**이 주석으로 남아 있었다.

```
/* 고르기만 하는 알약 select 까지 부풀려 놓으니 한 줄에 둘도 안 들어갔다.
   가로 스크롤 줄 안의 것만 되돌린다 — 다른 입력칸은 그대로 16px 이다. */   (css/pu-erp.css 831)

/* 12px — 위의 select{font-size:16px} 는 아이폰 확대 방지용인데 select 에는
   해당이 없고, 16px 로는 셋이 한 줄에 안 들어간다(「전체 담당자」가 잘렸다). */ (900)
```

- select 는 손대면 **자판이 아니라 고르개(피커)**가 뜬다 — 글자 칸과 사정이 다르다.
- 좁은 띠(연장 막대·거래 필터·앱바)는 셋이 한 줄에 들어가야 하고, 16px 면 잘린다.
- **다시 올리면 그때 그 고장을 그대로 되살린다.** 그래서 안 올린다.
  검사(`phone-input-zoom.test.js`)도 select 를 일부러 뺀 까닭을 주석에 적어 두었다.

## 고친 것 — 정부사업신청(gov.html)

포털에 실린 16개 앱 가운데 **혼자만 폰 전용 규칙이 0개**였다. 딱지 43×24 · 단추 31 높이.
푸른이알피가 이미 쓰는 기준(`min-height:38px`)을 그대로 옮겼다 — 새로 짓지 않았다.

| 잰 것(배포본 375×812) | 전 | 후 |
|---|---|---|
| 손가락보다 작은 단추 | **21개** | **3개** |
| 가로 넘침 · 밖으로 삐짐 | 0 · 0 | 0 · 0 |
| 딱지 줄 수 | 2줄 | 2줄 (안 늘었다) |
| 화면 길이 | 859 | 925 (+66px) |

딱지 높이는 32·38 둘 다 재 보고 **38** 로 했다 — 줄 수가 같았고, 집 안의 기준과 같다.
⚠ **표에는 손대지 않았다** — 표는 이미 `.scroll`(overflow-x:auto) 안에 있어,
표에 또 스크롤을 주면 상자 안에 상자가 생긴다(재서 확인).

## 검사

`tests/phone-input-zoom.test.js` 에 다섯째를 더했다 — 폰 크기에서 **단추와 딱지에
최소 높이를 주는 규칙이 있는가**(38 이든 40 이든, 어느 선택자든 통과).
되돌림 셋 모두 운다: gov 단추 빼기 · gov 딱지 빼기 · 이알피 폰 보강 빼기.

## ⚠ 한참 헤맨 자리 — 셸이 `\b` 를 먹었다

검사를 고치며 `node -e "...replace...\\bbutton\\b..."` 로 줄을 갈아 끼웠더니,
셸을 지나며 `\b` 가 **백스페이스 문자(0x08)** 로 들어갔다. 눈에는 `/button/i` 로 보이는데
`/\x08button\x08/i` 라 아무것도 안 맞는다 — 「규칙은 분명히 있는데 검사만 운다」로 보였다.
**파일 고치기는 셸을 거치지 않는다**(Write/Edit 또는 파일로 만든 node 스크립트).
저장소 기억에 이미 있던 함정이다.
