# 포털 업무 오케스트레이션 컴팩트 팝업 전환 (2026-11-18)

## 배경 및 사용자 지시
- 대표님 피드백: *"오케스트레이션을 이렇게 창으로 나올필요가 없다 작은 화면에 팝업으로 클릭하면 나오게 만들어달라."*
- 기존 `enter.html` 상단에 상시 노출되던 2줄짜리 넓은 박스(`#orchBar`)가 앱 타일 영역을 아래로 밀어내고, 클릭 시 전체 창으로 열려 번거로웠던 문제를 해소함.

## 주요 변경 사항
1. **상단 고정 박스(`#orchBar`) 제거 및 클릭형 알약 단추(`#orchFab`) 전환 (`enter.html`)**
   - 포털 홈 화면에서 넓게 자리를 차지하던 `#orchBar` 마크업·스타일을 완전히 제거함.
   - `업무 시스템` 줄 오른쪽에 작은 알약 단추(`🔄 오케스트레이션` + 대기 건수 배지 `#orchFabBadge`)만 두고, 자료함·자주 쓰는 앱의 `🔄 오케스트레이션` 타일(`popup:true`) 및 길잡이 챗봇 실행(`portalLaunchApp('orch')`)과 연결함.
2. **현재 화면 위 작은 플로팅 팝업(`#orchModal`, 폭 `472px`) 구현 (`enter.html`)**
   - 단추나 타일을 클릭했을 때만 열리는 컴팩트 모달(`#orchModal`, 헤더 드래그 이동·`Esc`/배경 클릭 닫기·`Tab` 포커스 가두기·트리거 포커스 복원 지원)을 구성함.
   - 팝업 내부에서 5대 생애주기 단계 필터(`전체` · `①~⑤`, `aria-pressed`), 검색칸(`16px` 모바일 안전 규격), `전체선택` 체크박스, `👤 내 담당`·`✓ 확인포함` 필터, 좌측 `☐` 선택 + `№` 순번 바통 카드, 로컬 `✓ 확인`·일괄 확인, 60건 단위 `더 보기` 페이지네이션, 원클릭 `[실행 ➔]` 바통 점프를 즉시 처리함.
   - 행 체크박스 선택·단계 전환·`✓ 확인`·`더 보기`·비동기 전체 스캔 완료 시에도 키보드 포커스가 `body`로 빠지지 않고 해당 컨트롤(또는 인접 행)로 보존되도록 처리함.
   - 포털 최초 진입 시에는 기존처럼 경량 대기열 2개만 읽어 로그인 속도를 지키고, 팝업을 열 때 허용된 9개 경량 공유 원장(`in_app` 민감 경로 완전 제외)을 온디맨드로 동기화하며 전체/부분 읽기 실패 안내를 분리함.
   - 상세 보드(`상세 보드 ↗`)를 열 때도 전체 화면이 아닌 작은 명명 팝업 창(`540×680`, `pureun-orch`)으로 열리도록 지정함.
3. **자동 검증 및 폰 전수점검 시드 보강**
   - `tests/portal-orchestrator.test.js`: `#orchBar` 부재, `#orchFab`·`#orchModal` 기본 숨김, `Tab` 포커스 가두기·페이지네이션·포커스 보존, 온디맨드 경로의 `in_app` 비접근 검증 추가.
   - `tools/phone-audit/seeds/portal.js`: 포털 기본 화면 및 `orch-popup` 열림 뷰(`360px`·`411px` 기본 점검 및 `--widths=768,1024` 실측 지원) 자동 점검 시드 추가.
