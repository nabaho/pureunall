# 2026-09-28 · 기업정보함 — 국세청 자동 확인 · 🧾 등록증 대조(진위확인)

- 대표 지시: 「기업정보에 국세청 확인을 자동으로 api 에서 검토하고 확인하고 처리하고 싶다」
  → 공공데이터포털 키 발급·포털 환경설정에 넣음(`data/app_config/ntsKey`, 조회 확인됨) → 목업 승인 → 「진행」

## 한 것 (`pu-cards.html`)

- **자동 물음** `coNtsAutoOne` — 상태조회(/status) + 등록증 대조(/validate)를 한 곳씩 묻고 날짜와 함께 적는다.
  - 수정창에서 사업자등록증 저장 직후(`coNtsAutoAfterSave`, 오늘 이미 묻고 값이 그대로면 안 묻는다)
  - 아직 안 물어본 회사의 상세를 열 때(`coNtsAutoOnOpen`, 창 하나에서 한 회사 한 번) — 사진첩·일괄 등 어느 길로 들어온 등록증이든 걸린다
  - 열쇠가 없거나 못 물어봤으면 아무것도 안 적는다.
- **🧾 등록증 대조** — 대표자·개업일·상호가 국세청 기록과 맞는지. 국세청은 «맞다/다르다»만 준다 → **고치지 않는다.**
  - 딱지: ✓ 등록증 일치 / ✗ 대표자·개업일 다름 / △ 상호 다름 (기업정보 머리줄, 국세청 딱지 옆)
  - 「확인 필요」에 국세청 줄(폐업·휴업·없는 번호, 등록증 다름) + 「사진 보고 고치기」(등록증 수정창)
  - 국세청 창에 「🧾 전체 대조」(무엇이 나가는지 먼저 묻는다) · 거르개 「🧾 등록증 다름」
  - 견준 뒤 값이 바뀌면 옛 판정은 숨긴다(`ntsMatchOf`). 저장 칸: `coInfo/{열쇠}/ntsMatch·ntsMatchAt·ntsMatchOf`
- 「전체 훑기」(상태조회)는 **그대로 번호만** 보낸다 — 대조는 따로 묻는 단추다.

## 실측 — 국세청 진위확인이 어떻게 맞춰 보나 (남경테크·충서로 시험)

- 개업일 하루·대표자 한 글자만 달라도 「확인할 수 없음」. 대표자 띄어쓰기·「외 1명」도 틀림 → `coNtsCeo` 로 다듬는다.
- 상호: (주)=주식회사, 앞뒤·띄어쓰기 무시. **㈜ 한 글자는 못 알아봄**, 법인 표시를 빼면 틀림 → ㈜→(주), 표시 없으면 (주)를 붙인 것도 함께 묻는다.
- 실제로 하나 잡힘: 목록 3번 「농업회사법인주식회사**서**」 — 국세청 기록은 「…**충서**」(coInfo 는 충서로 맞게 들어 있음).
