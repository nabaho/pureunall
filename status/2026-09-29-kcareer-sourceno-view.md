# 경력관리 실적 — 번호 칸에 이알피 관리번호 (목업 안 D + E)

- 대표 결정 2026-09-29 「추천대로」 (목업 6안 중 D + E). 앞 단계: status/2026-09-29-kcareer-puref-id.md
- D: 사건·컨설팅·기금·기타·자문 실적의 맨 앞 칸 「ID」 → 「번호」. 이알피와 이어진 줄은 관리번호(sourceNo, 옛 실적은 사건내용의 관리번호)를 보이고, 누르면 작은 창(puNoPop): 연결 상태(영구/옛 방식/확인 필요) · 경력관리 번호(CS…) · 🔎 이알피 현재 값 · 확인 필요면 「동기화에서 제 건 고르기」.
  - 줄 끝의 🔎 단추는 이 창으로 옮겨 없앴다. 손으로 넣은 기록은 예전처럼 CS 번호 칩.
  - 줄 열쇠는 `<tr data-rid>` — 칸 글자로 찾지 않는다(관리번호는 다시 매겨진다).
- E: 툴바 「📎 원본없음」 옆에 칩 「🔗 이알피 N · ⚠ 연결 확인 N(있을 때만) · ✎ 손으로 N」 — 누르면 그것만, 다시 누르면 풀림. 전체 건수 옆 «걸러짐» 표시는 그대로.
- 외부기관 실적 탭은 따로 그리는 화면이라 이번엔 안 바꿨다.
