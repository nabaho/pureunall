# 2026-09-11 · 지역뉴스 1단계 — 공식 출처 등록부

> 대표 지시: 「다음 진행사항 있나」 → 「순서대로 진행」

## 이번 단계

- 지역뉴스 공식 출처를 `js/pu-news-regional-sources.js` 한곳에 등록했다.
- 고용노동부 공지·정책·법령 RSS와 충남도·서산시·천안시 공식 게시판부터 시작한다.
- 업체 지역이 `충남/서산시`이면 전국·충남·서산 출처만 추천하고 천안 출처는 제외한다.
- 지역뉴스 입력에서 출처를 임의로 적지 않고 등록부에서 고른다.
- 해당 게시물의 `https://…go.kr` 원문 주소와 푸른 자체 설명이 모두 있어야 저장한다.

## 저작권 원칙

- 기사·게시물 본문과 사진은 복제하지 않는다.
- 제목·기관·공식 원문 링크와 푸른이 직접 쓴 설명만 사용한다.
- 공공누리 유형은 게시물마다 다를 수 있으므로 출처가 공공기관이어도 원문 복제를
  자동 허용하지 않는다.

## 온톨로지·자료

- 새 프로그램이나 새 자료 뿌리는 만들지 않았다.
- 기존 `newsletter/issues/{회차}/지역뉴스`의 `출처Id`에 공식 출처 영구 ID만 덧붙인다.
- 업체 주소 원문과 기사 본문은 복제하지 않는다.

## 검사

- 공식 HTTPS 주소, 중복 없는 영구 ID, RSS/게시판 구분, 지역 계층 추천,
  저작권 원칙, 화면 연결을 검사한다.
- 전체 통합검사에서 새 기능 관련 실패는 없다. 이 PC에서는 기존 Windows 전용
  `tests/rc-open.test.js` 창 열기 검사 1건만 실패한다(main CI 결과를 함께 확인한다).

2단계에서 RSS 출처를 매일 읽어 `검토 대기` 후보만 만든다. 자동 게시·자동 발송은 하지 않는다.
