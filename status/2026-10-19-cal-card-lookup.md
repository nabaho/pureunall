# 2026-10-19 · 푸른 캘린더 — 담당자 이름으로 기업정보함 찾기 · 주소 확인 · 연락처 남기기

대표 지시(구글 일정 고치기 창 캡처와 함께): 「사람 이름 검색 시에 정보함에 이름·주소 등을 모두 찾아서 자동으로 넣을 수 있게 해줘.
주소가 바뀌는 경우가 많으니 그 경우 주소 체크하게 해주고, 담당자 연락처도 항상 남기게 해줘 — 그래야 방문 시에 연락처로 전화할 수 있다」

## 무엇이 비어 있었나
- 기업정보함에서 불러오기는 «새 일정»에만 있었고(별도 줄), 구글 일정을 고치는 창에는 없었다.
- 「담당자」 칸은 그냥 글자칸이라 이름만 쳐도 저장됐다 — 전화번호가 안 남았다.
- 정보함 주소가 그대로 들어가도 «옛 주소일 수 있다»는 말이 없었다(색인에 갱신일도 없다).

## 만든 것
- `js/pu-cal-card.js`(PuCalCard, 순수 모듈) — 이름 찾기(직함이 붙어도 「정빛나이사」) · 연락처 글 · 주소 같음 판정 · 채우기 · 주소 안내 재료 · 저장 전 확인거리.
- `pu-cal.html`
  - 담당자 칸을 치면 아래에 후보 목록(이름·직함·업체·전화·주소). 고르면 «이름 직함 · 휴대폰 · 회사 전화» 와 주소가 채워진다. **새 일정·고치기(구글 일정 포함) 공통.**
  - 위치 칸 아래 «주소 확인» 줄: ① 정보함 주소 그대로 → [✔ 맞습니다][🗺 지도로 보기] ② 적어 둔 위치와 다름 → 둘을 나란히 [정보함 주소로 바꾸기][지금 위치가 맞음] ③ 같은 업체에 다른 주소(이전·지점) → 골라서 바꾸기.
  - 담당자 글에 전화번호가 없으면 칸 아래에 안내.
  - **저장 전 확인(doSave)** — 막지 않고 «묻는다»: 정보함 주소 그대로인데 확인 전 / 전화번호 없음 / 장소는 있는데 담당자 없음. 취소하면 저장하지 않고 돌아간다.
    이미 있는 일정은 «담당자 칸을 바꿨을 때만» 묻는다(시간만 옮길 때마다 묻지 않는다) — 열 때의 담당자 글을 `contact0` 로 적어 둔다.
  - 연락처는 구글 일정 설명(「담당자: …」)에 실려 폰 구글 캘린더에서도 보인다(기존 길 그대로).
  - 한글 조합 보호: 칠 때는 목록 칸만 갈아 끼운다. `명함목록고침` 은 색인이 도착해도 있는 칸만 고치고, 칸이 하나도 없을 때만 전체를 그린다.
- `tests/cal-card-lookup.test.js` 26개(이름·직함·전화·주소 규칙 / 화면 함수 실제 실행 / 저장 전 확인이 먼저 / 이빨 확인 5곳).

## 읽기만 한다
기업정보함(pucards/idx)은 읽기만 하고 고치지 않는다 — 주소가 틀렸다면 정보함 쪽에서 사람이 고친다(기존 원칙 그대로).

## 확인한 것 / 못 한 것
- 폰 폭(430px) 화면을 로컬에서 직접 그려 보고 고쳤다(후보 줄이 가로로 넘쳐 두 줄로 정리).
- ⚠ 실제 기업정보함 자료·로그인 상태로는 못 봤다 — 로그인 막 때문에 가짜 명함 3건으로 그렸다. 실제 폰에서 한 번 눌러 보기.
- ⚠ 이름 규칙은 «이름 앞부분 일치 + 직함 떼기»다. 같은 이름이 여럿이면 업체 이름이 목록에 함께 보이니 눈으로 고른다.
