# 조문 머리를 두 번 찍던 것 — 그나마 하나는 «옛» 번호였다 (2026-09-13)

대표 제보 「조문이 바뀐것인데 왜 이렇게 엉망으로 정리하나?」 + 확대한 화면 한 장.

## ■ 무엇이 보였나

「변경 결과(개정안 전문)」 창에서 —

```
카드 머리 : 제18조 (영리행위 및 겸직 금지)     ← 새 번호
본문 첫 줄 : 제15조(영리행위 및 겸직 금지) 사원은 회사의 허가 없이 …   ← 옛 번호
```

조문 하나에 번호가 **둘**이고, 그나마 하나는 개정 전 번호다.

## ■ 까닭

`it.after` 는 `parseArticles` 가 준 `a.body` 에서 온 것이라 **옛 조 머리를 품고 있다**.

```js
// buildItems
const before = a.body.replace(/\s+/g," ").trim();
…
it.after = before;     // ← 「제15조(…)」가 이 안에 그대로 들어 있다
```

문서를 만드는 셋(한글 전문·대조표 문안·미리보기 글)은 모두 `articleText(v)` 를 거쳐
**옛 머리를 떼고 새 번호를 붙여** 쓴다. **화면 하나만** 제 잣대를 안 썼다 —
`showRevision` 이 `escapeH(breakHo(it.after))` 로 **그대로** 찍고 있었다.

★★ 오늘 아침 「최종 확인 ①」에서 잡은 것과 **같은 종류**다. 잣대가 둘이면 갈린다.
  (그때는 화면이 제 정규식으로 첫 줄을 통째로 지워 4,459자를 삼켰다.)

## ■ 그리고 신구대조표에도 있었다 — 이쪽은 **노동청에 나가는 서류**다

같은 자리를 실제 문서(101조)로 재보니 —

```
변경조항 : 제1조 (영리행위 및 겸직 금지)      ← 새 번호
  변경 전: 제15조(…) 사원은 회사의 허가 없이 …   ← 옛 번호 (★ 이것은 맞다. 현행이다)
  변경 후: 제15조(…) 사원은 회사의 허가 없이 …   ← 옛 번호 (★★★ 틀리다)
```

개정 뒤에 그 조는 **제1조**인데 본문이 스스로를 제15조라 부르면 서류가 어긋난다.
`daejoRows` 가 `after: it.del?"〈삭제〉":it.after` 로 **날것**을 넘기고 있었다.

## ■ 고친 것

**떼는 일을 한 자리로 모았다.** 화면마다 제 정규식을 두지 않는다.

| 함수 | 하는 일 |
|---|---|
| `articleBody(it)` | 옛 머리를 **뗀다**. 떼는 일은 여기 **한 자리**뿐 |
| `articleText(v)` | `articleBody` + **새 번호 머리**를 붙인다 (문서용 — 그대로) |
| `afterHead(v)` | 대조표 「변경 후」 열 — 머리가 **있을 때만** 새 번호로 갈아 끼운다 |
| `showRevision` | `articleBody(it)` 를 찍는다 (카드 머리가 번호를 따로 찍으므로) |

⚠ **「변경 전」 열은 옛 번호가 맞다** — 그것이 현행이다. 여기는 손대지 않았다.
⚠ **머리가 «있을 때만» 간다** — 없는 문안(신설은 대개 머리 없이 쓴다)에 머리를
  새로 붙이면 지금까지 나가던 양식이 바뀐다. 검사가 이 둘을 다 못 박는다.

## ■ 실측으로 확인

실제 문서(`parseArticles` 로 뽑은 101조)에 붙여 —

```
변경조항 : 제1조 (영리행위 및 겸직 금지)
  변경 전: 제15조(영리행위 및 겸직 금지) 사원은 회사의 허가 없이 …   ← 그대로
  변경 후: 제1조(영리행위 및 겸직 금지) 사원은 회사의 허가 없이 …    ← 고쳐짐
신설(머리 없는 문안): ① 회사는 사원의 개인정보를 보호한다.          ← 안 건드림
```

## ■ 검사

`tests/rules-revision-head.test.js` **12개** — 먼저 빨강을 보고 고쳤다.

- 옛 머리를 뗀다 / 없는 머리는 안 뗀다 / 가지번호(제15조의2)도 뗀다 / 빈 값에 안 터진다
- 문서용은 **새 번호**를 붙인다 · `articleText` 도 **같은 자리**에서 뗀다
- 「변경 결과」 창이 `articleBody` 를 쓴다 · 삭제 행은 그대로 「삭제」다
- ★ **`escapeH(breakHo(it.after))` 로 찍는 자리가 한 곳도 없다** (주석은 먼저 걷고 센다)
- 「변경 후」 열이 `afterHead` 를 쓴다 · 「변경 전」 열은 `it.orig` 그대로다

  그대로 두고 번호만 맞췄다 — 지금까지 나가던 모양을 안 바꾸는 쪽이다.
