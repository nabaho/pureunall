# 자문사·거래처 수신 서류 「받았습니다 · 검토했습니다」 확인 클릭 및 자동 답메일 기능 (2026-11-28)

## 배경
- 푸른 메일에서 자문사·거래처가 보낸 서류(급여대장, 입퇴사 서류, 취업규칙·자문 요청서, 컨설팅 자료 등)를 담당 노무사·담당자가 확인했을 때, 내부 처리 표시와 별개로 고객사에 "서류를 잘 받았습니다" 또는 "검토 완료했습니다"라는 회신을 매번 수기로 작성해야 하는 번거로움이 있었다.

## 변경 사항
1. **자문사·거래처 서류 수신 자동 인식 및 확인 답메일 바 (`pu-cards.html`)**
   - `mbAckInfoOf`: ERP 거래처(`companies`), 세무사무실 연계 거래처(`mbTaxRecOfRow`), 진행 중 사업(`mbWorkOfRow`)과 연결된 수신 메일을 자동 판별하고, 발신전용 주소(`noreply`, 공단·홈택스 등)와 비거래처 일반 광고 메일은 자동 제외.
   - `mbAckStripHtml` · `mbAckTopBtnHtml`: 담당 노무사·담당자(주·부담당, 진행사업 담당자) 및 관리자가 열람할 때 **`📥 받았습니다 답메일`** · **`✅ 검토했습니다 답메일`** 원클릭 단추 제공.
2. **원클릭 확인·자동 답메일 발송 모달 (`mbAckOpen` · `mbAckSend`)**
   - 탭 전환(`받았습니다` ↔ `검토했습니다`)에 따라 거래처명·메일 제목·첨부 서류 파일명·담당자 이름·직책이 자동 반영된 정중한 답메일 본문 생성, 한 줄 덧붙임 안내 입력 지원.
   - 확인 클릭 시 회사 공식 메일(`postAutoMail`)로 원문 인용 + 담당자 디지털 서명(`signBlockHtml`) + 내 명함 파일 자동 첨부(`myCardShouldAttachNow`)를 포함해 즉시 발송.
   - 실제 발송 성공 직후 답장 완료 표시(`mbAnswered`) + 내부 `내가 봤다`(`mbSeenMark`) + 발송 이력(`pucards/mailAck`)을 함께 기록해 다른 직원의 중복 답메일 발송을 방지.
3. **보안 규칙 및 테스트 (`scripts/make-firebase-rules.js`, `tests/mail-ack-reply.test.js`)**
   - `pucards/mailAck`: 재직 직원 열람 허용, 통째 삭제 차단(`ADMIN` 전용), 개별 기록은 작성 본인(`auth.uid`) 또는 관리자(`MGR`)만 수정 가능하도록 검증 규칙 추가.
   - `tests/mail-ack-reply.test.js`: 거래처·권한·발신전용 판별, 수신/검토 답메일 발송 및 중복 방지, 실패 시 보존·거짓 표시 차단, 보안 규칙·XSS 방어 단위 시험 추가 및 통과.
