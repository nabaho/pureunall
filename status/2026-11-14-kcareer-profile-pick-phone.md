# 경력관리 · 프로필 «☑ 고르기» — 폰 폭 표 배치·자격 차례 고침 (2026-11-14, #3026 자동 검증 지적 반영)

#3026(경력·강의·자격·수상까지 고르기)이 자동 검증(Orca)보다 먼저 합쳐져, 검증의 지적을 후속으로 고친다.

- **폰(≤520px) 고르기 창 표**: 공용 폰 카드(`.dt`)는 «끝 칸 = 오른쪽 관리 단추 열(72px 이상)»로 세운다. 이 표는 끝 칸이 값이라, 긴 기관명 줄에서 일자 칸이 0px 로 눌려 가려졌다(검증 중간 지적, 375px·자격/강의). `#p1PickTbl` 에만 끝 칸을 일반 칸처럼(`grid-column:1 / 3`·이름표 + 값)·카드를 두 칸(`66px | 1fr`)으로 놓는 폰 폭 규칙을 더하고, 칸마다 `data-label`(열 머리)을 붙였다. 측정(375px, 자격·실적·위촉·경력): 모든 칸이 카드 안·눌린 칸 없음·가로 넘침 없음, 값 칸 폭 205px → 284px.
- **자격 차례**: 종이는 «국가자격 먼저·최근 것 먼저», 고르기 창은 날짜순이라 번호가 어긋났다(검증 낮음 지적). `certCmp` 를 내보내 종이와 창이 같은 비교 함수를 쓴다.
- 캐시 `kcareer-profile1.js?v=15`.
- **고치지 않은 것(원래 있던 문제 — 후속 과제)**: ① 다크 테마에서 노란 안내 상자·`.btn`·`.dt thead`·`#p1PickTbl th` 글자 대비가 AA 미달 ② A4 보기가 768px 에서 `#main` 가로 스크롤(`.p1-wrap` 500px 고정) ③ ⚙·☑ 단추 높이 20px.
- 시험: `tests/kcareer-profile1.test.js` ⑯ 고침(자격은 `certCmp`)·⑰ 새로(폰 규칙·이름표·두 칸·자격 차례 = 종이).
