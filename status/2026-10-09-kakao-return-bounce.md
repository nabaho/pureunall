# 포털 진입 직후 로그인 화면으로 튕겼다가 다시 들어오는 현상

- 대표 제보: 카카오 로그인 뒤 포털이 보였다가 로그인 화면으로 깜빡이고 다시 들어온다.
- 코드 경로: `enter.html`의 `onAuthStateChanged`는 포털 진입 후 `null` 알림을 받으면 재확인 없이 `location.replace`했다. 인증 저장 방식 전환·탭 복원 중 같은 사용자가 잠깐 비었다 돌아오더라도 새 로그인 페이지로 보낸다.
- 수정: `null` 알림 즉시 기존 포털을 가려 개인정보 노출을 막고, 같은 UID가 2.5초 안에 복원되면 가림막만 걷는다. 복원되지 않거나 명시적 로그아웃이면 새 로그인으로 이동한다. 다른 UID가 들어오면 이전 사용자의 화면을 드러내지 않고 새로 연다. 포털 타일 렌더가 끝나기 전 가림막을 걷지 않는다.
- 회귀 검사: `tests/portal-auth-return-bounce.test.js`에 복원·실제 로그아웃·다른 사람·렌더 전 알림 사례를 추가했다.
- 남은 일: 배포 뒤 대표 휴대전화에서 실제 카카오 로그인과 여러 앱 탭 복귀를 확인한다. 저장소에 남긴 `pu_login_flash_log`가 새 항목을 기록하면 그 사유를 보고 추가 경로를 추적한다.
