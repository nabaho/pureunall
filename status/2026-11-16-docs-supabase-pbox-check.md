## 확인 결과

- **지금은 켜져 있지 않다**: 배포된 `pboxApi`·`pboxDailySync` 에 수파베이스 주소·서버용 열쇠 환경변수가 없고, 화면에도 «무료 무제한»(연결되면 «공유DB · 보관 N편»)이 보인다.
- 코드는 서버 중계(서버 함수가 `pbox_documents` 한 표만 읽고 씀)가 실제 길이고, 브라우저 직접 연결은 증표 구조가 맞지 않아 이어지지 않는다.
- 안티그래비티(`antigravity:gemini-4-argon-high`) 검증과 직접 확인이 일치: 직접 연결 증표 불일치 · 연결이 꺼져도 성공으로 보임 · 안 쓰는 표 · 무료 요금제 한계(용량·정지·백업·내려받기) · 올리개·온톨로지 조건과 어긋남.
- 앞 글들은 «수파베이스 쓰는 곳 없음» 전제였음을 바로잡았다.

## 남는 것

- 수파베이스 대시보드에서 프로젝트·서울·표 적용 여부 확인(대표).
- 연결을 마무리할지(표 적용 → 서버 함수에 주소·열쇠 → 재배포) · 위 «고칠 곳» 코드를 고칠지 결정. 공유 문서를 두려면 Pro·백업을 먼저.
