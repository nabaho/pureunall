# 2026-10-09 · 경력관리 — 담당자 읽기 실측 고침 (fix/kcareer-biz-owner-ocr)

대표 크롬에서 실제 메일로 돌려 보니 둘 다 «이름 없음»이었다:
- 본문이 html 로만 온다(text 0자 · html 2만 자) → html 을 글자로 바꿔 본다(`_bizHtmlText`).
- 결과보고서 PDF 가 날인 «스캔본»이라 글자 층이 2자 → 그때만 AI 에게 «담당자 이름만» 묻는다.
  고를 이름(명부)을 함께 주고, 답도 ownerGuess 로 다시 걸러 명부 밖 이름은 버린다. 출처에 「(AI 판독)」.
- 실측: 충남북부상의 결과보고서(스캔 PDF) → 「권형하」(AI 판독).
