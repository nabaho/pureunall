# 경력관리 문서 비율 및 입력 초기화 개선

- 긴 HWP/HWPX 서식을 화면 높이에 억지로 축소하던 `한 장 맞춤` 대신 `폭 맞춤`을 기본으로 변경했다.
- 필요할 때 사용자가 `한 장`을 선택하는 기능은 유지했다.
- `처음부터 다시 채우기`를 `입력 내용 모두 지우기`로 명확하게 바꿨다.
- 초기화하면 입력값·도장·사진·제외한 쪽·서식 정리 상태를 지우고 빈 원본에서 멈추도록 변경했다.
- 초기화 직후 자동으로 같은 정보를 다시 넣지 않으며, 직접 입력하거나 `내 정보로 채우기`를 선택할 수 있다.
- 처음 올린 원본이 없는 오래된 작성 건은 빈 HWP/HWPX 서식을 다시 고른 뒤 빈 상태로 시작한다.
