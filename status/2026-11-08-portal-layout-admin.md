# 2026-11-08 · 포털 앱 배치 — 관리자(권형하)만 옮기고 «틀 고정», 모든 직원이 같은 배치를 본다

대표 지시: 「화면에서 프로그램을 위아래로 이동가능하게 해라. 서로 다른 영역을 정리할 수 있게 하고 틀 고정하게 하면 각 영역에서만 움직이게 해라.
만약 의뢰인 업무를 내부관리로 보내고 틀고정으로 하면 내부관리에서만 움직이게 하는 것이다. 이 부분은 관리자인 권형하만 가능하게 해라.」

## 한 것 (`enter.html`)
- **저장 자리**: `data/app_config/portalLayout`(순서·영역·틀 고정). 이 자리는 이미 «읽기 직원 · 쓰기 관리자만(`uid_roles.isAdmin`)» 이라 **보안규칙은 새로 만들지도 넓히지도 않았다**(올릴 규칙 변경 없음).
  위임관리인(`isSubAdmin`)도 못 쓴다 — 화면도 `role === 'admin'` 만 켠다.
- **관리자 화면**: PC 는 «업무 시스템» 옆 `✏️ 배치 편집`(예전 「🔓 이동 가능」 자리) → 켜면 편집 줄 · 영역마다 점선 · 앱마다 📌 틀 고정 단추 · 끌어서 위아래/다른 영역(빈 영역 포함).
  폰은 «내 메뉴 › ✏️ 앱 배치 편집» → 영역별 목록 창(☐ 고르기 · 번호 · 📌 · ▲▼ · 영역 고르개 · 여러 개 한꺼번에 «영역으로 보내기/틀 고정/풀기», 묻고 한 번에 저장). PC 도 편집 줄의 «목록으로 편집» 으로 같은 창을 연다.
- **틀 고정**: 📌 한 앱은 지금 있는 영역 안에서만 움직인다 — 끌기·▲▼·영역 고르개·일괄 옮기기 모두. 같은 영역 안 순서는 바꿀 수 있다.
- **직원 화면**: 편집 단추·편집 줄·📌·내 메뉴 항목이 **만들어지지도 않는다**. 관리자가 저장한 배치를 그대로 따른다. 직원이 앱을 끌어 ★ 자주 쓰는 앱 줄에 넣는 길은 그대로(배치는 안 바뀐다).
- **공용 배치가 아직 없을 때**는 예전처럼 각자 옛 저장값(`tilePrefs.order`·`rows`)을 따른다 — 배포한 날 아무 화면도 달라지지 않는다. 관리자가 처음 옮기는 순간부터 모두 같은 배치.
  「↩ 처음 자리로」는 저장값을 지우지 않고 «기본 배치를 새로 저장»한다(그래야 직원의 옛 개인 순서가 되살아나지 않는다).
- 준비중 앱은 계속 «영역 맨 끝»(대표 2026-10-09) — ▲▼·일괄 옮기기도 그 앞뒤를 건너뛰지 못한다.
- ⚠ **설정 창(`cfgSave`)은 `data/app_config` 를 통째로 바꾼다** — 저장 때 `portalLayout` 을 다시 얹는다(못 읽으면 저장하지 않는다). 안 그러면 설정 키 하나만 고쳐도 전 직원 배치가 지워졌다.
- 설정 창의 「줄 사이 이동 허용」(`tileCrossRow`)은 걷었다 — 눌러도 아무 일이 없는 죽은 스위치가 되기 때문. 안내 한 줄로 바꿨다.
- 예전 「고정됨」 잠금(`tilePrefs.locked`)도 걷었다. 저장돼 있던 값은 읽지 않는다(그대로 남아 있을 뿐).

## 검사
- 새: `tests/portal-layout-admin.test.js`(30) — 원본 함수를 떠서 가짜 화면에서 «돌려» 본다: 틀 고정 차단(계산·끌기·영역 고르개·일괄), 관리자만 서버 쓰기, 제자리 놓기는 안 쓰기, 서버 거절 때 되돌림,
  공용 배치 vs 옛 저장값, 직원 화면에 단추 없음, 설정 저장이 배치를 안 지움, 쓰기 규칙(생성기·적용본)이 관리자만, 목록 창 그리기·단추·일괄.
  일부러 기능을 망가뜨려(7곳 + 빈 칸 버그) 검사가 잡는지도 확인했다.
- 화면: 지어낸 자료(`tools/phone-audit`)로 PC 1366·폰 360 에서 관리자·직원 화면을 확인(옆넘침 0). 실제 끌기 이벤트로 영역 이동 → 저장 → 틀 고정 → 영역 밖 차단까지 돌려 봤다. playwright 가 없어 `phone-audit` 숫자 점검은 못 돌렸다.

## 남은 일 / 모르는 것
- 진짜 파이어베이스에서의 첫 저장은 아직 못 봤다(가짜 서버로만 확인). 배포 뒤 관리자 계정으로 한 번 옮겨 보고, 직원 계정에서 같은 배치가 보이는지 본다.
- 저장된 배치는 «새로 고침해야» 직원에게 보인다(실시간 반영은 안 했다).
- `APPS` 배열 가운데 쉼표만 있는 자리(빈 칸)가 하나 있다 — `forEach` 는 건너뛰지만 `for` 로 읽으면 죽는다(이번에 걸렸다). 손대지 않았다.
