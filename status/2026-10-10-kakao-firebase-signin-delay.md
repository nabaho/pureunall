# 휴대전화 카카오 로그인 Firebase 단계 지연 추적

- 2026-10-10 실기기 재측정: 저장 방식 준비는 30,659ms에서 1ms로 줄었다. 같은 기기의 새 시도는 카카오 서버 1,496ms, Firebase `signInWithCustomToken` 120,441ms로 전체 124,711ms였다. 이전 저장 세션 재방문 317초 기록은 이번 재측정에서 새로 생성된 값이 아니다.
- 카카오 복귀 화면에서 사용하지 않는 TOTP/MFA 모듈의 별도 Firebase Auth 초기화를 부팅 시점에서 제외했다. 비밀번호 MFA가 요구되거나 내 정보에서 등록을 볼 때 한 번만 지연 로드한다.
- Firebase 로그인 구간의 인증 API 리소스 시간·건수, 최초 Auth 관찰 완료 여부, 화면 숨김 여부를 진단에 추가했다. 주소·토큰·계정 정보는 저장하지 않는다.
- 현재 120초가 Firebase 통신인지 SDK 인증 초기화/기기 저장소인지 이 캡처만으로는 확정할 수 없다. 배포 후 같은 진단 화면의 새 항목으로 구분한다.
