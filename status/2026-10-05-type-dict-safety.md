일터·일터혁신 중복도 남아 있다. 푸른통합시스템 전 영역에 걸린다 — 어떻게 관리해야 문제없나」.

## 한 것 (pu-erp.html BizTypeCard + 머리 함수, 업무 기록은 안 건드림)
- 「복원」: 씨앗으로 통째 덮던 것 → «빠진 기본 유형만» 무엇을 더하는지 보여 주고 더한다. 지금 목록은 안 지운다.
- 삭제 전 쓰는 건수에 계약관리(contracts.typeCodes)도 센다. 지우기 직전 한 번 더 센다.
- 같은 약어·이름(띄어쓰기·점 무시, 숨긴 것 포함)은 추가·수정 때 막는다.
- 약어를 바꾸면 「번호가 두 갈래가 된다」, 현장클리닉·기술보호 이름이 빠지면 「그 계산이 못 찾는다」를 묻는다.
- 항목마다 hist(누가·언제·전→후, 최근 20) — 이름에 마우스를 올리면 마지막 변경이 보인다.
- 저장은 «지금 사전»을 다시 읽어 그 위에 바꿈 하나만 얹는다(bizTypeApply) — 동시 편집 덮어쓰기 줄임.
- 검사 `tests/biz-type-safety.test.js` 13개 — 일부러 망가뜨린 13가지 모두 운다.
