# 2026-10-09 · 「앱을 클릭하면 잠깐 카카오 로그인 화면이 팝업처럼 나온다」 — 고침 (fix/no-kakao-flash)

대표 보고(PC 크롬 포털 캡쳐): 「앱을 클릭하면 아주 잠깐동안 카카오톡 로그인 화면이 팝업처럼나온다 이거 완전히
안나오게 해라 모든 앱들에게서 계속 한번씩나오는경우 있다 반드시고쳐라」.

## 확인한 것
- 「카카오 로그인 화면」= 포털 로그인 화면(맨 위 노란 「카카오로 로그인」 단추)이다. 카카오 쪽 화면으로 실제로 넘어간
  것은 아니다 — 카카오 주소를 받는 서버 함수(kakaoAuthUrl) 호출은 하루 몇 번, 실제 로그인 때뿐이었다.
- 앱 화면 안에는 카카오 글자가 없다. 번쩍인 것은 «enter.html 문서»뿐이다.
- 대표 크롬에서 타일로 새 창을 여는 길(사진첩·기업정보함·업무관리·정부사업일정)은 0.01초 간격으로 기록해도
  로그인 화면이 한 번도 안 보였다 → 번쩍임은 «새로 여는 창»이 아니라 «숨어 있던 탭»이다.
- 대표 크롬 기록: 로그아웃 때 앱 탭이 「다른 창 로그아웃을 따라 나감」으로 로그인 화면으로 밀려난 자국이 있다.

## 원인 — 로그인 화면이 «다시 확인 없이» 보이던 길 셋
1. 로그아웃하면 열린 앱 탭들이 모두 로그인 화면으로 밀려나 뒤에 숨은 채 남는다. 다시 로그인한 뒤 그 탭이
   앞으로 나오면 브라우저는 «그려 둔» 로그인 화면부터 보이고, 그다음에야 파이어베이스가 다른 탭의 로그인을
   알아채 포털로 바뀐다 → 앱마다 한 번씩 번쩍.
2. 숨은 탭에서 40초 안전망이 가림막을 걷었다 — 숨은 탭은 인증 확인이 느리다.
3. 숨은 동안 «로그인 없음»이 잡혔다가 다른 탭의 로그인이 뒤따라 들어온다.

## 고친 것 (`enter.html`)
- `_loginGuard`: 탭이 숨을 때 로그인 화면 위에 가림막(「로그인 상태 확인 중…」)을 다시 세운다.
  다시 보이면 2초 동안 다른 탭의 로그인을 기다리고, 들어오면 포털이 다 그린 뒤 걷는다. 끝내 없으면 걷는다.
  입력하던 아이디·비밀번호가 있거나, 포털이 떠 있거나, 카카오 복귀 중이면 가리지 않는다.
- 숨은 탭에서 «로그인 없음»으로 드러냈으면 곧바로 다시 가린다.
- 40초 안전망은 숨은 탭에서 걷지 않고, 보일 때 걷는다.
- 그래도 번쩍이면 이 기기에 남긴다: localStorage `pu_login_flash_log`(최근 20건 · 어느 길·몇 ms·숨은 탭이었나·앱 창이었나,
  이름·주소 없음). 다음에는 추측하지 않고 이것을 읽는다.
- 검사 `tests/login-no-flash-on-return.test.js` 9개(지킴이와 부팅 스크립트를 가짜 문서·가짜 시계로 실제로 돌림) —
  일부러 망가뜨린 7가지 모두 운다. enter.html 을 읽는 검사 113파일 1641개 통과. 로컬 브라우저에서 숨김→보임 실제 동작 확인.

## 남은 것
- 대표 PC 크롬에서 «숨어 있던 탭»의 번쩍임은 내가 직접 재현하지 못했다(로그아웃을 해야 만들어지는 상태라 안 했다).
  또 보이면 크롬 포털에서 `pu_login_flash_log` 를 읽으면 어느 길이었는지 나온다.
