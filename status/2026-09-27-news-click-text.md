# 뉴스레터 — 글자를 눌러도 «단추와 같은 곳»으로 간다

대표 지시 2026-09-27 「원문 내려받기 전문보기를 클릭하면 각각의 자료가 나온다 이 단어 외에
내용을 클릭해도 다운받을 수 있게 해달라」

## 바꾼 것 (`js/pu-news-tpl.js`)

| 꼭지 | 눌리는 글자 | 가는 곳 |
|---|---|---|
| 주간노동뉴스 | 한 줄 제목 · 우리 말 | 「원문 ↗」과 같은 곳 |
| 고용·노동정책 자료 | 제목 · 우리 설명 | 「내려받기 ↓」와 같은 곳 (붙임 없으면 「자세히 보기 ↗」) |
| 판례·행정해석 | 제목 | 「전문 보기 ↗」와 같은 곳 — 펴는 표(`_법제처표`)까지 같다 |

- ⚠ **새 목적지를 만들지 않는다.** 단추가 가는 주소를 그대로 받는다. `href()` 는 같은 주소에
  같은 번호를 주므로 추적 목록도 안 는다. 자료는 붙임이 있으면 상세 쪽을 아예 안 부른다.
- ⚠ 대문 주소(「원문 ↗」을 안 다는 잣대)면 글자도 안 건다.
- ⚠ 글자 링크는 **색을 적는다** — 안 적으면 아웃룩·다음메일이 파란 밑줄로 칠한다.
- 웹 전문 보기의 팝업은 링크를 누르면 비켜 준다(`news-view.js` 의 `closest("a")`). 부딪히지 않는다.
- 2026-09-20 「자료 제목을 외부 상세 쪽으로 걸지 마라」와 어긋나지 않는다 — 붙임이 있으면
  글자도 «내려받기»로 간다. 붙임이 없을 때만 단추가 이미 가는 「자세히 보기」다.

## 옛 검사 둘을 덜 까다롭게

글자 «사이 거리»를 재던 두 곳(표 바로 뒤에 글 · id 에서 300자 안에 글)이 링크 태그(추적 주소
약 150자)가 끼면서 넘쳤다. 기능은 멀쩡하고 검사만 깨지는 자리라 «사이에 링크 태그가 올 수 있다»만 허락했다.
