# 경력관리 — ✏️ 한글 편집기를 프로그램 «안»에 넣었다 (2026-09-21)

가지: `feat/kcareer-hwp-editor`

## 대표 지시

> 필요시 hwp 화일 hwpx 화일을 모니터에서 직접 수정도 가능하게 만들고 싶다.
> 도데체 어떻게 해야 가능할까 … 검토해달라.

> **붙여라**

## 무엇이 됐나

서류 만들기 화면에서 **「✏️ 한글로 고치기」** 를 누르면
한글 프로그램 모양의 편집기가 그 자리에서 열린다. 메뉴·리본·눈금자까지 그대로다.

- 표·네모칸(☑)·글꼴·줄간격이 **한글에서 보던 그대로** 그려진다
- 칸을 눌러 **직접 친다** — 지우고, 넣고, 옮긴다
- 다 고치면 **「저장」** 한 번으로 우리 보관함에 되돌아온다
  (한글 왕복과 **같은 길** — `rhAdoptBase`. 길이 둘이면 언젠가 어긋난다)

### 실제로 돌려 본 것 (2026-09-21)

진짜 서식 한 장(`form-002.hwpx`, 5쪽·칸 440개)으로 왕복을 재 봤다.

| 잰 것 | 결과 |
|---|---|
| 편집기가 문서를 여는가 | ✔ 10쪽, 0.4초 |
| 친 글자가 되돌아오는가 | ✔ 「푸른시험글자」가 본문에 **꼭 한 번** |
| 우리 읽개가 다시 읽는가 | ✔ 칸 440개 · 쪽 5개 · 속파일 11개 — **원본과 같다** |
| 밖으로 나간 요청 | ✔ **0건** (망 기록으로 셈 — 글자 훑기가 아니라) |

## ★ 가장 무거운 것 — 서류가 밖으로 나가지 않는다

이음쇠(`@rhwp/editor`)는 npm 에 있지만 **23KB 껍데기**다.
기본값으로 쓰면 실제 편집기를 `https://edwardkim.github.io/rhwp/` 에서 틀(iframe)로 불러온다 —
**2026-09-05 에 막은 바로 그 구조**다. 주민번호·도장이 든 서류가 통째로 남의 서버로 간다.

그래서 **편집기 원본을 직접 지어 저장소에 넣었다**(`vendor/rhwp-studio`, MIT).

- `studioUrl:'vendor/rhwp-studio/index.html'` — 우리 것 한 곳으로 **굳혔다**
- 설정 칸(「한글 편집기 주소」)은 **이제 아무 데서도 안 쓴다**.
  ⚠ 칸은 남겨 두되 «안 씁니다»라고 화면에 적었다 —
  **어긋난 안내는 없는 것보다 나쁘다**. 거기 적힌 곳으로 서류가 나가면
  한 사람이 채운 설정으로 온 식구가 새는 꼴이 된다.
- 지을 때 만든 쪽의 안전 스위치를 켰다:
  `RHWP_DISABLE_EXTERNAL_WEBFONTS=1`(바깥 글꼴 끄기) · `RHWP_WITHOUT_HWPCTRL=1`(윈도 한글 제어 빼기).
  `RHWP_SUBSECOND` 는 **안 켰다**(개발용 WebSocket 이 들어간다).

## 넣은 것과 «안» 넣은 것 — 통째 11.6MB

| 뺀 것 | 왜 |
|---|---|
| `canvaskit*` 7.4MB | 그림 엔진. `canvas2d` 로 **똑같이** 그려지는 것을 눈으로 확인했다 |
| `samples/` | 견본 문서 — 우리 서식만 연다 |
| `sw.js`·`workbox-*` | PWA. `importScripts` 가 여기 있다 |
| `fonts` | **폴더가 아니라 바깥을 가리키는 18바이트 이음줄**이었다 (아래) |
| 큰 장식 그림 | 461KB·443KB 짜리 로고 |

## ⚠ 나는 404 둘 — 고장이 아니다

다음 사람이 이것을 쫓다 하루를 버리지 않도록 적어 둔다.

1. **`fonts/*.woff2` 다섯** — **만든 쪽 저장소에도 글꼴 파일이 없다.**
   `dist/fonts` 는 폴더가 아니라 `../../assets/fonts` 를 가리키는 18바이트 이음줄이다.
   글은 **PC 에 깔린 글꼴로 대신 그려진다** — 윈도에는 한글 글꼴이 있어 제대로 나왔다.
2. **`images/icon_small_ko.svg`** — 461KB 짜리 **장식 로고**라 일부러 뺐다.
   빈 화면 자리인데 우리는 늘 문서를 바로 열어 그 자리를 안 지난다.

## ⚠★ 지을 때 «반드시» `--base=./`

안 주면 `index.html` 이 `/assets/…` 처럼 **맨 위부터** 찾는다.
우리는 `vendor/rhwp-studio/` 아래에 두므로 404 가 나고 —
**틀은 뜨는데 속이 빈 채로 멈춘다.** 2026-09-21 에 실제로 여기서 한 번 막혔다.
`tests/kcareer-hwp-editor.test.js` ③-3 이 이제 기계로 지킨다.

## 남은 일
