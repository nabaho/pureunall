# 2026-09-28 · 카카오에서 돌아온 몇 초 — 로그인 화면이 보이던 것 (fix/kakao-login-flash)

대표 보고: 「로그인 했는데도 계속 이렇게 나오다가 화면으로 넘어간다」(로그인 화면 캡처).

## 까닭
카카오 승인 → 포털로 돌아옴 → 서버가 카카오에 확인(몇 초, 서버가 잠들어 있으면 더) → 포털.
그 몇 초 동안 로그인 화면이 그대로 떠 있었다. 게다가 «아직 로그인 전» 신호가 먼저 와서 가림막(스플래시)까지 걷었다.

## 고친 것 (enter.html)
- 주소에 code·state 가 있으면(카카오에서 막 돌아옴) 첫 줄에서 스플래시 + 「💬 카카오로 로그인하는 중…」.
- «로그인 전» 신호는 카카오 확인 중이면 스플래시를 안 걷는다. 성공이면 포털이 그린 뒤 걷고, 실패면 kkEndReturn 이 걷고 까닭을 보인다.
- 안전망 20초(서버 깨우기 여유).

## 확인
- 검사 4개 추가(망가뜨린 4가지 모두 운다) · 관련 1,513개 통과.
- 실제 화면을 20ms 마다 재 봄: 여는 순간부터 「로그인하는 중」, 실패하면 걷히고 까닭이 뜬다.
