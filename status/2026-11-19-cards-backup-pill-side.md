# 2026-11-19 · 기업정보함 PC 옆줄 — 「백업·복구」 알약이 「🔒 개인 폴더 열기」를 덮던 것 (claude/cards-backup-pill-side)

대표 화면 2026-11-18(1903px 크롬): 기업정보함(`pu-cards.html`) 왼쪽 아래에 떠 있는 파란 «백업·복구» 알약
(`#pu-backup-admin-button`, `js/pu-backup.js` 가 left:12px·bottom:58px 에 붙박음)이 남색 옆줄 맨 아래
«🔒 개인 폴더 열기»·«⚙️ 환경설정» 단추 위에 겹쳐 있었다.

## 고친 것

- 메일 창에서 쓰던 길(2026-09-06)을 기업정보함 PC 옆줄까지 넓혔다 — 옆줄 맨 아래(`pcSideBottomHtml`)에
  «🗄 백업·복구» 줄을 «대표일 때» 모든 갈래(명함·사업자·기업 상세·근로자·자료함·메일)에 그린다.
  누르면 알약을 그대로 누른다(`mbBackupOpen`) — 백업 창을 두 벌로 짓지 않는다.
- 알약은 그 줄(`.pcside-backup`)이 «보일 때만» 비킨다:
  `body.pc:has(#pcRoot:not([hidden]):not(.sidehidden) .pcside-backup) #pu-backup-admin-button{display:none!important}`.
  직원(줄 없음)·옆줄을 접었을 때(`.sidehidden`)·폰 차림에서는 알약이 그대로 떠 길이 끊기지 않는다.
- 메일 창 규칙(`body.mailview …`)은 그대로 두었다. 다만 `body.mailview` 는 폰 차림 render(`renderMobile`)에서만
  붙어 PC 메일 창에서는 false 였다(실측) — 옛 규칙은 PC 메일 창의 알약을 못 감추고 있었다.
  새 규칙이 PC 메일 창·자료함까지 함께 감춘다.

## 왜 공용 앱바가 아니라 앱에서

- 공용 앱바(`js/pu-appbar.js`)의 떠 있는 단추 정리는 «폰(640px 이하)» 몫이고 «PC 는 그대로»가 그 파일의 규칙이다.
  이번 겹침은 기업정보함 PC 의 왼쪽 옆줄 배치 탓이라, 메일 창과 같은 자리에서 같은 방식으로 풀었다.
- 「숨기기만 하면 길이 끊긴다」(STATUS.md 되풀이된 실수 12)를 지키려고 감추는 조건을 «대신 누를 줄이 화면에 있을 때»로 걸었다.

## 확인

- 임시 미리보기(지어낸 자료 + `tools/phone-audit/fake-firebase.js`, 내장 브라우저):
  - PC 1366×768 명함 목록: 알약 숨음, «🔒 개인 폴더 열기 · ⚙️ 환경설정 · 🗄 백업·복구» 세 줄 모두 그 자리에서 제 단추가 눌린다(`elementFromPoint`).
    «🗄 백업·복구»를 누르면 «자동 백업 · 시점 복구» 창이 열린다.
  - 기업 상세·근로자: 같은 세 줄, 알약 숨음 · 옆줄 접기: 알약 다시 뜸 · 직원(isAdmin 아님): 백업 줄 없음, 알약 그대로.
  - 메일 창: «‹ 기업정보함으로 · 개인 폴더 · 환경설정 · 백업·복구» 모두 눌림, 알약 숨음.
  - 폰 360×780: 전과 같다 — 알약은 공용 앱바가 감추고 «즐겨찾기» 목록 맨 아래 «🗄 백업·복구» 줄이 그대로, 옆넘침 0.
- 검사: `tests/mail-backup-pill-overlap.test.js` 를 새 규칙으로 고쳤다(옛 ⑤ «기업정보함에서는 알약 그대로»가 바로 이 겹침을 남겨 둔 것).
  CSS 이름을 박지 않고 «그린 백업 줄에만 붙은 class 로 알약을 감추는 CSS 가 있는가 · 그 CSS 가 PC 전용이고 옆줄을 접으면 풀리는가»를 본다.
  사본에서 ① 조건을 메일 전용으로 되돌림 ② CSS 지움 ③ `:not(.sidehidden)` 뺌 ④ class 지움 — 넷 다 빨갛게 잡혔다.

## 남은 것

- 부대표(`isSubAdmin`)는 알약은 받지만 기업정보함 `state.isAdmin` 은 거짓이라 백업 줄이 안 그려진다 —
  그래서 부대표 화면에서는 알약이 그대로 떠 있다(길은 있음). 그 화면의 겹침은 따로 재어 보지 않았고, 이번에 손대지 않았다.
