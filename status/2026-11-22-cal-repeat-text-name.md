# 2026-11-22 · 푸른 캘린더 — 같은 이름 함수 `반복글` 둘 (고침)

대표 「고쳐 주세요」 — 11-15 자동 검토가 «이번 일과 별개의 예전 버그»로 짚은 것(`status/2026-11-15-cal-restore-people.md` 후속).

## 무슨 일이었나
- `pu-cal.html` 의 한 `<script>` 안에 같은 이름 함수가 둘이었다: `반복글(규칙)`(RRULE → 「매주 월·수요일 반복」)과 `반복글(ymd)`(새 일정 입력 창의 «반복 고르기» 글 — 날짜를 받아 객체 `{D,W,M,Y}` 를 돌려줌).
- 같은 스크립트 안의 같은 이름 함수 선언은 «뒤에 온 것이 앞의 것을 덮는다». 그래서 구글 상세가 `반복글("RRULE:…")` 을 부르면 객체가 돌아와 상세 창의 「🔁」 줄이 **[object Object]** 로 나왔다(구글 연결로 받은 반복 일정에서만).
- 예전 시험은 함수를 «하나씩 따로 떼어» 돌려서 이 겹침을 못 잡았다. 고치기 전 파일에서 두 함수를 같은 상자에 올려 부르면 「[object Object]」 가 그대로 재현됐다.

## 고친 것
- 입력 창 쪽을 `반복고르기글(ymd)` 로 이름을 나눴다(부르는 곳 `반복알림줄` 한 군데). RRULE 글 `반복글(규칙)` 과 부르는 곳(`구글더줄`)은 그대로.
- 화면에 보이는 것은 입력 창(「매주 (수요일)」 등)도, 상세 줄(「매주 월·수요일 반복」)도 «글자 그대로» 같다 — 이름만 나눴고 동작은 건드리지 않았다(상세 줄은 깨졌던 것이 바로잡힌다).

## 검사
- 새 `tests/cal-no-duplicate-functions.test.js` 3건 — ① pu-cal.html 맨 앞 칸 function 이름이 겹치지 않는다(다음에 또 겹치면 바로 걸린다) ② 두 함수가 따로 있고 부르는 곳이 각자 제 것을 부른다 ③ 두 함수를 «같은 상자에 함께» 올려도 「🔁」 줄이 글자로 나온다. 고치기 전에는 3건 모두 실패했다.
- `tests/cal-google-form.test.js` 의 함수 이름만 새 이름으로.
- 확인 못 한 것: 구글을 실제로 이어 반복 일정을 여는 화면(구글 로그인이 필요해 미리보기로 못 봤다) — 위 «같은 상자» 시험으로 갈음했다.
