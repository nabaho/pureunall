# 2026-10-04 · 환경설정도 폰에서 16px — 마지막 예외를 없앤다

- 가지: `fix/phone-env-16px`
- 왜: 대표 지시 「환경설정화면도 올리고 목업」
  (앞선 PR #1970 에서 16개 앱을 올렸는데 **환경설정만 예외**로 남겨 두고 보고했었다)

## 무엇이 남아 있었나

`css/pu-erp.css` 의 폰 규칙(@media ≤768px) 안에 이렇게 적혀 있었다 —

```
/* 환경설정 내 input/select/button: iOS zoom 강제 16px 예외 */
.env-section input, .env-section select, .env-section textarea { font-size: 12px !important; … }
.env-section input[type=number] { height: 24px !important; font-size: 11px !important; }
```

앱 전체를 16px 로 올려도 **더 «센» 규칙이 이긴다.** 그래서 환경설정에서만
칸을 누를 때마다 화면이 확대됐다. 빽빽한 표를 폰에 욱여넣으려던 자리다.

## 고친 것

| 무엇 | 지금 | 고친 뒤 |
|---|---|---|
| 입력칸·고르는 칸 | 12px | **16px** |
| 숫자 칸(정렬 순서 등) | 11px · 높이 **24px 못 박음** | **16px** · `min-height:30px` |
| 표 글자 | 11px | 그대로 |
| 표 안 작은 단추 | 10.5px · 22px | 그대로 |
| 칸 여백 | 4px 6px | 그대로 |

⚠ 높이를 24px 로 못 박아 두면 16px 글씨가 잘린다 — 최소 높이로 바꿔 글씨에 맞췄다.

## 치르는 값 — 실제로 재서 보여 드렸다

브라우저에 같은 규칙으로 두 벌을 그려 쟀다: **줄 높이 31px → 37px(줄당 +6px).**
계좌·카드 마스터처럼 14줄이면 화면이 **+84px** 길어진다(폰 한 화면의 10% 남짓).
표는 지금도 옆으로 밀어 보게 되어 있어 칸이 넓어져도 잘리지 않는다.
목업(`폰-환경설정-목업.html`)으로 대표님께 먼저 보여 드렸다.

## 검사 — 「올렸다」만으로는 모자랐다

`tests/phone-input-zoom.test.js` 에 **「도로 내리는 자리」**를 보는 자를 더했다(4개째).
앞선 검사는 「16px 규칙이 있는가」만 봐서, 환경설정처럼 **더 센 규칙으로 다시 내리는 것**을
못 잡았다. 이제 폰 규칙 안에서 `input`·`textarea` 글씨를 16px 아래로 내리면 그 자리에서 운다.

- ⚠ `select` 는 뺐다 — 손대면 자판이 아니라 고르개가 뜨고, 좁은 띠에 일부러 작게
  맞춰 둔 자리가 **일곱 군데**다(아래 「남은 것」).
- 되돌림 둘 다 운다: 환경설정을 12px 로 되돌리기 · 숫자칸을 11px·높이24 로 되돌리기.

## 남은 것 — 대표님 판단

폰 규칙 안에서 아직 16px 아래인 **`select` 일곱 군데**:

| 앱 | 자리 | 지금 |
|---|---|---|
| 푸른이알피 | `.user-tbl select` (직원표) | 10px |
| 푸른이알피 | 가로 스크롤 상자 안 `select` | 11.5px |
| 푸른이알피 | `.tb-filters > select` | 12px |
| 푸른이알피 | `.ld-bar select` (연장 막대) | 11.5px |
| 업무관리 | `.fbar select.tool` | 11px |
| 기금 | `td select` (표 안) | 11px |
| 홈페이지 | `.appbar select` | 12px |

고르개라 자판처럼 바로 확대되지는 않지만, 기종·판에 따라 다르다.
올리면 그 띠들이 높아진다 — 올릴지 말씀해 주시면 같은 방식으로 하겠다.
