# 지역뉴스 5단계 — 중단된 승인 자동복구

## 막은 상황

- 관리자가 후보를 선점한 직후 브라우저를 닫거나 연결이 끊기면 `승인처리중`에 남을 수 있었다.
- 회차 저장은 성공하고 후보 상태 확정만 실패한 경우와, 회차 저장도 안 된 경우를 구분해야 한다.
- 구분 없이 잠금을 풀면 이미 담긴 후보가 다시 승인되어 같은 뉴스가 두 번 들어갈 수 있다.

## 복구 규칙

- 화면을 열 때 `승인처리중` 후보만 점검한다.
- 어느 회차든 같은 `후보Id`가 있으면 후보를 `승인`으로 확정하고 승인회차와 복구결과를 남긴다.
- 회차 어디에도 없고 선점 후 10분이 지난 후보만 `검토대기`로 돌린다.
- 10분 이내 작업은 정상 진행 중일 수 있으므로 건드리지 않는다.
- 후보 한 건의 상태와 `revision`을 transaction 안에서 다시 확인해 최신 변경을 덮어쓰지 않는다.
- 모든 복구는 revision을 올리고 복구일·복구결과를 남기며 자료를 삭제하지 않는다.

## 검증

- 지역뉴스 수집·검토·철회·중단복구·주소별 발송 관련 시험 28개 통과.
- JavaScript 캐시 버전 검사와 diff 공백 검사 통과.
