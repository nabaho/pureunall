# 💬 취업규칙 — 이 문서에 묻기 (RAG 1단계) (2026-10-30)

상태: 완료(화면·검사) · 실제 AI 답 품질은 아직 못 봄

대표: 「취업 규칙을 rag 로 관리하려면 어떻게 해야되나」 → 검토(코딩 없이) → 「여기 프로그램에」(✏️ 검토·개정 화면 갈무리) → 목업 → 「추천대로」.
설계 `docs/superpowers/specs/2026-10-03-취업규칙-새로짓기-design.md` §13.

## 한 것
- **💬 묻기** — 원본 미리보기 단추 줄 맨 앞(목업 ①) + 오른쪽 칸 탭 «자동 검토 결과 | 💬 묻기»(목업 ②, 폰에서는 묻기 칸이 위로).
- 지금 연 문서의 **원본**에서 질문과 관련된 조를 **AI 없이** 낱말로 고른다(`js/rules-v2/lib-ask.js` — 두 글자 조각 겹침, 드문 조각·조 제목은 무겁게,
  일상어 사전: 결혼 → 경조 · 월급 → 임금 · 야근 → 연장근로 …). 많아야 10개(목업 ③). 걸리는 조가 없으면 **AI 를 안 부른다**.
- 고른 조만 ✨ 다듬기와 **같은 길**로 보낸다 — 회사 이름 `{회사}`(질문 속 이름도) · kordoc 가림(사업자번호 포함) · **가림 실패면 안 보냄** ·
  `PuAiCall.ask(app:'rules')` · 이번 달 한도면 물어본 뒤 manual.
- 답: 근거 조 단추(누르면 왼쪽 원본의 그 조로 — 📍 와 같은 `focusPreviewArticle`) · **보내지 않은 조를 근거로 들면 빼고 ⚠ 로 센다** ·
  근거 없음/못 믿음을 따로 적음 · 같은 조 자동 검토(검토 전 / ✓ 지적 없음 / ⚠ 수 — 누르면 검토 탭) · 「AI 가 읽은 조 n개」 · ⚠ 효력 판단은 노무사.
- 답은 **저장하지 않는다**(화면 보는 동안 최근 10개). 문서를 바꾸면 비운다. 열람 전용이어도 묻는다(읽기만).
- 답 JSON 읽개는 `PuRulesPolish.findJson` 한 벌로 꺼냈다(✨ 다듬기도 같은 것을 쓴다 — `lib-polish` 캐시 3→4).
- 곁들여 고침: 원본 미리보기 머리(flex)에서 1366px 일 때 제목·단추가 「원본 미리/보기」·「전체/보기」로 접히던 것(main 에서도 그랬다) — 제목·단추는 한 줄, 설명 딱지가 줄어든다.

## 새로 생긴 것 · 안 생긴 것
- 서버 함수·보안규칙·저장 자리 **없음**(✨ 의 readDoc `app:'rules'` 몫을 함께 쓴다). 온톨로지 개체·쓰기 경로 없음.
- 하루 AI 몫은 회사 전체가 함께 쓴다 — `ai_read_tally` 의 `rules` 칸이 ✨ 와 💬 를 함께 센다.
