# P박스(pu-pbox) 검색 중심 미니멀 UI 개편

## 변경 요약
- **최상단 바 & 사이드바 정적 건수·홍보 안내 제거**: 상단 홍보 문구(`[안내] ...`)와 정적 법령·판례 건수 배지, 사이드바 항목별 정적 건수 배지 및 장문 안내 문구를 제거하고, 실제 동기화가 진행 중일 때만 상단 상태 알약이 표시되도록 단순화했습니다.
- **중앙 집중형 검색 홈 & 영역 직행 탭**: 홈 화면의 중복 조작 설명 줄을 제거하고, `920px` 중앙 검색 스테이지·빠른 영역 전환 탭(`통합검색`, `판례·재결`, `행정해석`, `법령·조문`, `노무사회 자료`, `외부 사이트`)·원클릭 핵심어 칩·2열 대시보드(`최근 본 자료`, `프로젝트`)로 정돈했습니다.
- **하위 화면 상단 빠른 검색창 & 접이식 상세 도구**: 통합 검색·법령 조회·외부 사이트·자료 수집 화면의 장문 설명 상자를 제거하고, 검색창을 최상단에 배치하는 한편 보조 도구(쟁점 파인더·외부 DB 직행·5단계 체크리스트)는 접이식 서랍(`<details class="pbox-slim-drawer">`)으로 정리했습니다.
