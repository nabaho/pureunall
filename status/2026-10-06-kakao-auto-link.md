# 2026-10-06 · 카카오 첫 연결 자동 마무리

- 연결 전 카카오 계정으로 로그인한 직원은 아이디·비밀번호를 한 번 확인한다.
- 비밀번호 확인 뒤 별도 확인창이나 내 정보 찾기 없이 카카오 연결 화면으로 자동 이동한다.
- 처음 시도한 탭에서 15분 안에 로그인한 경우에만 자동 연결한다.
- 카카오 계정 자체는 서버가 다시 확인하므로 공용 휴대전화에서 다른 계정이 잘못 붙지 않는다.
- 휴대전화 저장소 설정은 2초, 직원명부는 3.5초, 전체 카카오 복귀는 15초를 넘기면 자동 복구한다.
- 카카오 서버 호출은 10초 뒤 중단하고 다시 시도할 수 있는 안내를 보여 준다.
- 로그인 복귀 시 인증표·저장소·직원명부를 동시에 준비해 순차 대기 시간을 없앴다.
- 인증 성공 결과를 받은 즉시 포털을 열어 인증상태 재알림을 한 번 더 기다리지 않는다.
