# 카카오 복귀 뒤 진행 화면 재등장 방지 (2026-10-17)

## 제보와 확인

- 휴대전화에서 카카오 로그인 → 포털 잠깐 표시 → 「카카오로 로그인 중」 → 포털의 왕복이 반복된다는 제보.
- 이 진행 문구는 `enter.html`을 `code`와 `state`가 붙은 콜백 주소로 **새로 열 때** 표시된다.
- `js/pu-version.js`는 카카오 코드 교환·포털 타일 준비 중에만 업데이트를 미뤘다. 포털을 보여 준 직후에는 대기 중인 버전을 자동 적용하여 페이지를 다시 열 수 있었다.
- `js/pu-kakao.js`는 콜백 주소 정리를 시도하지만 `history.replaceState` 실패를 허용한다. 실패한 모바일 브라우저에서는 버전 감시기의 새 주소에 일회용 인증값이 그대로 복사될 수 있었다.
- 확인 당시 운영 `version.json`과 `enter.html`의 배포 SHA는 같았다. 특정 휴대전화의 캐시·브라우저 동작은 직접 관찰하지 못했으므로 위 경로는 코드로 확인한 재발 조건이며, 유일한 실제 원인이라고 단정하지 않는다.

## 조치

- 카카오 복귀 표시를 버전 감시기 실행 전으로 앞당겼다.
- 해당 복귀 문서에서는 포털 표시 뒤에도 자동 업데이트를 보류한다. 새 버전 단추의 명시적 적용은 가능하며, 다음에 여는 앱 화면의 자동 업데이트는 그대로다.
- 버전 교체 주소에서 `code`, `state`, `error`, `error_description`을 항상 지운다.
- 카카오 복귀 중/포털 준비 중/포털 표시 뒤 자동 새로고침 금지 및 수동 주소 정리를 회귀 검사에 추가했다.

## 확인할 일

- 배포 뒤 실제 휴대전화의 카카오 로그인에서 포털이 한 번만 열리는지 확인.
- 다른 경로로 다시 깜빡이면 `pu_login_flash_log`와 네트워크 탐색 기록으로 재확인. 인증 코드를 포함한 전체 URL은 공유하지 않는다.
