# 휴대전화 카카오 계정 창 반복 완화 (2026-10-22)

- 제보: 휴대전화 설치형 포털에서 카카오 계정 창과 포털 로그인 화면이 번갈아 보이고, 카카오가 접속 정보 변경 경고를 표시함.
- 확인: 10/21 변경 뒤 일반 모바일 브라우저에서도 매번 `prompt=login`을 보내 기존 카카오 세션을 버리고 카카오 계정 화면을 다시 열었다. 카카오 공식 문서상 이 옵션은 재인증용이며, 카카오톡 내부 브라우저에서는 지원되지 않는다. 카카오톡으로 로그인한 모바일 웹이 포털로 자동 복귀하지 않는 경우도 공식 FAQ에 안내돼 있다. 포털에서 인증 창을 새로 여는 코드는 노란 로그인 단추의 클릭 처리 한 곳뿐이므로, 손대지 않아도 창이 다시 열리는지는 휴대전화에서 확인해야 한다. 화면의 「지난번 로그아웃 · 로그아웃 단추 누름」은 실제 버튼 클릭 기록이며 자동 재로그인·재로그아웃의 증거는 아니다. 카카오의 접속 정보 변경 경고 원인은 앱 코드만으로 단정할 수 없다.
- 수정: 모바일 브라우저·설치형 포털에서는 강제 재인증 요청을 빼 기존 카카오 세션을 이용한다. PC에서는 계정 재확인을 유지한다. 인증표·state 확인·직원 연결은 변경하지 않았다.
- 검사: PC, Android 일반 브라우저, 모바일 웹뷰, 카카오톡 내부 브라우저의 요청 분기 및 카카오 복귀 검사. 실제 휴대전화에서 카카오 계정 창 전환 여부는 배포 뒤 재현 확인이 필요하다.
