## 왜 고쳤나

앞 판은 **구글 쪽 PostgreSQL**(파이어베이스 SQL Connect = 옛 Data Connect + Cloud SQL)을 견주지 않고
«급여는 수파베이스»로 권했다. 그 서비스는 2026-08-09 에 실제로 만들었다가 10/07 지운 것이다.

- 그대로: 지금 프로그램은 파이어베이스 · 급여 아웃소싱은 PostgreSQL.
- 바뀜: 어디에 둘지는 **구글 Cloud SQL 먼저 반나절 시험**(SQL Connect 를 빌드 없이 CDN 으로 부를 수 있나) →
  되면 구글, 안 되면 수파베이스 또는 Cloud SQL + 우리 서버 함수.
- 구글로 기우는 까닭: 로그인·재직자 표시·청구서(세금계산서)·요금 감시가 한 집 · 브라우저는 정해 둔 질의만 ·
  고객사 재위탁 동의(개인정보 보호법 제26조 제6항)에 새 회사가 안 는다.
