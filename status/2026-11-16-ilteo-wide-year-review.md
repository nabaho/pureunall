# 2026-11-16 · 📂 일터상생혁신 화면 좌우 전체폭 확장 · 최신 연도순 정렬 · 연도별 필터·즉시검토 구축

가지: `feat/ilteo-wide-year-review` (`main`에서 분기)

## 한 것
- **화면 좌우 100% 전체폭 레이아웃 개방 및 와이드 좌우 분할 검토 (`ilteo.html`, `js/pu-ilteo-view.js`)**:
  - `main`의 `max-width: 1360px; margin: 0 auto` 제한을 제거하고 `width: 100%; max-width: none; margin: 0`으로 변경하여 넓은 모니터에서 좌우 여백 낭비 없이 화면 전체 폭을 사용하도록 개편.
  - 와이드 데스크톱(`1440px` 이상)에서 탭 1(`📂 사업장 · 메일 감지`)을 **좌측(사업장 목록 · 연도 필터) + 우측(연도별 · 사업장 즉시 검토 패널, `sticky` 고정)** 2단 좌우 분할(`.proj-split.split-on`, `[📐 검토창 접기/펴기]` 토글 지원)로 구성하고, 탭 3·4의 보고서 7개 섹션 편집 목록(`.rpt-sec-list`)도 와이드 화면(`1360px` 이상)에서 2열 좌우 그리드로 배치.
  - 사업장 표에 전용 **`연도` 열**(`.yr-col`)을 분리하여 상호가 긴 사업장에서도 수행연도 배지가 말줄임(`...`)으로 잘리지 않도록 개선하고, 셀 최대 폭을 와이드 화면에 맞게 확장.
- **최신 연도순(`2026→2015`) 기본 정렬 고정 및 다중 정렬 지원 (`js/pu-ilteo-view.js`)**:
  - 기존 `updatedAt`(백필 일괄 적재 시각) 기준 정렬로 인해 연도가 뒤섞여 보이던 문제를 해결하여, `sortProjects`의 기본값(`year_desc`)을 **수행연도 내림차순(2026년 → 2015년) → 미확인 메일 우선 → 상호 가나다순**으로 고정.
  - `#projSort` 정렬 선택기(`최신 연도순` / `과거 연도순` / `사업장명순` / `최근 작업순`)를 추가하고, 자동 발견 후보(`DISCOVER_LIST`), 기초·후속 수집 카드(`preCards` · `postCards`), 상단 작업 사업장 전환 셀렉트(`<optgroup label="2026년 (N건)">`) 모두 최신 연도순으로 통일.
- **원클릭 연도별 필터 바 · 연도별 검토 요약 · 즉시 검토 패널 및 연도별 종합검토 모달 (`ilteo.html`, `js/pu-ilteo-view.js`)**:
  - 상단 **원클릭 연도 필터 칩 바(`#yearQuickBar`)** 및 실시간 건수 표시 드롭다운(`#projYear`: `2026년 (N건)` ~ `2015년 (N건)`)을 양방향 동기화.
  - **연도별 검토 요약 바(`#yearSummaryBar`)**: 선택한 연도(또는 전체)의 대상 건수 · 수집 자료 수 · 중간/최종보고서 수록 건수 · 주요 개선과제를 집계 표시하고 `[◀ 최신 연도]` / `[과거 연도 ▶]` 원클릭 연도 이동 제공.
  - **우측 즉시 검토 패널(`#projReviewBox`)**: 목록에서 행을 클릭하거나 `[◀ 이전]` / `[다음 ▶]`으로 이동하면서 화면 전환 없이 우측에서 곧바로 `📋 요약·수집자료(원문보기)` · `📊 중간보고서 7개 섹션 전문` · `📑 최종보고서 7개 섹션 전문` 열람 및 PPTX 다운로드 가능.
  - **`[📑 연도별 검토표]` 모달(`openYearReviewModal`)**: 2026~2015년 연도별 수행 건수·수록 현황·주요 과제를 한눈에 비교하고 `[이 연도 검토 →]`로 즉시 필터 진입 가능.
