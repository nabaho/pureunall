# 2026-09-20 step2-share — 2걸음(다): 비고 고치기 · 2걸음 끝

대표 지시 「0부터 순서대로」 → 2걸음의 마지막.

## 이것으로 «이알피로 돌려보내던 자리»가 하나도 안 남았다

2걸음 시작할 때 푸른 캘린더가 못 하던 것이 넷이었다 —

| 무엇 | 어떻게 됐나 |
|---|---|
| 연간 한도 | **지움** (2걸음-나, 아무도 안 씀) |
| 이음강의 기록 | **지움** (2걸음-나, 아무도 안 씀) |
| 외부 공유 링크 발급·발행 | **옮김** (2걸음-가) |
| 개인 비고 | **옮김** (이번) |

`data-erp="dash/ieum"` 링크 수: **4곳 → 0곳**.

## 비고는 담기는 자리가 둘이다 — 그대로 따랐다

이알피가 그렇게 담아 왔다. 옮겨서 한 자리로 합치고 싶어도 지금 하지 않는다(옮기다 옛 글을 잃는다).

- 외부 인원 → `external_staff` 레코드의 `note` 칸 → «레코드 표»라 칸별 저장 문(`save`)
- 내부 직원 → `data/ieum_notes` 의 `{ 사번: 글 }` → 한 덩이 지도라 새 `saveNotes`

## 누가 고칠 수 있나

**로그인한 직원 누구나.** 서버 규칙(`data/$other` = LOGIN)이 그렇게 열려 있고,
이알피도 「전 직원 수정 가능 — 확정 사양」이었다. 같게 뒀다(색·계정 잇기는 관리자만인 것과 다르다).

## 조심한 것

- 비고 단추가 «줄 펼치기»를 건드리지 않게 퍼짐을 멈췄다 — 「끌리는 것 안의 끌기」와 같은 덫.
- 빈 글로 저장하면 칸을 **없앤다**(빈 글자를 쌓지 않는다).
- 고친 뒤 그 표 하나만 다시 받는다.
