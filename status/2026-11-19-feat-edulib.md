## 만든 것
- **새 앱 `pu-edulib.html`** — 포털 «자료함» 줄 타일 🎓 법정교육자료함(재직 직원 모두). 탭 넷:
  - 📊 한눈에 — 숫자 넷(모은 자료·자료함에 원본·PC에만·검토 대기) · 강의 종류 카드(왼쪽 파란 띠 = 법정 의무교육 5종, 근거 조문 안내) · 연도×종류 표(칸 누르면 그 목록)
  - 📚 자료 — ☐ + 번호 목록, 종류별·연도별 묶기, 거르개(종류·연도·형식·상태·원본 위치·법정만·휴지통), 고르면 «⧉ 나란히 보기(4건)»·«🪟 새 창으로 각각(6개)»·종류 바꾸기·참고 가능으로·휴지통
  - ＋ 넣기 — 파일·폴더 끌어놓기/고르기(이름·폴더로 종류·강의일을 미리 채움), «📥 PC 목록 가져오기»(아래 스크립트가 만든 JSON), 같은 파일 알림(sha256 → 이름+크기), PC 목록에 있던 것은 «원본만 붙임»
  - ✉ 메일에서 찾기 — **관리자만**. 메일함 머리글·첨부 이름을 훑어 강의자료로 보이는 첨부를 고르고, 읽음 표시를 바꾸지 않고(peek) 원본 그대로 자료함에 복사
- **보기 칸** — PDF·한글·엑셀은 푸른 문서뷰어의 격리 칸(`pu-viewer-frame.html`, sandbox allow-scripts)에서, pptx·docx 는 슬라이드별 «글자만» 뽑아(`js/pu-edulib-preview.js`), 영상·소리·그림은 그대로. 옛 ppt·압축은 원본 내려받기 안내.
- **자세히·검토** — 제목·종류·강의일·강의처·상태·개인정보·메모 고치기(원본 파일 정보는 못 바꿈), 검토 메모 남기기, PC에만 있는 것은 «📤 원본 올리기».
- **원본 유지** — 받은 바이트 그대로 창고 `edulib/{id}/{원래 이름}` 에 올림(변환·압축 없음, `contentDisposition` 에 원래 이름). 창고 규칙 «새로 쓰기만»·지우기 금지·1GB. 실시간DB 는 지우기 금지(_deleted 표식만).
- **강의일은 «추정»을 가른다** — 이름·폴더·메일 날에서 찾은 것은 «추정» 딱지, 사람이 고치면 «확정»(dateFrom:'manual'). 파일 수정일은 강의일로 쓰지 않는다.
- **`scripts/edulib-scan.js`** — 내 PC(C·D·E·F·H)를 «읽기만» 해서 강의자료 목록 JSON 을 바탕화면에 만든다. 회의자료·증명서·신청서·정산 폴더는 뺀다. OneDrive «바탕 화면» 사본·저장소는 건너뜀.
- 분류 규칙 `js/pu-edulib-classify.js`(PC 스크립트·화면 공용), 셈 `js/pu-edulib-core.js`.
