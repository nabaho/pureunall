# 2026-09-19 · 푸른 캘린더 — 아이콘을 «그린 것」으로 (2번, 빨강 머리띠)

대표 지시 2026-09-19 「아이콘 바꾸고싶다. 샘플보여달라.」→ 그림글자 열두 가지 →
「캘린더 종류 20개 더 달라 보고 판단하게」→ 달력 그린 것 스무 가지 → 「2」

## 왜 그림글자를 버렸나

그림글자에 달력은 📅 📆 🗓️ 셋뿐이다. 셋 다 포털 타일 크기(38px)로 줄이면
서로 같아 보인다 — 애초에 ⏰(알람시계)로 갔던 까닭이 「정부사업일정과 같은
📅 였다」였는데, 다른 달력 그림글자로 바꿔도 같은 문제가 되풀이될 뿐이었다.
그래서 아예 **손으로 그렸다**. 바탕화면 아이콘은 원래도 손으로 그리고 있었으니
같은 길이다.

대표가 스무 견본 중 **2번(빨강 머리띠)**을 골랐다 — 흰 몸통 + 빨강 머리띠 +
옅파랑 점 다섯. 큰 그림이 아니라 **포털에서 보이는 38px 크기**로 견본을 나란히
세워 보여 드렸고, 그 크기에서 고르셨다.

## 세 자리를 한 SVG 문자열로 맞췄다

| 자리 | 파일 | 담는 법 |
|---|---|---|
| 포털 타일 | `enter.html` (cal 항목 `icon` 필드) | `innerHTML` 로 꽂힌다 |
| 앱 바꾸기 목록(15px) | `js/pu-appbar.js` (cal 항목 `icon` 필드) | 새로 갈랐다(아래) |
| 탭 그림글자 | `pu-cal.html` `<link rel="icon">` | `encodeURIComponent` 로 안전하게 묶었다 |
| 머리글 작은 그림 | `pu-cal.html` `.brand` | 같은 SVG, 17px |
| 바탕화면 아이콘 | `icon-cal-192.png` · `icon-cal-512.png` | `scripts/make-cal-icon.js` 로 같은 그림을 다시 그려 구웠다 |

셋(포털·탭·바탕화면)이 **정확히 같은 그림**이어야 한 벌만 외운다는 규칙은
그대로다 — 이번엔 글자가 아니라 SVG 라 값도 그렇게 바뀌었다.

## 앱바가 «그림글자만» 담던 자리

`js/pu-appbar.js` 의 앱 바꾸기 목록(15px 아이콘)은 여태 `ic.textContent = a.icon`
하나였다. SVG 문자열을 그대로 textContent 로 넣으면 `<svg...>` 글자가 **그대로
찍힌다**(그려지지 않는다). `icon` 값이 `<svg` 로 시작하는지만 보고 그때만
`innerHTML` 로 갈아 꽂고, 안의 `<svg>` 에 100% 크기를 준다. 다른 15개 앱은
전부 그림글자라 이 가지를 타지 않는다 — 모양이 그대로다.

⚠ **이 자리를 실제로 도는 검사가 없었다.** 앱바를 도는 검사들은 팝업을 여는
손잡이가 있어야 닿는 코드라 여태 아무도 건드리지 않았다. 흉내 `<span>` 에
`innerHTML`·`querySelector` 를 «진짜처럼」 만들어 `tests/appbar-drawn-icon.test.js`
로 처음 돌려 봤다(3건).

## 검사

- `tests/app-icons.test.js` ⑤ — `icon` 값이 `<svg` 로 시작하면 favicon 을
  `decodeURIComponent` 로 되풀어 **문자 그대로 같은지** 본다(그림글자 앱은 예전 그대로
  `<text>` 안 글자를 뽑아 견준다).
- `tests/appbar-drawn-icon.test.js` **새로 만듦**(3건) — 그림글자는 `textContent`
  그대로, SVG 는 `innerHTML` + 안쪽 100% 크기, 판가름은 「`<svg` 로 시작하는가」
  하나뿐임을 본다.
- 색은 전부 팔레트 안이다 — `#dc2626`(red) · `#cbd5e1`(gray) · `#bfdbfe`(blue) ·
  `#ffffff`. `color-palette-apps.test.js` 예외 목록을 늘리지 않았다.
- 이빨 확인 다섯 가지 모두 걸림(포털·탭 SVG 어긋남, 앱바 textContent 로 되돌리기,
  앱바 svg 크기 안 주기, 판가름을 포함 여부로 바꾸기, 다른 타일이 같은 그림을 쓰게
  하기). 전체 **18,285건 통과**.
