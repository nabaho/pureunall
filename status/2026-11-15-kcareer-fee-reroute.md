# 경력관리 · 이력서 보관함에 잘못 들어온 «비용 서류»를 비용관리로 자동으로 보낸다 (2026-11-15, 대표 지시)

대표 지시: 「회의 비용관리에 있어야 될 내용이 이력서 관리에 있다. 이부분 jev 를 적용해서 만약에 잘못 입력되면 자동으로 비용관리로 보내게 해달라」.
화면 속 서류는 어느 협회가 낸 지급확인서가 이력서 보관함(파일 이름이 날짜뿐인 `____2026.10.12`)에 앉아 있던 것이다.

- **왜 들어왔나**: «올리기» 화면(`rhAutoSaveDomain`)에는 «협회 서류 + 지급확인서·상담비 낱말이면 비용 서류로» 판정이 있었지만(2026-10-12), 「5번 폴더 모두 넣기」·「지난 제출 이력서 모으기」·직접 추가 같은 다른 입구는 그 판정을 거치지 않고 `set('resume', …)` 로 바로 담았다.
- **Jev 는 쓰지 않았다(대표 결정 2026-11-15, «규칙으로 자동 분류»)**: Jev(TypeSafe)는 서류 글을 미국 업체 서버로 보내고(주민번호·계좌만 가리고 이름·주소는 못 가림, 관리자만·하루 한도), 메일 자동분류도 같은 이유로 «기본 꺼짐»으로 둔 방식이다. 이번에는 글이 밖으로 나가지 않는 규칙 판정으로 했다. 시험이 «이 일을 하는 코드는 서버·AI 를 부르지 않는다»를 못 박는다.
- **규칙(js/kcareer-feeroute.js, 판정은 이 한 곳)**: ① 협회 서류(기관·이름·메모·본문에 «협회») ② 돈 받은 확인 낱말(지급확인서·지급조서·영수증·참석확인서·노무상담비·상담비·강사비·강사료·원고료·지급금액·비용지급·수당지급신청) ③ 이름·종류가 이력서·프로필·경력기술서·자기소개서·약력이면 제외 ④ 사람이 정한 것(feeKeep)은 판정 안 함 ⑤ 확신 없으면 안 옮김. 2026-10-12 «비용관리 한정 협회»를 그대로 따른다 — 협회가 아닌 곳의 지급확인서는 이력서 보관함 그대로(넓히려면 대표 결정). 결과에는 «찾은 낱말»만 담고 본문 조각·이름·번호는 담지 않는다.
- **자동(입구 전부)**: `set()` 한 곳에서 **이력서 보관함** 쓰기를 잡아(`feeRouteSoon`, 2.5초 디바운스 — 프로필·증명서 보관함은 자동 대상이 아니고 훑기 단추로만) **이 화면을 연 뒤에 담긴 서류만**(savedAt) 글을 이 기기 안에서 읽어(hwpx·docx 는 압축 안 XML, pdf 는 앞 3쪽 글자층, **.hwp 는 자동 길에서 열지 않는다** — 한글 엔진 7MB 를 사람 몰래 받게 되므로. 훑기에서는 7MB 이하만) 판정하고 비용관리 › 저장 서류(`feedoc`)로 옮긴다. 예전에 담긴 수백 건을 몰래 열어 읽지 않는다. 옮기면 「🧾 … 비용관리로 보냈습니다 · 이력서에 두려면 ↩ 되돌리기」 알림.
- **예전 서류**: 이력서 보관함 위쪽 「🧾 비용 서류 찾기」 → 훑어서 비용 서류로 보이는 것을 목록(☐ + №, 머리줄 ☐, 지금 있는 곳·기관·보낼 종류·찾은 낱말, 「N건 선택」)으로 보여 주고, **고른 것만** 「🧾 N건 비용관리로 옮기기」로 옮긴다. 고르기·훑기만으로는 아무것도 안 바뀐다. 글을 못 읽은 것(스캔 PDF·그림 등)은 건수로 알려 준다.
- **옮기기는 지우기가 아니다**: 같은 파일(genFileId)·같은 내용으로 새 보관함에 **새 번호(id)**로 «먼저» 쓰고, 그것이 이 기기에 «담긴 것을 확인한 뒤에만» 옛 보관함에서 뺀다(localStorage 쪽은 `set._lastOk`, 기본 저장소 KV 는 `KV.flush()` 뒤 `KV.errors` 가 늘지 않았는지 — `_feeSaved`). 옛 번호는 «지운 기록표»에 정상으로 적혀 다른 기기의 옛 사본도 사라진다(아래 검증 지적 ①②). 되돌리면 원래 보관함·원래 종류로 돌아가고 `feeKeep` 을 남겨 다시 안 옮긴다(사람이 정한 것이 이긴다). 사람이 올리기 화면에서 보관함을 직접 고른 서류도 `feeKeep`.
- 확인(지어낸 자료·실제 화면): 새로 담은 협회 지급확인서(.hwpx)만 자동으로 «지급조서·영수증» 으로 옮겨짐 · 이력서 이름·비협회·예전 것은 그대로 · 「🧾 비용 서류 찾기」 목록에 예전 협회 지급확인서 1건 → 옮기기 → 되돌리기(feeKeep) 동작 · 375px 에서 창이 화면 안·카드 배치·단추 안.
- 시험 `tests/kcareer-feeroute.test.js` 20건 + 변이 12가지(순서 거꾸로·훅 삭제·예전 서류 자동 판정·두 번 열기·feeKeep 안 남김·훑기만으로 옮김·밖 호출 삽입·협회 조건 삭제·이력서 이름 예외 삭제·keep 무시·본문 조각 노출 …) 모두 잡음.
- **안 한 것 / 한계**: ① 협회가 아닌 곳의 비용 서류는 안 옮김(위 규칙). ② 글이 없는 스캔·그림 서류는 판정 못 함(파일 이름도 비어 있으면 근거가 없다). ③ 비용관리 «쪽»에서 이력서 보관함으로 거꾸로 잘못 들어온 것은 다루지 않음. ④ Jev 를 쓰려면 대표가 «국외 보관·이름 가림» 기준을 다시 정해야 한다(메일 자동분류 선례: 이름을 못 가리면 보내지 않는다).
