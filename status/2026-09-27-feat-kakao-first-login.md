# 2026-09-27 · 카카오 먼저 로그인 (feat/kakao-first-login)

대표 지시: 「아이디 비번을 계속 보이는게 좋은가 … 폰에서도 로그인 카카오로 하게 하고
다른직원도 카카오로 가능하게 모두 바꿔라」 → 목업(kakao-first-login, 저장소 밖) 승인 「네」.

## 바뀐 것 (enter.html)
- 로그인 화면: 💬 카카오로 로그인 단추를 **맨 위**로. 지문 단추도 그 아래(비밀번호 칸 밖).
- 이 기기에서 카카오로 들어왔거나 이었으면(`localStorage pu_kakao_used`) 아이디·비밀번호 칸을
  「아이디·비밀번호로 로그인 ▾」 아래로 **접는다**. 처음 쓰는 기기·저장소 막힌 창은 펼친 채.
  카카오 로그인이 실패하면 저절로 편다.
- 포털 맨 위 노란 줄 `#kkRegRow` — 카카오를 안 이은 직원 **모두**에게
  「💬 다음부터 카카오로 한 번에 [카카오 연결] [나중에]」. 「나중에」 7일(사번마다 따로), 이으면 다시 안 뜸.
- 폰도 같은 화면 — 따로 만든 것 없음.

## 비밀번호 로그인을 남긴 까닭
새 직원의 첫 연결 · 카카오 장애 · 회사 명의(사업자) 카카오는 카카오가 로그인을 막는다.
