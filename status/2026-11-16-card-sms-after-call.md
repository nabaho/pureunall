# 2026-11-16 · 통화 후 명함 문자 (하나문자 앱 2.6.0)

대표 지시: 「내 핸드폰에서 전화통화 후 자동으로 명함 문자로 보내는 기능. 이미 저장된 이름은 보낼지 선택하게 하고, 연락처에 없으면 선택해서 자동 보내기. 폰에서 만들어줘」

## 만든 것 (모두 `android/hana-sms-bridge`, 서버·ERP 화면은 바뀐 것 없음)
- `CardCallReceiver`(통화 끝 알아채기) → `CardCallWorker`(4초 뒤 통화기록 한 줄) → `CardSms`(걸러내기·물어보기·보내기).
- `CardActionReceiver`(알림 «보내기/안 보내기», exported=false, 번호표만 든다) · `CardSmsActivity`(설정 화면).
- 보내는 길은 기존 `VisitSmsSender.sendOne` 을 그대로 쓴다(공개 범위만 package-private 으로).
- 판 번호 2.6.0 — `build.gradle.kts` · `BridgeConfig.java` · `pu-erp.html`(HANA_APK_VER) 세 곳.

## 설계 해석 (대표가 바꿔도 되는 것)
- 저장된 번호 = 기본 «물어보기», 없는 번호 = 기본 «바로 보내기». 화면에서 둘 다 «물어보기/바로/안 보내기» 선택.
- 같은 번호는 30일에 한 번. 문구는 명함(이미지) 글자를 옮긴 텍스트 — 이미지(MMS) 첨부는 안 했다.
