# 2026-09-18 · 「제발 한번에 할 수 있게 니가 만들어라」 — 폴더 찾기까지 내가 한다

가지 `claude/login-start-screen-386qu2`

## 무엇이 있었나

대표님이 명령 프롬프트를 여시고 내가 적어 드린 대로 치셨다 —

```
C:\Users\fair0>git pull
fatal: not a git repository (or any of the parent directories): .git
```

**`C:\Users\fair0` 에 계셨다.** 이알피 폴더가 어디인지는 아무도 안 알려 줬다.
내가 「`git pull` 하고 `node …` 하세요」라고만 적었다 — **사람에게 폴더를 찾게 한 것이다.**
그러고는 「`dir /s /b` 로 찾으세요」를 또 시켰다. 그래서 「제발 한번에」가 나왔다.

## 만든 것 둘

| 파일 | 언제 쓰나 | 무엇을 하나 |

| `scripts/나스-올리기-찾아서.ps1` | **폴더를 모를 때(처음 한 번)** | `pu-erp.html` 을 찾아 그 폴더로 들어간 뒤 같은 일 |

그리고 대표님께는 **붙여넣을 한 줄**을 드린다(폴더를 몰라도 되는 것) —
그 한 줄이 찾아서·들어가서·받아서·올린다.

## 못 박은 규칙 (검사가 지킨다)

- **`.bat` 은 «자기 자리»에서 폴더를 잡는다**(`cd /d "%~dp0.."`) —
  이것이 없으면 어디서 눌렀느냐에 따라 오늘과 똑같은 「not a git repository」가 난다
- **실패하면 창을 세운다(`pause`)** — 두 번 눌러 연 창은 끝나는 순간 닫힌다.
  오류가 번쩍하고 사라지면 사람은 무엇이 잘못됐는지 영영 못 본다.
  검사가 «모든» 실패 갈래에 `pause` 가 있는지 본다
- **두 길이 같은 것을 부른다** — `--deploy` 가 한쪽에서 빠지면 «보여만» 주고 끝나는데
  화면은 「끝났습니다」라고 한다. 사람은 올린 줄 안다
- **찾기는 «이알피 폴더인지»까지 본다** — 내려받기 폴더에 굴러다니는 `pu-erp.html`
  한 장을 저장소로 잘못 보면 `git pull` 이 또 터진다. `scripts` 가 옆에 있는지 함께 본다
- **배포본에 안 나간다** — `scripts` 는 지우는 목록에 있다
