# 2026-09-18 · 역방향 프록시 — IP 를 넣으면 DSM 이 거절한다(별표여야 한다)

가지 `claude/login-start-screen-386qu2`

## 무엇이 있었나

대표님이 안내판대로 역방향 프록시 창을 열어 값을 넣으시는데, 소스 칸에 **빨간 딱지**가 떴다 —

> ⚠ **잘못된 도메인 이름** · 호스트 이름 `192.168.0.21`

DSM 의 역방향 프록시는 소스 호스트 이름에 **«도메인»만** 받는다. IP 는 안 받는다.
내가 안내판에 `192.168.0.21` 을 넣어 드렸으니, **시킨 대로 했는데 그 자리에서 막히는** 안내였다.

## 고친 것

| 칸 | 전 | 후 |
|---|---|---|
| 소스 · 호스트 이름 | `192.168.0.21` | **`*`** (어느 이름으로 와도 받는다 — 우리 나스에는 도메인이 없으므로 이 길뿐) |

같은 화면에서 하나 더 봤다 — **대상 프로토콜이 `HTTP` 로 놓여 있었다.** 창을 열면 그것이 기본값이다.
내가 「HTTPS」라고만 적어 두고 «기본값이 HTTP 라는 것»을 안 말했다. 그대로 저장하면 또 안 된다.

## 그래서 안내판에 «곁말»을 달았다

걸리기 쉬운 칸에는 값 바로 아래 같은 줄에 «왜 그 값인지»를 붙인다.
딴 데 적으면 안 읽는다.

```
소스 · 호스트 이름   [ *     ] [복사]
   ↳ IP 는 거절당합니다 — 별표가 「어느 이름으로 와도」입니다

대상 · 프로토콜      [ HTTPS ] [복사]
   ↳ 기본값이 HTTP 입니다 — 반드시 HTTPS 로 바꾸세요
```
