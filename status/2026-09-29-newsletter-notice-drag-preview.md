# 안내문 자료 끌어놓기와 기본 미리보기

- 안내문이 없을 때 오른쪽 빈 영역 전체를 PPT·PDF·한글·워드·엑셀·사진 파일의 끌어놓기 영역으로 바꿨다.
- 파일을 놓으면 기존 `파일올리기 → 새안내문` 순서를 그대로 사용해, 업로드 실패 시 빈 초안이 남지 않는다.
- 파일을 올리기 전에도 실제 안내문 서식으로 만든 기본 메일 디자인을 화면에 표시한다.
- 파일 선택이 필요한 경우를 위해 `파일을 직접 고르기` 보조 동작은 남겼다.
