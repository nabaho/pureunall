# 경력관리 «요청 메일» — 업무 메일은 빼고 이력서·경력·회의·비용만, 애매한 것은 Jev 로 (2026-11-15, 대표 지시)

대표 지시: 「이력서 경력 회의 비용 등에 대한 부분이다 — 업무와 관련된 건 빼라, Jev 를 활용해서 자동 분류하게 해달라」

## 무엇이 바뀌었나
- **1차 — 말 목록(`js/kcareer-mailreq.js` `scopeOf`)**: 제목·첨부 이름만 본다(본문은 안 본다, 밖으로 안 나간다). 개인(이력서·프로필·경력증명·위촉·심의·인력풀·서약서·지급확인서·강사료 …) 말만 있으면 남기고, 업무(보고서·이행관리·인터뷰·노동청·신고사건·근로계약·급여·취업규칙·퇴사자 … `[푸른노무법인]` 이름표) 말만 있으면 **«요청 아님»으로 자동 제외**한다. 둘 다 있거나 둘 다 없으면 «애매» — 지어서 가르지 않는다.
- **2차 — 애매한 것만 Jev**: 서버 함수 `mailReqScope`(`functions/mail-req-scope.js`, `functions/index.js`). 제목·첨부 이름(최대 3개)만 받아 **직원·업체 이름과 번호를 가린 뒤** Jev 에게 «업무/개인/애매»를 묻는다. 관리자만 · 한 번에 10건 · 하루 100건(`typesafe_tally_mailreq`, 사람 몫·메일 분류 몫과 다른 자리) · 이름 목록을 못 읽으면 통째로 건너뜀 · 모르는 답은 «애매».
- **자동 제외는 «새 요청»에만.** 사람이 «확인함»·«처리 완료»로 만진 건은 상태를 그대로 두고 범위 딱지만 붙인다(건마다 transaction). 되돌린 건을 스캔이 다시 치우지 않는다. 이 기능 전에 올라온 건도 훑을 때 한 번 규칙으로 가른다(60건씩).
- **화면(`kcareer.html`)**: 목록에 「🤖 업무 관련 · 자동 제외」 딱지(규칙인지 Jev 인지·왜는 마우스를 올리면), 위쪽 «🤖 Jev 분류 켜짐/꺼짐» 단추(켜짐이 기본 — 이 기기에서 끈다), 상태줄에 자동 제외 건수와 Jev 가 켜졌는지·쉬는지, 안내문. Jev 호출이 실패하면 던지지 않고 **30분 쉰다**(그동안은 규칙 결과 그대로).
- 캐시 번호: `kcareer-mailreq.js?v=3`(경력관리·포털 둘 다). 문서: `docs/kcareer-요청메일.md` «업무 메일은 뺀다».

## 확인한 것
- 시험: `tests/kcareer-mailreq-scope.test.js`(19) · `tests/mail-req-scope.test.js`(12) · `tests/kcareer-mailreq-doc.test.js`(+3, 문서의 말·숫자를 코드와 견줌). 변이 22가지(규칙을 하나씩 되돌림) 중 21 잡음 — 못 잡은 1개(`!x.scopeAsked` 제거)는 앞 조건(`scopeBy==='rule'`)과 겹치는 안전장치라 결과가 같다.
- **실제 요청 메일 52건에 규칙을 대어 봄**(이 PC 브라우저 안에서만 계산, 외부로 안 보냄): 처리 완료로 둔 5건은 모두 «개인», 업무 33건은 «업무», 처리 완료 건이 «업무»로 잘못 갈린 것은 0건. 규칙이 못 가른 13건은 모두 이미 치워 둔 건.

## 아직 안 된 것 / 알아 둘 것 (숨기지 않는다)
- **서버 함수 `mailReqScope` 는 아직 배포 전이다.** 배포는 «이름을 찍어서만»(`firebase-deploy.yml`) — 합친 뒤 별도로 한다. 배포 전에는 화면이 «서버 함수가 아직 배포 전일 수 있습니다»라고 하고 30분마다 조용히 쉰다. 규칙 분류는 배포와 상관없이 돈다.
- **실제 Jev 에게는 불러 보지 못했다**(가짜 fetch 로만 시험). 열쇠·업체 응답 모양은 기존 `mail-ai-classify.js`·`typesafe-evaluate.js` 와 같은 길을 쓴다.
- **규칙의 정확도는 «같은 52건에 맞춰 다듬은» 값이라 새 메일에서는 [확인 필요]** — 틀리게 치운 것은 «요청 아님» 탭에서 되돌리고, 알려 주면 말을 더한다.
- 외부로 나가는 것: 애매한 건의 «제목·첨부 이름»(이름·번호 가림)뿐. 사람 이름(근로자 등)은 기계로 다 못 가린다 — 그래서 규칙이 이미 가른 건은 아예 안 보낸다. 끄려면 화면의 «🤖 Jev 분류» 단추.

## 자동 검증(Orca) 1회차 지적과 고침 — 2026-11-15
기능 검증 «조건부 실패»(중간 1·낮음 3), 보안·기능 검토 중간 1·낮음 4. 높음은 없었다. 모두 고쳤다(변이 31가지 중 29 잡음, 나머지 2는 결과가 같은 변이 1 · 시험 보강 1).
- **[중간] 가리는 차례가 거꾸로** — 숫자를 먼저 `#` 로 바꾸면 이메일·전화·사업자번호 가림이 못 알아봐, 이메일 아이디·도메인이 그대로 나갈 수 있었다. → 번호·이메일 가림(`TS.redact`)을 «먼저», 그다음 직원·업체 이름, 마지막에 남은 4자리 숫자. 시험이 차례를 코드에서 직접 확인한다.
- **[중간] 하루 한도를 «부른 뒤에» 셈** — 동시 부름이 한도를 넘고, 함수가 중간에 끊기면 이미 보낸 건이 안 세어질 수 있었다. → **부르기 전에 transaction 으로 칸을 잡고**(남은 만큼만), 못 쓴 칸은 끝에서 돌려준다. 건마다 8초·전체 40초 마감을 걸어, 넘으면 지금까지 결과만 돌려준다(partial). 시험: 동시에 두 부름·DB 오류·마감.
- **[낮음] 직원 목록이 «읽혔지만 비어 있으면» 가림 없이 나감** → 직원 목록이 비면 통째로 건너뛴다(503).
- **[낮음] 관리자는 메일함과 상관없는 글도 보낼 수 있었음** → **화면은 건 번호만 주고, 서버가 로그인한 사람의 `kcareer/{uid}/mailreq/items` 에서 제목·첨부 이름을 직접 읽는다.** 물을 만한 건(애매·새 요청/확인함·아직 안 물음)이 아니면 읽어도 안 보낸다.
- **[낮음] 되돌린 건이 「자동 제외」로 계속 셈되고, 사람이 다시 치우면 기계가 한 것처럼 보임** → 사람이 상태를 바꾸면 `autoIgnored` 표시를 지운다(`stateUpdate`), 상태줄은 «지금도 기계가 치운 채인 건»만 센다.
- **[낮음] 자동 제외 직후 «새 요청» 알림이 울릴 수 있음(1.5초 뒤 알림)** → 알리는 순간 `_mr.items` 의 상태를 다시 보고 새 요청만 알린다.
- **[낮음] 자동 제외 까닭이 마우스를 올려야만 보임** → 팝업에 «자동 제외» 줄을 넣고, Jev 가 쉬는 까닭을 상태줄에 글자로 보인다.
- 기존 시험 `stateUpdate` 가 «st 와 시각 칸만»을 글자 그대로 못 박고 있어, 규칙의 뜻(기한·종류·메모·제목·보낸이는 안 건드린다)은 그대로 두고 `autoIgnored` 를 포함하도록 시험을 고쳤다.

## 자동 검증(Orca) 재검증 지적과 고침 — 2026-11-15
기능 검증 «통과»(문제 0건), 보안·기능 검토 높음 2·중간 2(모두 가짜 fetch 로 재현). 고쳤다.
- **[높음] 가리기 «전»에 자름** — 제목 140자·첨부 60자로 먼저 잘라 경계에 걸린 이메일(`tester@exa`)·업체 이름 조각이 가림을 빠져나갔다. → 자르기는 가린 «뒤»(`TEXT_MAX`)로 옮기고, 저장 단계가 «…»로 잘라 둔 글은 끝의 한 마디를 버린다(`dropCutTail`). 시험이 제목·첨부 경계에서 이메일·업체 이름이 안 남는지 직접 본다.
- **[중간] 보낸 뒤의 실패를 «안 센 것»으로 돌려줌** — 통신 오류·시간 초과가 반복되면 글이 계속 나가는데 하루 한도가 안 줄었다. → **보낸 시도는 실패해도 센다**(`counted`). 업체가 열쇠·길·모양을 거절해 글이 안 남은 부름(key·route·shape)과 아예 안 보낸 칸만 돌려준다.
- **[중간] 응답 «본문» 대기에는 시간 한도가 없고, 전체 마감은 요청 사이에서만 확인** — 머리글만 받고 타이머를 풀었다. → 한 건 부르기(`judge`)에 응답 본문까지 시간 한도(`AbortController` + 경주)를 걸고, 한도를 넘으면 끊어 실패(timeout)로 센다. 전체 마감은 함수 «시작»부터 잰다(남은 시간이 1.5초 미만이면 새로 부르지 않는다).
- **[높음: 시험 자료의 «실제 기관명»]** — 시험 제목의 «[푸른노무법인]» 이름표. 이 저장소 주인(법인) 자신의 이름이고 규칙의 열쇠말이라 **고치지 않고** 시험 머리글에 예외 사유를 적었다(고객·다른 기관 이름은 없다).
