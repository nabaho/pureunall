# 2026-10-31 · 폰 메일 읽기 «안 B + 빠른 답장» (mail-phone-read)

대표 지시(2026-10-31): 「폰 읽기 화면 위쪽이 화면 절반을 차지한다 → 줄이고, 폰에서도 빠른 답장」 목업 «안 B + 빠른 답장» 승인.

## 바뀐 것 (폰 화면만 — PC 는 그대로, 서버·함수·규칙 배포 없음)
- 폰(.dmr) 읽기 위 줄 = ‹ · 제목 한 줄 · ▲ ▼ · ⓘ📎N. 아래에 «보낸이 · 날짜» 한 줄, 곧바로 본문.
- ⓘ 를 누르면 자세히(보낸이 주소·받는 곳·받은 때·폴더·열어봄·첨부) 펼침·접힘(`mbPhInfo`, state.mbInfoOn). 다른 통을 열면 늘 접힌 채로 연다.
- 아래 막대 = ↩ 답장 · ↩↩ 전체 · ➡ 전달 · ⋯ 더보기. 더보기는 «있던 단추»(.lft: 삭제·스팸신고·이동·중요·담당자·안 읽음·내가 봤다)를 시트로 연다 — 핸들러가 한 벌이다.
- 빠른 답장 시트(`mbQrOpen/mbQrSend`): 문구 칩 3 · 입력 · 보내기. 보낸 사람에게만(참조 없음) · RE: 제목 · 원문 인용 + 서명 자동 · 보낸 «뒤에만» 답장 표(`mbAnswered`).
  빈 글 막기 · 연타 막기 · 실패하면 시트를 닫지 않고 글을 남긴다. 「⤢ 전체 화면으로 쓰기」는 쓰던 글을 들고 기존 쓰기 화면으로(`mbQrFull`).
  자동 발송이 꺼졌거나 보낸 사람 주소를 모르면 시트 대신 예전 길(`mbReply`).
- 뒤로가기: 더보기·빠른 답장 시트가 PuBack 층에 올라 뒤로가기가 시트부터 닫는다.
