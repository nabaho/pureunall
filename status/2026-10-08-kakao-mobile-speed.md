# 휴대전화 카카오 로그인 지연 점검

- 운영 함수 기록(2026-10-06~07): `kakaoLoginFinish` 성공 응답은 대체로 0.8~1.1초. 카카오 토큰 확인 자체보다 휴대전화의 브라우저 왕복·인증 저장소 대기 구간을 우선 점검했다.
- `kakaoAuthUrl` GET 에 본문 없이 `Content-Type: application/json`을 붙이던 부분을 제거했다. 불필요한 CORS OPTIONS 왕복을 없애고, 캐시된 옛 화면의 GET 사전 요청도 서버가 허용하도록 했다.
- 카카오 버튼을 누른 뒤 Firebase `setPersistence`를 기다렸다가 카카오로 떠나던 순서를 고쳤다. 유지 여부는 기존처럼 복귀 뒤 실제 로그인 직전에 적용한다.
- 검사: `tests/kakao-login-fast.test.js`에 GET 헤더·옛 화면 CORS·출발 전 저장소 대기 방지 회귀 검사를 추가했다.
- 남은 일: 배포 후 실제 휴대전화에서 카카오 버튼→카카오 화면→포털 타일 구간을 각각 재어 확인한다. 카카오 앱 전환·휴대전화 네트워크 시간은 서버 로그만으로 확정할 수 없다.
