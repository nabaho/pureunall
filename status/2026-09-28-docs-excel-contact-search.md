# 문서관리 엑셀 원형 보존·담당자 찾아오기

## 요청

- 엑셀 양식을 채운 뒤 내용·선·줄 간격이 흐트러지는 문제를 막는다.
- 계약서의 회사와 담당자 정보를 ERP 업체관리·기업정보함에서 검색해 가져온다.
- 검색되지 않는 값은 사람이 직접 입력한다.

## 반영

- 엑셀 셀 전체를 새로 만들지 않고 기존 셀·행·글꼴·줄바꿈 XML을 둔 채 글자만 교체한다.
- 숫자와 날짜 계산이 필요한 단일 표시 칸만 기존처럼 숫자 값으로 넣는다.
- 담당자 검색창을 추가하고 이름·회사·직급·부서·전화·휴대폰·이메일로 검색한다.
- ERP 주담당자와 기업정보함 명함 담당자를 함께 검색한다.
- 다른 회사의 담당자를 고르면 그 담당자의 회사도 함께 선택해 회사·담당자가 엇갈리지 않게 한다.
- 담당자 직급·부서·휴대폰·유선전화·이메일·주소를 계약서 표시 이름에 연결한다.
- 검색 결과가 없으면 오른쪽 빈칸에 직접 입력하라고 안내한다.

## 확인

- 행 높이, 셀 스타일, 굵게·기울임 글꼴 노드를 그대로 보존하는 자동검사를 추가했다.
- 회사 안팎 명함과 ERP 주담당자 검색 검사를 추가했다.
- 문법·기능·화면 배선·공용 캐시 번호 검사 28건 통과.
