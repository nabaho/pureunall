# 2026-09-20 · 푸른 캘린더 — 「직원별 업무」·「분석」 탭을 없앤다

대표 지시 「직원별업무와 분석은 필요없다 여기 넣지 마라」

## 무엇을 없앴나

법인대시보드를 캘린더로 옮기며(2026-09-18) 두 탭은 「다음 걸음에 옮긴다」는
안내(`laterHtml`) — 「푸른이알피에서 열기」 단추만 있는 빈 탭으로 자리를
잡아 뒀다. 이번 지시로 **탭 자체를 없앴다.**

- `TABS` 배열에서 `workload`(직원별 업무)·`analytics`(분석) 두 항목 삭제
- 부르는 곳이 없어진 `laterHtml()` 함수와 `render()`의 `else` 갈래도 함께 지움
  (죽은 코드를 남겨 두지 않는다 — CLAUDE.md 「죽은 코드는 검사가 부르는 것」)
- 이알피 옆 메뉴의 「직원별 업무」·「분석」은 그대로 있다 — 거기서는 그대로 쓴다

## 검사

`tests/cal-no-dashboard-tabs.test.js` 새로 만듦(3건):
1. `TABS` 에 두 탭(이름·열쇠 모두)이 없다
2. `laterHtml` 정의도 부르는 자리도 없다(둘 다 없어야 진짜로 지운 것)
3. 남은 탭 넷이 모두 `ready:true`(안내용 미완성 탭이 안 섞여 있다)

이빨 확인 둘 다 걸림(탭 되살리기·`laterHtml`만 죽은 채로 되살리기). 전체
**18,327건 통과**. 실브라우저·진짜 자료로 탭 줄에 캘린더·이음센터·근무 캘린더·
인원 현황·외부 공유 뷰 다섯만 남은 것을 확인했다.
