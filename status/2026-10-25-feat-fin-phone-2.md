## 하나씩 열어 본 것 (tools/phone-audit seeds/fin.js — 화면·탭 20개, 411·360px, 글자 1.4배도)
찾은 것 → 고친 것
1. 표 열이 폰 폭에 안 들어가 오른쪽 열이 옆으로 미는 상자 안에 숨음(입금관리 업체입금·미수금·세금계산서·예상부가세·자동 처리·손익)
   → js/pu-fin-phone.js: 표마다 칸 이름표(data-l) + 들어가면 줄임(fit/fit2) · 안 들어가면 카드(card) · 줄 없으면 머리글 접음(empty) · 달 열 12개짜리 달력표는 옆으로 밀되 이름 칸 붙박이(matrix)
2. 탭·칩 줄이 옆으로 밀려 끝이 잘림(입금관리 탭·업체입금 칩) → 재무에서 줄바꿈(인사관리 폰과 같은 규칙)
3. 출금관리 줄이 이름 4줄로 부서짐 → 격자(이름·금액 / 날짜·딱지 / 단추). 글자 1.4배에도 금액이 안 떨어짐
4. 출금관리 도구줄 단추 8개 제각각 → 같은 폭 3열 격자 + 검색 줄 폭 전체. 요약 한 줄 «…»로 잘림 → 두 줄까지
5. 월말 마감 단계 줄 정렬이 제각각(첫 단계만 왼쪽·나머지 오른쪽, 안내 글 잘림) → 번호·이름 / 상태·누가언제 / 보기·마감(같은 폭)
6. 🎤 단추가 목록 끝 줄(금액·삭제)을 덮음 → 작게·아래로 + 본문 맨 끝 여백

## 추가 (대표 2026-10-25 저녁 — 「KPI 나 상단 셀이 너무 불필요하게 크고 길게 내려와서 데이터 확인이 어렵다 — 모두 수정」)
대표 폰(글자 크게)에서 월말 마감·자동 처리·미수금·세금계산서·손익계산서의 위쪽 요약·도구가 화면 절반을 먹고 데이터가 맨 아래로 밀림.
- 틀고정 덩어리(sticky z-index:5)는 폰에서 풀어 같이 올라가게(PC 에서 머리를 붙이려던 것).
- 자동 처리 띠: 한 줄씩 → 이어 붙이고 보조 설명 작게(약 400px → 100px).
- 미수금 여섯 칸: 두 줄짜리 작은 칸 셋씩 두 줄. 손익: 연도·CSV 한 줄 / 숫자 셋 같은 폭 / 탭 한 줄.
- 세금계산서: 안내 세 줄 접고 단추·검색·기간 토글 줄 폭 맞춤. 입금관리(미입금 대기): 설명 접고 칩·검색 줄 압축.
- 월말 마감: 설명(sub) 접고 단계 = 이름·상태 / 보기·마감 — 여섯 단계가 한 화면.
- 숫자 표: fit → fit2 → fit3(건수·비중·마진율·비고 열 접기) → 카드. 카드는 긴 칸이 없으면 세 칸씩.
- 점검 도구에 «글자 크게(--font=1.4)» 뒤 표를 다시 재는 단계(rescan) 추가 — 안 하면 큰 글자에서 표가 실제와 다르게 찍힌다.
