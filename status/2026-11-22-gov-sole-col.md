# 2026-11-22 · claude/gov-sole-col

대표 지시(공고 목록 갈무리와 함께) 「수의계약이나 업종제한 관련 표시는 별도의 열을 만들어 체크하게 해 주고, 수의계약이 이미 있는 것들은 별도로 체크할 필요가 없다. 들어가서 입찰이 되지 않기 때문에 표시만 하고 자동으로 빠질 수 있게 정리해 달라」.

## 한 것
- **공고 모아보기에 「계약·제한」 칸** — 상태 다음, 공고명 앞. 공고명 앞에 붙어 제목을 가리던 딱지(수의계약·🏭 업종제한·📍 지역)를 이 칸으로 옮겼다(`limCell`).
  - 차례: 수의계약 → 🏭 업종제한 → 📍 지역(칸 안에서는 «📍 충남 외 2»처럼 짧게 — 시도 줄임은 🎯 와 같은 `GovPick.regionFit`). 한 줄, 넘치면 잘리고 칸 풍선(`limTitle`)에 계약방법·업종 이름·지역 전부.
  - 제한이 없거나 못 읽은 공고는 빈 칸(「제한 없음」이라 쓰지 않는다 — 못 읽은 것일 수 있다).
  - 폰은 이 칸을 숨기고 예전처럼 둘째 줄에 딱지(바뀐 것 없음). 폰 머리줄 규칙은 자리 번호(nth-child(6)) 대신 `.nmh`(이름 칸)로.
- **수의계약은 «기본으로» 뺀다** — 고르개 「수의계약 빼기(기본) / 수의계약도 보기 / 수의계약만」(`mthdOf`·`mthdNow`). 고른 적이 없거나 옛 값(빈 값 = 예전 「전체 계약」)·이상한 값은 「빼기」. 뺀 건수는 건수 줄에 「수의계약 N건 뺌」. 숨기거나 지우지 않는다(보기만).
  - 같은 값을 따르는 곳: 공고 모아보기 · 📅 발주 예정(표·보기 건수·탭 숫자) · 📍 충청권·🤖 AI 탭(목록·탭 숫자·「수의계약 N건 뺌」) · 🎯 지원할 만한 것(`soleCut`). 매일 카톡 요약(functions/gov-digest.js)은 원래 수의계약을 뺀다.
  - 🏢 푸른 지원사업 탭(사람이 직접 고른 것)은 거르지 않는다.
- 발주 예정 사업명 앞 수의계약 딱지는 걷었다 — 그 표는 원래 「계약방법」 칸이 있어 거기서 눈에 띄게(한 곳).
- 업종제한은 빼지 않고 표시만(대표 말씀대로 수의계약만 자동으로 뺀다).
