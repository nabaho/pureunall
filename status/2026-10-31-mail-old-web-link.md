# 2026-10-31 · 창 밖 지난 메일에 «다음메일 웹에서 열기» 단추 (mail-old-web-link)

#2804 의 다음 걸음. 목업(대표 승인 2026-10-31)대로 — 열 수 없는 지난 메일 화면의 긴 안내를 한 줄로 줄이고 단추를 붙였다.

## 바뀐 것 (화면만 — 서버·함수 배포 없음)
- 서버 `readOldMail` 이 이미 주던 `outOfWindow:true` 를 `mbFetchBodyNow` 가 오류에 싣고(`er.outOfWindow`), 열람 상태 `state.mbOpen.outWin` 으로 옮긴다.
- `mbReadErrHtml` — `outWin` 이고 지난 메일이면 「다음메일 창(최근 3만 통) 밖이라 여기서는 못 엽니다. 다음메일 웹에서 열기 ↗」 한 줄 + 저장해 둔 앞부분.
  그냥 실패(네트워크 등)나 다음메일 폴더 메일에는 단추를 달지 않는다.
- 새 창(`target="_blank" rel="noopener"`) 으로 `https://mail.daum.net` 을 연다.

## 한계 (숨기지 말 것)
다음메일은 «메일 한 통으로 바로 가는 주소»를 주지 않는다 — 첫 화면만 열리므로 제목·날짜로 직접 찾아야 한다.

## 검사
`tests/mail-old-outofwindow.test.js` 에 3개 추가(총 8) — 되돌려 우는지 6가지 모두(주소 제거 · noopener 제거 · outWin 조건 제거 · 폴더 메일에도 단추 · 오류에 안 실음 · 화면 상태에 안 옮김).
로그인 뒤 화면이라 브라우저로 직접 열어 보지는 못했다(함수를 가짜 화면 없이 직접 돌려 그려 보는 검사로 대신함).
