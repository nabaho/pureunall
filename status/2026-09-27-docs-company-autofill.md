# 문서관리 사업장정보 자동 채우기 최종 정리

## 문제

- 문서관리의 회사 찾기가 ERP 업체관리가 아니라 기업정보함 색인만 읽어, ERP에 등록된 업체가 검색되지 않는 경우가 있었다.
- 엑셀 원본에 `{{회사명}}` 같은 표시가 없으면 사업장정보를 채우지 못했다.
- 양식에 같은 원본의 첨부본·보관본이 함께 있을 때 먼저 고른 보관본이 사라지면 문서 전체를 못 찾은 것으로 끝났다.

## 해결

- `data/companies`의 ERP 업체관리를 회사정보 원본으로 읽고 기업정보함의 명함 담당자를 보충자료로 합쳤다.
- 업체의 영구 ID와 사업자번호를 유지하고, 이름은 검색 보조로만 사용한다.
- 상호·사업장명·사업자등록번호·대표자·주소·전화·팩스·이메일·업태·종목·담당자 항목을 인식해 표시가 없는 기존 엑셀의 오른쪽 빈 서식칸도 채운다.
- 엑셀의 수식·모양은 다시 저장하지 않고 원본 XML의 빈 값만 바꿔 보존한다.
- 선택한 원본이 보관함에서 사라졌으면 같은 양식의 다른 첨부본/보관본을 자동으로 순서대로 확인한다.
- 화면 안내를 `ERP 업체관리에서 찾기`로 바꿔 실제 정보 출처와 맞췄다.

## 확인

- ERP 업체가 기업정보함 사업자등록증 목록에 없어도 검색·선택된다.
- ERP 주담당자와 기업정보함 명함 담당자가 함께 나온다.
- 표시 없는 엑셀의 상호·사업자번호가 채워지고 기존 수식은 보존된다.
- 원본 누락 시 다른 보관본으로 넘어간다.
- 관련 자동검사 30건 통과.
