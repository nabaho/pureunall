# 2026-10-05 · 통합로그인 — 인증 앱(TOTP) 2단계 인증

- Identity Platform TOTP를 선택해 문자요금 없이 2단계 인증하도록 구성.
- `내 정보`에서 직원이 본인 인증 앱을 등록하는 화면 추가.
- 직원이 직접 로그인했는데 미등록이면 등록 요청을 자동 표시.
- 카카오 로그인은 연결 상태를 안내하고, 인증 앱은 아이디·비밀번호 로그인 때 등록하도록 안전하게 분리.
- 등록된 계정만 비밀번호 뒤 숫자 6자리를 요구하며 미등록 직원은 기존 로그인 유지.
- 비밀키는 별도 DB에 복제하지 않고 Firebase Auth 등록 과정에서만 사용.
- 기존 compat 로그인과 분리된 작은 modular MFA 모듈을 사용하고, 완료 후 기존 포털 세션으로 이어짐.
