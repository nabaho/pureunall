# 경력관리 · 프로필 1장 — 「최근·전체」 표시 없앰 + 위촉·위원/컨설팅 실적 «고른 것만 넣기» (2026-11-12)

대표 지시: 「위촉위원과 컨설팅 실적에 대해서 선택을 하고 싶다 · 최근 전체 이런 표시 없애라 · 제출하면 제출된 내용만 있어야 된다」

- **표시 없앰**: 칸 제목 옆 «(최근 N · 전체 M)»·«(주요 N · 최근 N · 전체 M)» 와 컨설팅 실적 아래 «연도별: …» 줄을 미리보기·PDF·한글(hwpx) 모두 찍지 않는다. 2026-10-12 지시(건수는 제목 옆에)를 이 지시가 대신한다. 몇 건 중 몇 건인지는 화면 옆 «넣을 칸 고르기»(「27건 · 넣음 3」)에서만 본다.
- **고른 것만 넣기**(`opts.only`): 위촉·위원, 컨설팅 실적 두 칸. 켜면 ⭐로 고른 것(`pins`)만 종이에 나오고, 자동 채움·금액 문턱(500만 원)·건수·한 장 맞추기가 건드리지 않는다(넘치면 «넘친다»고 알림). 고른 것이 없으면 그 칸은 빠진다. 끄면 예전 그대로(고른 것 + 자동).
- **화면**: 칸 옆 단추 «⭐ 중요» → «☑ 고르기»(켜면 «✅ 고른 것만 N»). 고르기 창 위에 «자동 / ✅ 고른 것만 넣기» 스위치, 합계 글이 방식마다 달라진다. 저장은 `p1_opts.only[칸]`(클라우드 동기화 대상, `pins` 와 같은 자리).
- **안 건드린 것**: 주요 경력·강의·자격·수상 등 다른 칸(고르기 창이 위촉·실적 두 곳만 있음 — 넓히는 방법은 검토안으로 보고). `사업별 수행 요약`(biz)은 여전히 실적 전체에서 센다.
- 시험: `tests/kcareer-profile1.test.js` ⑫⑬ 새로, ①·⑩ 고침 · `tests/kcareer-profile1-group.test.js` ② 고침(건수 표시가 «없다»를 못 박음). 캐시 `kcareer-profile1.js?v=13`.
- 자동 검증(Orca, 2026-11-12): 기능·화면 **통과**(높음 없음) · 보안 **발견 사항 없음**. 낮음 중 «고른 것만 넣기» 몫은 고침 — 칸 ⚙ 패널의 «몇 건» 상자를 막고 까닭 안내 · 고르기 창 `role=dialog`·스위치 `aria-pressed`·찾기칸 이름·빈 목록 안내(시험 ⑭).
- **고치지 않은 것(원래 있던 화면 문제 — 후속 과제)**: ① 고르기 창 표가 `.dt` 라 375px 카드 변환 때 `data-label` 이 비고 마지막 칸이 관리 단추 열로 갈라짐 ② A4 보기(`_p1Scale`)가 768px 에서 가로 스크롤 ③ 어두운 테마에서 노란 안내 상자·`.btn`·`.dt thead` 글자 대비가 WCAG AA 미달 ④ ⚙·☑ 단추 높이 20px.
- 화면 확인: 지어낸 자료(`tools/phone-audit/seeds/career.js`)+가짜 파이어베이스로 열어 종이에 건수 표시가 없음·고른 3건만 나옴·저장 알림을 확인했다. 폰(360px)은 새 CSS 를 더하지 않아 따로 재지 않았다.
