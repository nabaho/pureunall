# 뉴스레터 «핵심판» — 메일은 «이번 주 꼭 알아야 할 3가지»만, 전체는 웹으로

대표 지시 2026-10-13 「뉴스레터에 너무 불필요한 정보가 많으면 기업에서는 전혀 참고를 안할 것 같다. 정말 중요한 정보를
핵심만 전달하게 할 수 있을까 그리고 아주 쉽고 직관적으로」 → 목업(데스크톱 880px·폰) 보여 드림 → 대표 「네」(승인).

## 승인된 설계 (바뀌면 안 되는 것)
- 메일 = **핵심 카드 최대 3장** + 「그 밖의 소식 N건 · 전체 소식 보기 ▸」(= 기존 웹 전문 `newsView`). 전문은 웹에 그대로 남는다.
- 카드 = 종류 딱지 · 쉬운 제목 · 한 줄 설명 · **「우리 회사는?」**(대상 · 할 일) · 시기 · 자세히 보기.
- 핵심 기준(편집 화면에 안내): ① 시행일·기한이 있는 것 ② 우리 회사가 직접 할 일이 있는 것 ③ 어기면 과태료·분쟁 위험이 있는 것.
- **억지로 3개를 채우지 않는다** — 해당이 2개면 2장(띠도 «꼭 알아야 할 2가지»).
- **AI 는 «후보»만**(`핵심후보`). 사람이 «쓰기»를 눌러 `핵심`에 넣고 고친 것만 나간다. 법률 문장이라 지어내기 금지(건에 없는 날짜는 비움, 링크는 건의 것).
- **카드가 없으면 지금처럼 전문판**(자동 발송이 깨지지 않는 안전한 기본값). 보낸 옛 회차는 «그때 나간 그대로».
- 업종·규모별 «귀사 해당» 맞춤은 **이번에 안 했다**(다음 단계 후보).

## 한 일
- **Core**(`js/pu-news-core.js` + 서버 사본): `핵심다듬기`·`핵심밖건수`·`핵심거리`·`핵심후보지시`·`핵심후보받기` + `바탕도장`에 핵심 반영
  (핵심이 «없는» 회차의 도장은 예전과 한 글자도 같다).
- **서식**(`js/pu-news-tpl.js` + 서버 사본): 핵심판(표로 짬 — 발송기 STYLE_OK 안의 꾸밈만) + 평문 몫. 호출하는 쪽은 안 바뀜:
  `회차.핵심`이 있고 · `웹`이 아니고 · 요약판이 아니고 · 웹주소가 있을 때만 핵심판(웹 전문은 늘 전문).
- **화면**(`pu-news.html`): 「담는 법」 탭 줄에 ⭐ 핵심 — 카드 3장 편집(대상·할 일 / 시기·원문 링크 한 줄 두 칸) · 후보 뽑기(AI) · 쓰기/지우기 ·
  쓰는 중 커서·굴림 유지 · 요약에 «나가는 판» 줄(핵심판이면 전문판 전용 경고 걷힘) · 후보 있음 ●.
- **서버**(`functions/`): ★ **월요일 문지기가 읽는 칸(`index.js 바탕칸`)에 `핵심`을 더했다** — 안 더하면 카드가 있는 회차는
  «준비한 뒤 바뀌었다»로 월요일 자동 발송이 막힌다(코드를 읽다 발견). 금요일 준비(`news-friday.js`)가 핵심 «후보»를 골라 `핵심후보`에만 담고
  검토 메일이 «핵심판으로 나감 / 후보 N장 준비 / 카드 없음»을 알린다(카드·후보가 이미 있으면 AI 안 부름, 실패해도 준비 계속).

## 검증
- 진짜 Edge(가짜 파이어베이스·가짜 AI): 후보→쓰기→고치기→저장→미리보기·요약 반영→3장 한도→폰 폭, 크게 보기 팝업, 지난 회차 탭(보낸 회차) 확인.
- 새 검사 `news-core-card`(15)·`news-core-letter`(17)·`news-core-ui`(11)·`news-core-server`(9) — 일부러 망가뜨린 변형 전부 잡힘(서식 11·화면 12·서버 5·금요일 6).
- 새 검사가 잡아낸 실수: ① `margin-top`(미리보기엔 있고 발송기가 지우는 꾸밈) ② 카드 높이 제각각 → 줄 표 `height="1"` ③ 월요일 문지기 칸 목록.

## 못 본 것 · 알아 둘 것 (정직하게)
- **실제 메일 프로그램(다음메일·아웃룩·지메일)에서의 모양은 못 봤다** — Edge 에서 같은 HTML 로만 봤다. 발송기를 지나도 스타일이 안 지워지는지는 검사로 확인했다.
  한글 단어 단위 줄바꿈(word-break)은 발송기 허용 목록에 없어 못 썼다(기존 편지와 같이 단어 중간에서 꺾일 수 있다). `mail-send.js` 는 git 이 «바이너리»로 보는 파일이라 손대지 않았다.
- ⚠⚠ **서버(functions) 배포가 있어야 «자동 발송»에 반영된다.** Pages 배포만 되면 «손으로 누르는 보내기·시험 발송»은 핵심판이 되지만,
  금요일 준비·월요일 자동 발송은 옛 서버가 전문판을 짓는다 — 화면은 «핵심판으로 나갑니다»라는데 서버는 전문을 보내는 어긋남이 생긴다.
  **그러니 카드를 쓰기 전에 functions 배포를 먼저 한다.** (배포·푸시는 감시 작업이 하지 않는다 — 사람이 승인.)
- 폰 폭 미리보기 카드는 «쌓기»지만 실제 폰 메일 앱은 CSS 를 안 먹어 980px 표를 줄여 보여 줄 수 있다(기존 전문판과 같은 한계).
- 후보 AI 는 «공개 제목·출처»만 보낸다. 대표님이 쓰신 한마디·인사는 안 보낸다.
