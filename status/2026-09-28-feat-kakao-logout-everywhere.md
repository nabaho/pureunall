# 2026-09-28 · 어느 앱에서 나가든 카카오 로그인도 풀린다 (feat/kakao-logout-everywhere)

대표 「추천대로」 — 공용 PC 에서 이알피 등 다른 앱으로 로그아웃하면 카카오 로그인이 브라우저에 남던 틈.

## 방식 — 길목 한 곳(포털 로그인 화면)
- 앱마다 로그아웃 길이 제각각(15개 앱·20곳 남짓, 60분 자동 로그아웃 포함) — 하나하나 고치면 빠진다.
- 다음 사람이 노란 단추를 누르려면 반드시 포털 로그인 화면을 거친다 → 거기서 막는다.
- 카카오로 들어오면 `localStorage pu_kakao_session` 표시. 로그인 화면이 «로그인 안 됨» 인데 표시가 있으면 표시를 지우고 카카오 로그아웃을 거쳐 돌아온다(한 번만).
- 카카오에서 막 돌아온 참이면 안 간다. 서버가 «로그인» 주소를 주면 안 간다. 4초 안에 못 받으면 로그인 화면.
- 이번 판 전부터 카카오로 들어와 있던 사람: 포털이 뜰 때 표(kakao:true)를 보고 표시를 남긴다.

## ⚠ 사람 손
카카오 콘솔 「로그아웃 리다이렉트 URI」 에 enter.html 등록이 아직이다 — 등록 전에는 카카오가 오류 화면을 한 번 띄운다(포털은 이미 끊긴 뒤라 보안 문제는 아님).
