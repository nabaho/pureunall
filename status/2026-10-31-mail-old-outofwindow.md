# 2026-10-31 · 지난 메일이 «다음메일 창 밖»일 때 — 정직한 안내 + 저장해 둔 앞부분 (mail-old-outofwindow)

「지난 메일」 한 통이 «다음메일에 없습니다 — 지워졌을 수 있습니다»로 나오고 화면이 빈 채이던 것.

## 원인 (실측)
`oldProbe`(#2802)로 센 결과 — 담아 둔 지난 메일 **23,155통** 중
- 열 수 있는 것 **22,344통**
- 열 수 없는 것 **811통** — 전부 가장 옛 2020-12 ~ 2021-03 (월별 76 / 268 / 256 / 211)

다음메일 POP3 는 «최근 3만 통»만 목록(UIDL)에 올린다. 새 메일이 올 때마다 가장 옛것이 창 밖으로 밀려나므로 **앞으로도 조금씩 늘어난다.**
지운 메일이 아니다 — 예전 안내 「지워졌을 수 있습니다」는 사실과 달랐다.

## 바뀐 것
- 서버 `readOldMail` 404 응답에 `outOfWindow:true` + 「다음메일 POP3 는 최근 3만 통만 열어 줘서 … 다음메일(웹)에서 보세요. 저장해 둔 앞부분은 아래에 있습니다.」
- 화면 `mbReadErrHtml(o, v)` — 지난 메일을 못 열면 **저장해 둔 앞부분**(목록의 미리보기 글, 800자)을 오류 문구 아래에 함께 보인다.
  다음메일 폴더(IMAP) 메일의 «없다»에는 덧붙이지 않는다 — 그쪽은 정말 지워진 것이라 지운 메일을 보이면 안 된다.
- 검사 `tests/mail-old-outofwindow.test.js`(5) — 되돌려 우는지 6가지 모두(표시 제거 · 옛 문구 복귀 · IMAP 에도 덧붙임 · 앞부분 esc 제거 · 오류 글 esc 제거 · 화면이 함수를 안 씀).

## 다시 세는 법
```
firebase database:set /mailbox/old/probeAsk --data 'true' --project pureun-erp --force
```
다음 동기화 회차(최대 3분) 뒤 `mailbox/old/probe` 를 읽는다 (`listed·stored·found·missing·byMonth`, 수만 적힘).

## 배포할 함수
`readOldMail` (이름으로: `firebase deploy --only functions:readOldMail`). `maxInstances` 는 걸지 말 것(경력관리도 부른다).
