# 경력관리 서류 만들기 — 저장 이름 한 규칙 «해년 기관 서류제목_이름 날짜»

- 대표 승인 2026-09-29(09-28 「해 + 올린 이름 + 날짜」를 넓힘).
  예) 「2027년 천안어린이꿈누리터 제안서 평가위원 후보자 등록 신청서_권형하 2026. 09. 29.hwpx」
- 까닭: 올린 이름이 «공고문»이면 신청서에도 공고문이 붙었고, 작성 중 목록에 「양식.hwpx」만 줄지어 무엇인지 몰랐다.
- 서류제목: 남은 쪽 제목 중 신청서·지원서… 먼저(rhPickTitle) → 서류 글의 「…」 신청서 → 붙임(동의서 등).
  기관: 「○○장 귀하」(rhOrgFrom — 장 한 글자/두 글자는 다른 글로 가림). 이름: 기본정보 성명.
- 적용: 완성본 생성 · 편집기 저장창 · 내보내기 · 큰 창 ⬇ 파일로 저장(작업 중 서류일 때) · 작성 중 목록의 보일 이름(title).
  ⚠ 속 이름(_rhDoc.name)은 그대로 — _날인 판단 등이 거기에 기댄다.
- 실측: 천안 서식·한국기계연구원 신청서 두 개로 이름을 뽑아 확인.
