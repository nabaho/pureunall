# 2026-11-22 · claude/gov-ls-owner-uid

정부사업신청(`gov.html`) 이 기기 저장소에 «주인 uid» — 한 브라우저에서 계정이 바뀌어도 앞 계정 자료가 새 계정 클라우드로 가지 않게.
출발: PR #3241(🏢 푸른노무법인 지원사업) 자동 보안 검토 «높음» — 그 PR 전부터 있던 앱 전체 동기화 구조라 따로 다루기로 한 것.

## 문제
- 이 기기 저장소(`gov3_*`)에 계정 구분이 없었다. A 가 쓰던 브라우저로 B 가 로그인하면 `cloudSync` 가 A 의 인증키(`key_data`·`key_biz`)·공고(`feed`)·진행 사업(`pursue`)을 B 의 `gov/{uid}` 와 합쳐 «B 클라우드로» 올리고, A 가 못 보낸 «보낼 칸»(`_dirty`)·시각(`_stamps`)도 B 로 갔다.
- 2026-10-30 부터 재직 직원도 이 앱을 써서 공용 PC 에서 실제로 생길 수 있다. 대표 PC 한 계정만 쓰면 안 생긴다.

## 한 것
- **주인 표시** `gov3__owner` = 로그인 uid. 받기(`cloudSync`)·보내기(`_cloudFlush`)는 «주인 = 로그인 계정»일 때만 — 아니면 클라우드를 읽지도 쓰지도 않는다. 읽는(await) 사이 계정·주인이 바뀌면 쓰지 않고, «보낼 칸» 표시도 지우지 않는다(`_acctSame`). 받기 성공도 계정별(`_syncUid`).
- **계정이 바뀌면 옮겨 두기**(`acctEnter` — 로그인 확인 뒤·받기 전) — 앞 계정의 동기화 칸 전부 + `_stamps`·`_dirty` + `ai_back`·`last_win`(이 계정 공고를 어디까지 받았나)을 «지우지 않고» `gov3__acct.<uid>.<칸>` 으로 옮기고, 새 계정 이름표 자리가 있으면 꺼낸다. A→B→A 로 돌아오면 A 자료·못 보낸 고침이 그대로이고 그때 `gov/A` 로 간다. 칸 명단은 `GovSync.acctKeys()` 한 곳.
  - 옮기기: 쓰고 → 다시 읽어 같은지 → 그때만 옛 자리 지움. 자리가 모자라면 «같은 크기를 비우고 바로 쓰기», 그래도 안 되면 원래 자리에 되돌림(되풀이된 실수 ⑪ — 저장 공간은 ERP 앱끼리 한 몫). 하나라도 못 옮기면 옮긴 것을 모두 되돌리고 **이 계정으로는 잠근다**(잃는 것 없음, 섞이는 것 없음).
- **주인 표시 없는 옛 자료(이번 고침 전)** — «처음 로그인한 계정 것»으로 보되 판단은 `GovSync.legacyVerdict`:
  - 합쳐도 클라우드가 안 바뀌면(올라갈 것 없음) → 묻지 않고 이 계정 것.
  - 이 기기 시각표와 이 계정 클라우드 시각표가 «같은 열쇠·같은 시각»으로 하나라도 맞으면(주고받은 증거) → 묻지 않고 이 계정 것. **대표 PC·폰은 이 길이라 흐름이 그대로다.**
  - 둘 다 아니면 **올리기 전에 묻는다**(무엇이 올라가는지 «인증키(기업마당)·공고 목록…» 으로). [취소]면 `gov3__acct.?<시각>.*` 로 옮겨 두고(지우지 않음) 이 계정 것만 받는다. 클라우드에 못 닿으면 정하지 않고 아무것도 안 보낸다(다음 받기 때 다시).
- **열린 화면에서 다른 계정으로 바뀌면 새로 연다**(`onAuthStateChanged`) — 화면이 쥔 앞 계정 것(불러온 경력 이력·고른 줄·기다리던 보내기)을 새 계정에 넘기지 않는다. 같은 계정 재로그인은 그대로.
- 캐시 번호: gov-sync 11 → 12.

## 남은 것 · 모르는 것
- ⚠ **옛 판 화면(이 PR 전 코드가 열린 다른 탭)** 은 주인 표시를 모른다 — 그 탭이 새로 열리기 전 짧은 동안은 예전 길이 남는다. 막으려면 보안규칙을 sv≥3 로 올려 옛 판 쓰기를 거절해야 하는데(규칙 배포), 이번엔 하지 않았다.
- 로그인 «전» 첫 그림(빠른 화면)은 마지막 주인의 목록을 잠깐 그린다 — B 로 확인되면 곧 옮기고 다시 그린다. 인증키는 화면에 글자로 안 나온다.
- [취소]로 옮겨 둔 «주인 모름» 자료(`gov3__acct.?<시각>.*`)는 저절로 되살리지 않는다 — 잘못 누른 경우 개발자 도구에서 손으로 꺼내야 한다(클라우드에 이미 있던 것은 안 잃는다).
- 옮겨 둔 다른 계정 자료는 그 계정이 다시 로그인할 때까지 이 브라우저 저장소에 남는다(공용 PC 저장 공간을 그만큼 더 쓴다).
