(글은 「캡쳐1 … 캡쳐1은 왼쪽」 — 두 번째를 캡쳐2 로 읽었다).
앞서 대표 선택 「직접 입력 기능 추가」(승진텍라인 — 산업일자리전환컨설팅능률, 안내 엑셀 없음).

## 바꾼 것
- 정산 탭: 1280px 이상이면 왼쪽 450px 지급월 목록(위에 붙어 따라옴) · 오른쪽 정산표. 좁으면 위아래. 아무것도 안 골랐으면 오른쪽에 안내.
- 왼쪽 목록: 규칙이 있는 컨설팅 종류는 정산표가 없어도 묶음 머리로 보이고(«아직 정산표 없음»), 묶음마다 «+ 입력».
- **직접 입력**(오른쪽): 컨설팅 종류 · 사업장(그 종류·2026) · 지급월 · 수행자별 세전(세후 바로 보임). 주관은 규칙대로 못박고, 담당은 이알피 부담당으로 먼저 채운다(세전 0).
  저장하면 `settle/notices/M_<종류>`(source 'manual')에 쌓고 업체·사람 연결을 잇고 정산표를 만든다. 사업장 글은 «업체명 (컨설팅 번호)»(같은 업체가 여러 컨설팅에 있어도 연결이 섞이지 않게).
  세전 0 담당도 정산표에 들어간다 — 대표 「특별히 배분되어서 입금되는게 아니면 항상 권형하에게 입금」 → 주관 전액이면 담당 몫을 «추가 지급».
  막기: 주관 없음 · 사업장/지급월 없음 · 숫자 아님 · 요율표에 없는 담당 · 같은 사람 두 번 · 같은 종류·같은 달에 엑셀 안내가 있음 · 같은 이름이 다른 사람에게 연결됨.
  «이 컨설팅에 직접 넣은 것» 목록(☐·번호) → «고른 입력 빼기»(비게 된 임시저장 정산표는 _deleted 표식). 안내 파일 탭에도 «✍️ 직접 입력» 단추.
- `buildRuns`: 직접 입력으로 만든 달과 안내 파일로 만든 달은 서로 덮지 않는다(건너뛴 수를 알림).
- 계산 모듈 `manualAdd`·`manualRemove`·`manualEntries`. core ?v=6 · view ?v=8.
