# 2026-09-27 · 사진첩 판독 중 화면 멈춤 방지

- 원인 1: 판독·창고 요청 Promise가 끝나지 않으면 `readBusy`가 계속 참으로 남아 대기열과 화면이 영구적으로 `판독 중`에 머물렀다.
- 원인 2: 판독 한 장이 시작될 때마다 사진 격자 전체를 다시 만들어, 많은 사진이 보이는 화면에서 이미지 해제와 DOM 교체가 반복됐다.
- 조치: 판독 한 건에 응답 감시 시간을 두고, 넘으면 남은 자동 대기열을 멈춘 뒤 화면 조작권을 돌려준다. 진행 표시는 해당 사진 단추만 바꾸며 격자는 대기열 종료 때 한 번만 다시 그린다.
- 안전: 이미 서버로 보낸 판독은 취소하거나 다시 보내지 않는다. 늦게 응답하면 기존 저장 경로가 그대로 끝난다.
