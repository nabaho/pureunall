# 인사관리 폰 화면 정리 — 급여명세서(개별) 본보기 (2026-10-25)

대표 「폰에서 UI 너무 이상하다 … 좌우로 너무 많이 나가고 아래위로도 너무 길게 … 인사관리 폰 UI 다 정리」 → 시안(목업) → 「시안대로」.

## 찾은 원인
- **급여 입력칸이 한 줄에 하나씩 쌓였다** — 칸을 묶는 grid 상자가 `}}),` 로 «열자마자 닫혀» 비어 있고, 입력칸이 그 밖에 흩어져 있었다
  (맨 처음 올린 코드 9dc1cb58 부터의 실수, PC 도 마찬가지). 직원 한 명 화면 2,000px → 상자 안에 넣으니 접힘 1,015px · 펼침 1,450px.
- **css/pu-erp.css 의 «1fr 1fr · repeat(2/3/4 → 한 칸» 폰 전체 규칙**이 폰의 2칸·3칸 격자를 다 접는다 — 법정수당 칸이 쌓이던 것도 이것.
  폰에서 일부러 쓰는 격자는 `minmax(0,1fr) minmax(0,1fr)` 꼴로 쓴다(규칙의 글자를 피함).
- 칩·탭·단추 줄이 «한 줄 + 옆으로 밀기» 라 끝의 것이 화면 밖에 숨었다.

## 한 것
- 급여명세서(개별) 폰: 탭 2×2 · 단추 2×2 · «급여 입력 ▾» 접이(달·직원 바꾸면 접힘) · 카드 안쪽 여백 12px · 지급·공제 근거와 12개월 추이는 접이 · 순서 = 입력 접이 → 명세서 → 추이 → 변경이력.
  넓은 화면은 접지 않고 늘 펼침(입력칸만 3열로 묶임).
- 인사관리 메뉴 전체 폰: 칩·탭·단추 줄은 줄바꿈(css `body[data-erp-group="hr"]` — 재무·사무관리는 그대로). 표를 감싼 상자는 그대로 옆으로 민다.
- 폰 점검 도구(`tools/phone-audit`)로 인사관리 7화면을 잼: 옆넘침·화면밖·세로깨짐·짓눌림 0. 옆으로 미는 줄은 성과관리 표 하나만 남음(표라서 정상).
- 검사: tests/hr-phone-tidy.test.js
