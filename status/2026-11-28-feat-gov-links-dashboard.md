도메인 주소하고 어떻게 해야 되는지 쭉 나와 있으면 그것만 클릭해서 바로 들어갈 수 있게 … 팝업창으로 바로 열리게 …
관련되는 사이트 전체 다 연결해 가지고 왼쪽에 대시보드에다가 다 때려 넣어라 … 별표 표시해서 상단에 자주 하는 거 빨리 클릭할 수 있게」

## 한 것 (`gov-links.html` · `js/pu-gov-links.js`)
- 카드 판을 걷고 **좌우 2단**으로: 왼쪽 대시보드(사업 이름 + 기관) · 오른쪽 상세. 폭 제한 없이 화면 전체를 쓴다.
  - 왼쪽: ★ 즐겨찾기(사이트·사업, 누른 차례) → 찾은 사이트 → 최근 연 사이트 → 📂 사업(▸ 로 펼치면 그 자리에서 사이트 열기, «모두 펼치기») → 🧩 이알피 진행 사업(바로가기 없음) → 🔒 종결 → 푸른 안에서.
  - 오른쪽: 📝 할 일·순서(여러 줄) → 🌐 사이트(이름·로그인·**전체 주소**·사이트 메모, 누르면 바로 열림 + «다른 방식으로» 단추) → 🧰 푸른 앱 → 🏢 이어 둔 이알피 사업·올해 업체 → 연결 제안 → 📁 폴더.
  - 열기 방식 «팝업창 · 새 탭»(대시보드 맨 위, 이 기기에 기억). 팝업창은 사이트마다 창 하나를 다시 쓰고, 빈 창을 먼저 열어 opener 를 끊은 뒤 주소로 보낸다. 막히면 새 탭.
  - 폰: 대시보드 한 화면 → 사업을 누르면 상세 한 화면(«← 목록»·뒤로가기, `PuBack`).
- **★ 즐겨찾기는 사람마다** `govlinks/stars/{사번}`(`GovLinkStar`) — 본인만 읽고 쓴다. 이 기기에도 사본을 둔다(서버를 못 읽으면 사본).
- 할 일·순서 1000자(줄바꿈 살림) · 사이트마다 «여기서 하는 일» 메모(200자) 칸.
- 보안규칙: `govlinks` 뿌리 읽기를 `sets` 로 내리고 `stars/$sid`(본인 사번만) 추가 — 남의 ★ 가 읽히지 않게.
