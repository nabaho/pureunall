# 2026-10-09 · 로그아웃으로 밀려났던 앱 탭은 다시 로그인하면 «하던 앱으로» (feat/return-to-app-after-relogin)

대표 결정 「4」 — 로그아웃하면 열린 앱 탭이 모두 포털 로그인 화면으로 밀려나 그대로 쌓였다(앱 다섯 개면 로그인 탭 다섯 개).
다시 로그인해도 포털로 남았고, 숨어 있다 앞으로 나올 때 로그인 화면이 번쩍였다(#2252 의 뿌리).

## 고친 것
- `js/pu-authsync.js` (v=4): 로그아웃으로 밀려날 때 이 탭(sessionStorage `pu_return_app`)에 주소·창 이름·사람·시각을 적는다.
  다른 사람으로 바뀐 경우는 안 적는다. 얼어 있던 탭은 끊기 «전» 사람으로 적는다.
- `enter.html` `_returnToApp`: 포털 진입(enterPortal) 맨 앞에서 표를 읽고(한 번 읽으면 지움)
  같은 사람·12시간 안·우리 앱 폴더의 화면이면 그 주소로 돌아가고 창 이름을 되돌린다(포털 타일이 그 창을 다시 쓴다).
  숨은 탭은 보일 때 간다(한꺼번에 켜져 자료를 몰아 받지 않게) · 그새 나갔으면 포털을 새로 연다.
- 검사 `tests/return-to-app-after-relogin.test.js` 9개 — 일부러 망가뜨린 11가지 모두 운다.
  enter.html·authsync 를 읽는 검사 167파일 2676개 통과 · 로컬 브라우저에서 enter.html 스크립트 오류 없음.

## 남은 것
- 실제로 «로그아웃 → 다시 로그인» 해 봐야 끝까지 확인된다(내가 로그아웃하지 않았다). 대표가 다음에 로그아웃할 때 저절로 확인된다.
