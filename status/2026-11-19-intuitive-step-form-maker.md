# 2026-11-19 — 쉽게 새 양식 만들기 시각 강조 2단 배너 · ①·②·③ 단계형 스튜디오 · 실시간 종이 모양 미리보기 (`pu-contract-easy.js` · `pu-contract-forms.js` · `docs-esign.html` · `pu-erp.html`)

## 배경 및 대표 지시
- **문제점**:
  1. `계약서등관리` 상단 막대에서 `✨ 쉽게 새 양식 만들기` 단추가 오른쪽 구석에 작게 밀려 있어 한눈에 찾기 어려웠고, 좌측 목록에서는 21개 행 맨 아래까지 스크롤해야 보였음.
  2. `✨ 쉽게 새 양식 만들기` 모달을 열면 개발자 용어(`{{변수}}`)가 섞인 탭·단추·칩 18개와 분류 선택상자 3개, 예전 회사명 입력칸 3개, 빈 본문 입력창이 순서 번호나 종이 미리보기 없이 한꺼번에 세로로 나열되어 어디서부터 무엇을 해야 하는지 판단하기 어려웠음.
  3. 또한 CSS `.pce-cklbl{display:flex}` 등이 브라우저 기본 `[hidden]{display:none}`을 덮어써서 파일 선택 전에 숨겨 두어야 할 `빈 공용 서식 원본 파일임 확인` 행 등이 화면에 그대로 노출되는 버그가 있었음.
- **대표 지시 (2026-11-19)**:
  > "쉽게 만들기 를 좀더 눈에 띄게 만들고 좀 체계적으로 볼수 있게 해라 정신없다 뭘 어떻게 해야되는지 전혀 판단이 안된다 좀 더 직관적이고쉽게 해달라"

## 구현 내용
1. **상단 2카드 강조 배너 + 좌측 목록 상단 바로가기 (`js/pu-contract-forms.js`)**:
   - 비좁은 1줄 막대를 **`[거래처 서류 작성 — ⚡ 쉽게 서류 작성하기]`(파란 강조 카드)** 와 **`[새 양식 등록 — ✨ 쉽게 새 양식 만들기]`(진초록 테두리 강조 카드)** 2단 배너로 분리해 눈에 확 띄게 배치.
   - `✨ 쉽게 새 양식 만들기` 옆에 `📄 파일 올리기` · `✅ 10초 조립` · `🎙 새로 창작` 원클릭 진입 칩을 두고, 좌측 양식 목록 머리(`listHead`) 상단에도 바로가기 단추를 배치해 스크롤 없이 즉시 열 수 있게 개선.
2. **`✨ 쉽게 새 양식 만들기` 2단 단계형 스튜디오 개편 (`js/pu-contract-easy.js`)**:
   - **왼쪽(① → ② → ③ 순서만 따라가면 완성)**:
     - **① 어떻게 양식을 만드시겠습니까?**: `📄 쓰던 파일 올리기` · `✅ 10초 표준 양식 조립` · `🎙 말·글로 새로 창작` 3가지 큰 시각 카드(개발자 용어 `{{변수}}` 완전 제거, 쉬운 우리말 `자동 빈칸` 사용).
     - **② 선택한 방법으로 내용 만들기**: 고른 방법 1가지만 깔끔하게 표시. 파일 모드에서는 큼직한 파일 드롭 상자를 중심에 두고 부수적인 예전 이름 치환 도구는 `[🔧 문서 속 예전 회사·대표 이름 지우기 ▾]` 뒤로 접음. 조립 모드에서는 문서 종류 카드 4종과 조항 체크박스를 누를 때마다 오른쪽 종이 미리보기가 실시간으로 즉시 완성됨.
     - **③ 양식 이름 확인 및 저장**: `새 양식 이름` 1칸만 바로 보여주고 상위 분류·문서 역할·하위 세트 선택상자 3개는 `📁 자동 저장 위치` 1줄 요약과 `[분류·세트 바꾸기 ▾]` 뒤로 깔끔하게 정리.
   - **오른쪽(`📄 완성될 양식 미리보기` — 실시간 A4 종이 시트 + `[✏ 글자 직접 수정]` 전환)**:
     - 기본 화면에서 실제 흰 종이 모양 시트(`.pce-paper`)로 결과를 바로 확인하며, `{{회사명}}`·`{{계약금액}}` 등은 파란 `[회사명]`·`[계약금액]` 배지로 직관적으로 표시.
     - `[✏ 글자 직접 수정]` 전환 시에도 `+ 회사명 칸`, `+ 계약금액 칸` 등 쉬운 한글 단추로 빈칸을 넣을 수 있도록 개선.
3. **`[hidden]` CSS 누수 버그 원천 차단**:
   - `.pce-m [hidden],.pce-mbg [hidden]{display:none!important}` 및 `.pcf [hidden]{display:none!important}` 규칙을 추가해 파일 선택 전 원본 확인 행이나 접힌 세부 항목이 실제 브라우저에서 절대 새어 나오지 않도록 수정.
