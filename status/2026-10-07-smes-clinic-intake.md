# 2026-10-07 중진공 현장클리닉 → 푸른이알피 계약 등록 요청

대표 문의: 「현장클리닉 자문위원을 푸른노무사로 선정하는 경우 자동으로 푸른이알피에 계약내용과 담당자 금액 등을 넣게 할 수 있나」 → 목업 → 「진행해라」

- 새 딸린 화면 `clinic-intake.html`(이알피 SATELLITES.clinic_intake). 처음 열면 즐겨찾기 단추 «📤 푸른이알피로 보내기»(북마클릿) 설치 안내.
- 노무사가 스스로 로그인한 중진공 상세 화면에서 단추 → 보이는 표(칸 이름 옆 칸)·칠해진 진행 단계를 읽어 이 창에 건넴(postMessage, 우리 출처로만).
  받는 창은 smes.go.kr 에서 온 메시지만 믿는다.
- 창에서 담당 노무사(기본: 나)·선정일·예정 일수 확인 → `data/contract_requests` 한 줄(source:'smes'). 계약은 쓰지 않는다.
- 계약관리: 사진첩 요청과 «같은 문»(processOneContractRequest)으로 검사·등록. 새 `ctReqHumanFill` 이 사람이 적은 선정일·예정 일수만 얹고,
  금액은 계약 창과 같은 「1일 단가 × 일수 (+부가세)」로 셈. 일수가 비면 금액도 비움(기본값 금지 — photo-contract-auto 규칙 그대로).
- 대표자 휴대폰은 체크했을 때만 담당자 칸에. 업체관리 연결은 사업자번호로만(이름 금지), 같은 번호로 보낸 요청이 있으면 경고.
- 하지 않는 것: 중진공 대신 로그인·인증서 저장·중진공에 쓰기·계약 직접 쓰기.
- 검사: `tests/clinic-intake.test.js`(돌연변이 9개 모두 잡힘). pu-ontology.js ?v=50.
- [확인 필요] 실제 중진공 화면의 표 꼴(th/td)로 읽히는지는 대표가 한 번 눌러 봐야 확정 · 자문위원 이름이 보이는 화면을 받으면 담당 자동 고르기 가능.
