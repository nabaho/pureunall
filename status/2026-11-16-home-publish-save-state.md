# 2026-11-16 · claude/home-publish-save-state

대표 「고쳐라」 — 홈페이지 «올리기»가 새 판 자동 갈아타기에 끊긴 일(같은 날 얼굴 사진 7장 첫 올리기에서 6장째에 끊김).

## 원인
- `js/pu-version.js` 는 새 판이 오면 «저장 중이 아니고 손을 30초 놓은 탭»을 새로 연다. `pu-home.html` 의 올리기 세 길(`publishPeople`·`publishPage`·`publishPartner`)은 `pu:save-state` 를 보내지 않아, 30초 넘게 걸리는 사진 올리기 도중에 갈아탔다. 사진마다 우리 저장소 사본 커밋 → 배포가 생겨 사진이 많을수록 잘 걸린다.

## 고친 것
- `pu-home.html` — `올리는중켜기()`: 확인 창 «올리기»를 누른 «뒤», 서버에 쓰기 «전»에 `pu:save-state` saving, 끝나면(실패해도 — 실패 알림 창을 띄우기 전에) saved. 겹쳐도 마지막 하나가 끝나야 saved, 끄기를 두 번 불러도 한 번만 셈. 2분마다 다시 알림(pu-version 은 3분 넘으면 스스로 놓는다 — 경력관리 `kcBusy` 와 같은 길), 10분 넘으면 다시 알리기를 멈춰 응답 없는 올리기가 탭을 붙잡지 않게.
  - «고치는 중»(초안)에는 쓰지 않는다 — 기존 «이어쓰기» 설계(초안은 끊겨도 이어지게) 그대로.
- `tests/home-publish-save-state.test.js` — 부품 동작(켜기·끄기·겹침·다시 알림·한도), pu-version 의 막는 상태·놓는 시간과 맞물림, 세 길이 «확인 뒤·쓰기 전» 켜고 finally 에서 끄는지.
