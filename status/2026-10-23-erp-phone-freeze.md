# 2026-10-23 이알피 폰 — 틀 고정 · 요약 접기 · 드롭다운

대표 지시: 「급여 등 이 창을 좌우로 움직여야 되는데 … 폰에서는 드롭다운 방식으로」 ·
「상단은 아래 위 높이가 너무 많이 차지」 · 「ERP 폰에서 데이터가 들어가는 모든 부분 틀 고정」

폰(≤768px)만 — PC 는 그대로. css ?v=27.

## 1. 틀 고정 (`.pu-mfreeze`)
- 업체관리 · 계약관리 · 사건관리 · 컨설팅/기금/기타 의 검색·거르개 줄이 목록을 내려도 맨 위에 붙는다.
- 계약관리는 폰에서만 `position:static` 이던 것을 sticky 로.
- 입금관리·출금관리는 이미 붙어 있었다(손대지 않음). 종료관리는 도구줄이 카드 묶음 안이라 이번에 안 함 — 남은 일.

## 2. 요약 숫자 한 줄 (MonthKpiHeader — 업체·계약·사건·컨설팅 등 공용)
- 폰에서는 「📊 운영 업체 277개 · 활성 자문 211개 · …」 한 줄로 접힌다. 누르면 예전 상자, 「▴ 요약 접기」로 다시 접는다.
- 펼침은 이 기기에 기억(`pucards_mkpi_open`).

## 3. 옆으로 미는 줄 → 고르기 상자
- 업체관리: 상태(활성/사무대행)·유형(자문 89·급여 113·노조…) 칩 → 고르기 상자 둘(건수 그대로). PC 는 칩 그대로.
- 업체관리: 정리 도구 단추 여섯 + 📥 → 「🛠 도구」 고르기 하나(그때 있는 도구만, 설명은 같은 tip 상수).
- 사건·컨설팅/기금/기타: 이미 고르기 상자였던 거르개가 옆으로 밀리던 줄 → 한 줄에 나눠 앉고 모자라면 아랫줄.
- 업체 「N건 선택」 줄도 옆으로 밀지 않고 줄바꿈.

## 4. 덤으로 고친 것
- 사건관리 폰: 상태 고르기의 기본값(종결 제외)에 맞는 항목이 없어 **빈칸**으로 보였다 → 「종결 제외」 항목 추가.
- 컨설팅·사건 폰 카드가 글자 크게일 때 화면보다 넓어(425/411) 오른쪽 「진행중」이 잘림 → `.m-card` 를 border-box·max-width 100%,
  금액 줄은 모자라면 합계가 아랫줄로.
