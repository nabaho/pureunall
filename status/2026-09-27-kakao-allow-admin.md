# 2026-09-27 · kakao-allow-admin — 관리자도 카카오 로그인

대표 지시 「관리자도 카카오 로그인되게 해라」. 처음 결정(관리자·위임관리인은 비밀번호로만)을 뒤집었다.

## 한 것
- `functions/kakao.js` — 연결·로그인에서 관리자 막음을 걷었다. 재직자(status active)만인 것은 그대로.
  남의 연결 끊기는 여전히 관리자만.
- `functions/index.js` requireStaff — 카카오로 들어온 사람도 메일·급여명세서·메일함·하나 알림 등을 쓰게 했다
  (전에는 비밀번호 로그인만 받아서, 카카오로 들어온 대표님이 메일을 못 보냈을 것이다). 보낸이 email 이 표에 없으면 계정에서 채운다.
- 검사: `kakao-login` 관리자 연결·로그인 되는지, `payslip-send-token` 카카오 표 통과·카카오 표시 없는 서버 표는 막힘. 되돌림 3개 모두 걸림.

## 카카오 앱을 새로 만들었다
- 옛 앱 1589416 은 어느 카카오 계정이 관리자인지 끝내 못 찾았다 → 대표 계정으로 새 앱 **1589519 「푸른토탈서비스」**.
- 비밀값 KAKAO_REST_KEY v4 · KAKAO_CLIENT_SECRET v3 (모양만 검사해 넣음). 카카오 왕복은 확인 —
  로그인 화면에서 「연결되지 않은 카카오 계정입니다」까지 나왔다(키·비밀·복귀주소 모두 맞다는 뜻).
