# 2026-09-23 · 📲 「앱으로 깔기」 — 포털 머리 카드에서 설정 창·⋯ 로

- 가지: `feat/app-install-spot`
- PR: (열면서 채움)
- 대표 지시: 「이상하다 그리고 앱으로 깔기 여기 위에 두지 말고 다른곳에 둘곳 목업해달라」
  → 목업(스크래치패드 `app-install-spot.html`, 저장소에 안 둠)에서 **③ 설정 창 안** 을 고르셨다.
  → 설정 창이 API 열쇠가 든 **관리자 전용**이라 직원 폰에서 깔 길이 사라지는 것을 여쭈었더니
    **「관리자는 설정, 직원은 ⋯」**.

## 왜 이상해 보였나

- 「앱으로 깔기」는 폰 전용인데 PC 크롬도 「깔 수 있음」 신호를 보내 **PC 머리 카드에도 떴다.**
  그 한 칸 때문에 「건의하기」가 카드 밖으로 밀려 나갔다.
- PC 에서는 **눌러도 아무 일도 없었다** — 누름 배선이 폰에만 돼 있었다.
- 같은 캡쳐에서 ✨ TypeSafe 가 안 보인 것은 그 순간 PR #1572 배포가 아직 돌던 중이라서였다.

## 바뀐 것 (`enter.html`)

| 누구 | 어디서 깐다 | 언제 보이나 |
|---|---|---|
| 관리자 | ⚙ 설정 창 안 한 줄 「📲 이 기기에 앱으로 깔기 [깔기]」(장애 알림 바로 아래) | 폰 기기이고 아직 안 깔았을 때 |
| 직원 | 폰 ⋯ 더보기 안 「📲 앱으로 깔기」 | 폰 폭(520px 이하)이고 아직 안 깔았을 때 |
| PC | 어디에도 없다 | — |

- 배선은 그대로 `<head>` 에 둔다(파이어베이스가 안 닿는 날에도 깔 수 있게). 누르면 안드로이드는
  설치 창, 신호가 없는 브라우저(아이폰 등)는 `install.html` 세 걸음 안내.
- ⚠ 관리자 여부를 «알기 전»에는 어느 쪽도 안 띄운다(`__puInstallAdmin` 이 참/거짓으로 정해진 뒤).
- 옛 모양 `.pcview`·`.appinst` 는 마지막 사용처가 없어져 걷었다.

## 고치다 찾은 것 — 직원 폰 ⋯ 에 떠 있던 「⚙ 설정」

⋯ 안 단추의 `.docked` 가 `display` 를 `!important` 로 켜서, 관리자 전용 「⚙ 설정」
(직원에게는 `style.display='none'`)이 **직원 폰 ⋯ 안에 눌러도 안 열리는 채로 떠 있었다.**
`#moreDock .docked[hidden]{display:none!important}` 를 두고 설정 단추에도 `hidden` 을 건다.
