# 2026-09-18 · 안내판이 한 번도 안 떴다 — «글월»에서 낱말을 찾아 상태를 되짚었다

가지 `claude/login-start-screen-386qu2`

## 무엇이 있었나

역방향 프록시 안내판(#1434)을 붙이며 이렇게 폈다 —

```js
if(!(진단 && 진단.ok === false && /CORS/.test(진단.msg || ''))) return null;
```

그런데 그 글월에는 **「CORS」라는 글자가 없다.** 사람 말로 이렇게 적었기 때문이다 —

> 막는 것은 딱 하나 — DSM 이 **이 화면의 주소를 안 받아들입니다.**

그래서 정작 원인이 CORS 일 때 **안내판이 한 번도 안 떴다.** 대표님 화면에도 없었다.
칸마다 복사 단추를 달아 둔 그 판이, 가장 필요한 순간에 숨어 있었다.

## 규칙

**글월을 보고 상태를 되짚지 말 것.**
글월은 «사람이 읽으라고» 고치는 것이고, 고치는 순간 그 되짚기가 **조용히** 죽는다.
`nasReachProbe` 는 이미 `kind`(`cors`/`blocked`/`silent`)를 돌려준다 — 그것을 그대로 들고 다닌다.

```js
set진단({ ok:false, kind: r && r.kind, msg: 말 });
…
if(!(진단 && 진단.kind === 'cors')) return null;
```
