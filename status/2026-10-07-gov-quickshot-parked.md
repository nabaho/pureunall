# 2026-10-07 정부컨설팅 「📷 오늘 바로 찍기」 — 대표가 «나중에»

- 대표 물음: 사진 찍고 보고서·사진 업로드를 자동화할 수 없나. 아픈 곳은 사진 넣기 + 기관 사이트 업로드
  (노사발전재단·기술보호·현장클리닉).
- 제안: ① 폰에서 오늘 내 방문 → 카메라 바로 → 찍은 시각 도장 → 빈 칸 저장(5~6번 → 3번)
  ② 사진첩 사진을 빈 칸 후보로 자동 배치(✔ 한 번 확정) ③ 기관별 제출 묶음 ④ 기관 사이트 입력 도우미(로그인·제출은 사람).
- ①은 목업만 보냄(저장소에 안 넣음) → 대표 「나중에 한다」. 코드 변경 없음.
- 다시 시작할 때 물을 것: 사무실 일정 포함? · 도장 시각(실제 찍은 시각 권장) · 저장 확인 한 번 vs 바로 저장.
- ③·④에는 기관별 업로드 화면 캡처·파일 규칙이 필요하다.
- 대표 덧붙임(같은 날): 「폰에서는 직접 작업하지 않고 진행상황 확인만 한다 — 몇 차례 진행중이었는지 확인한다」.
