# 지역뉴스 4단계 — 안전한 철회와 발송 제외

## 발견한 문제

- 회차의 지역뉴스 `✕`는 배열에서 `splice`하여 자료를 물리 삭제했다.
- 누가 왜 뺐는지 남지 않고, 여러 관리자가 동시에 고치면 낡은 화면의 배열 자리로 다른 기사를 지울 위험이 있었다.
- 수동 등록 지역뉴스에는 온톨로지 필수 식별자와 버전 정보가 없었다.

## 개선

- 삭제 대신 `상태: 철회`와 철회사유·철회자·철회일·수정차수를 남긴다.
- 회차 전체를 덮어쓰지 않고 해당 회차의 지역뉴스 경로를 transaction으로 다시 확인한 뒤 철회한다.
- 같은 배열 자리뿐 아니라 영구 ID(옛 자료는 공식 링크)까지 일치할 때만 바꾼다.
- 철회 자료는 화면에 이력 건수로 남되 주소별 HTML·평문·대량발송에서는 빠진다.
- 수동 등록에도 영구 ID, 개체 종류, 스키마·계약 버전, 출처 종류·출처 ID를 붙인다.
- 2026-09-06 이전 자료처럼 상태가 없는 기존 지역뉴스는 계속 활성으로 읽는다.

## 검증

- 지역뉴스 수집·검토·철회·주소별 발송 관련 시험 25개 통과.
- JavaScript 캐시 버전 검사와 diff 공백 검사 통과.
