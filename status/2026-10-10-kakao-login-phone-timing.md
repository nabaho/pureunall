# 2026-10-10 · 휴대전화 로그인 단계별 시간 확인

대표 요청: 카카오 로그인 지연이 계속되어 다음 개선 단계를 정해야 한다.

- 포털 탐색 시작, 카카오 복귀 화면 준비, 서버 응답, 인증 저장소 준비, Firebase 로그인, 타일 준비 시간을 이 기기에만 기록한다. 버튼부터 포털까지의 시간에는 카카오 계정 선택·동의 화면에서 보낸 시간도 포함됨을 표시한다.
- 저장값은 숫자와 시각·로그인 종류뿐이다. 계정, 사번, 토큰, 명부, 오류 전문은 기록하지 않는다. 카카오 로그인과 저장된 세션 재방문 결과를 별도 저장해 서로 덮지 않는다.
- 관리자 `⚙ 시스템 설정 → 휴대폰 로그인 속도 → 시간 보기`에서 마지막 측정값을 확인한다. 서버 전송이나 추가 DB 읽기는 없다.
- 이 변경은 계측 단계이며, 인증 경로·로그아웃·권한 검사를 바꾸지 않는다. 실제 병목은 같은 휴대폰에서 여러 번 측정한 뒤 판단한다.
- 검사: `tests/login-timing-diagnostic.test.js`와 카카오·인증 화면 관련 검사 통과. 전체 `node --test tests/*.test.js` 24,146개 통과·55개 건너뜀·실패 0개. `node scripts/check-cache-version.js` 통과.
- 운영 사이트에는 아직 배포하지 않았다. 배포 뒤 같은 휴대전화에서 저장된 세션 재방문과 새 카카오 로그인을 각각 재서 다음 병목을 고른다.
