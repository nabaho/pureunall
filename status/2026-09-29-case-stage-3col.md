# 이알피 환경설정 › 사무관리기준 › 사건 심급·단계 — 세 칸 정리

- 대표 지시 2026-09-29 「세로로 노동위 산재 노동청으로 열을 3으로 나눠서 정리」(목업 두 번 보고 결정).
- 세 칸 = 노동위원회 · 산재 · 노동청. 「법원」 칸은 없애고, 행정소송(orgKind:'court')은 노동위·산재 칸 맨 끝에 점선 «함께 쓰는 단계»로 붙인다 — 자료는 하나.
- 한 줄 = 약어 + 이름만. 단계 사이 ↓ 옆에 기한(송달일 + 10일), 확인 전이면 ⚠. 「확인 필요」 다섯 번 → 머리 단추 「⚠ 기한 N개 확인 전」 하나(누르면 첫 단계가 열림).
- 줄마다 있던 ✏·× 는 없앴다 — 단계를 누르면 아래에 편집 칸 하나(이름·약어·기관·기한·확인함·설명·적용유형·삭제/숨김).
- 늘 펼쳐져 있던 맨 아래 추가 칸 → 칸 머리의 「+ 추가」(그 칸의 기관으로 들어간다). 법원 단계는 편집 칸의 기관을 「법원」으로 바꿔 만든다.
- 기관 없는/모르는 단계는 세 칸 아래 「그 밖의 단계」 한 줄 — 사라지지 않는다.
- 저장 자료(biz_case_stages) 모양은 그대로. 사건 화면·기한 계산은 안 건드림.
- caseStageGrouped 가 돌려주는 모양이 바뀌었다: 배열 → { cols:[3칸], etc:[] }. 쓰는 곳은 카드 하나뿐.
- 검사: tests/case-stage-card.test.js (세 칸·행소 공용·확인 단추·편집 칸 하나), tests/case-stage.test.js.
- ⚠ 로그인 화면을 못 띄워 실제 브라우저로는 못 봤다 — 검사는 카드를 실제로 그려서 본 것까지.
