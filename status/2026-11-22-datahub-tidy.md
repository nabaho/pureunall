## 파일
- `pu-datahub.html` — 위 막대·머리말·접기 HTML, CSS 끝의 «정리판» 덩어리(되돌리기 = 그 덩어리 지우고 이 PR 앞으로). 화면 스크립트 `?v=2`(옛 스크립트가 없어진 단추를 부르지 않게).
- `js/pu-datahub-view.js` — 각 화면 보기 단추 → `applyGlobalMode`(모든 화면), 없앤 위 막대 단추 손잡이 지움(없는 단추를 부르면 손잡이 달기가 통째로 멈춘다).
- `tools/phone-audit/seeds/datahub.js` — 눌러 보기 `mode3d`(A 화면에서 3D → 전체 배치·다년·업체 도시 모두 3D 인지, 아니면 오류).
