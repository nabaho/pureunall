## ★★ 먼저, 정직하게 — «완전 자동»은 안 된다

국세청 조회는 상태(계속·휴업·폐업)와 세금 갈래만 준다. **상호를 안 준다.**
그래서 기계가 「보성」과 「부성」 중 어느 쪽이 맞는지 **알 길이 없다.**

그래서 목표를 바꿨다 — **「기계가 알아서 고친다」가 아니라
「사람이 한 번만 보면 끝나게 한다」.** 그 길이 둘이다.

## ① 고친 «글자 짝»을 기억해 제안한다

대표가 ✏ 로 「농업회사법인주식회사보성」 → 「농업회사법인 주식회사 부성」으로
고치시면, 앱이 거기서 **「보 → 부」** 하나만 뽑아 적어 둔다.
다음에 다른 회사에서 「보」가 든 이름을 고치실 때 —

> 전에 이렇게 고치셨습니다  [ **보→부 · 부성물산** ]

누르면 **적을 칸에 채워만 준다.** 확인하고 「✏ 상호 고치기」를 누르셔야 바뀐다.

### ⚠⚠ 자동으로 바꾸지 않는다

「보→부」를 외워 두고 자동 적용하면 **「보건부」가 「부건부」**가 되고,
「보증」이 「부증」이 된다. **제안까지가 안전선**이다.
그래서 화면에 **무엇을 바꾸자는 것인지(보→부)를 함께 적는다** — 그것이 없으면
잘못된 제안을 걸러낼 수가 없다.

### ⚠ 뽑는 규칙

| | |
|---|---|
| 띄어쓰기 | **글자로 안 센다** — 대표의 실제 고침이 띄어쓰기가 늘어난 것이었다. 공백까지 세면 길이가 달라져 **아무 짝도 안 뽑힌다** |
| 길이가 다르면 | **안 외운다** — 글자가 빠지거나 더해진 것은 오독이 아니라 이름을 새로 적으신 것이다 |
| 서너 글자가 한꺼번에 | **안 외운다** — 오독이 아니라 다른 이름이다 |
| 언제 외우나 | **쓴 뒤에.** 「아니오」를 누르셨는데 외워 두면 일어나지도 않은 고침을 제안한다 |
| 어디에 | **이 PC** (「중복 아님」과 같은 결). 서버에 올리면 한 사람의 오타가 스무 방의 제안이 된다 — 먼저 여기서 값어치를 재고 그다음에 옮길 일이다 |

## ② 🔗 합치기가 «한 글자 다른» 줄도 찾아낸다

잘못 읽힌 이름은 한 회사를 **두 줄**로 갈라놓는다. 그런데 합칠 상대를 찾는 자리가
**글자 그대로 훑는 것**이라, 「부성」으로 찾아도 「보성」 줄이 **안 나왔다** —
합칠 길이 통째로 막혀 있었다.

이제 글자가 안 들어맞아도 **한 글자 다른 줄**을 함께 올린다.

- ⚠ **두 글자 이상 다르면 안 본다.** 그것은 오독이 아니라 다른 회사다
  (「두레」/「두레전자」처럼 이름이 겹쳐도 다른 곳인 쌍이 실제로 있다)
- ⚠ **길이가 다르면 안 본다** — 「가나」와 「가나상사」가 합쳐지면 안 된다
- ⚠ 한 글자짜리 이름끼리는 안 본다 — 다 「한 글자 차이」다
- ⚠ **글자가 그대로 들어맞는 줄이 언제나 먼저**다. 짐작한 것이 앞에 서면
  확실한 것을 못 보고 지나친다
