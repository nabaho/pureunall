# 2026-11-18 담당자함 개인별 메일 소분류 · 자동정리 · 규칙 학습 · 처리완료 기능 구현

## 배경 및 문제
- 김보람 과장 등 여러 역할을 겸임하는 직원의 담당함(`@담당자`)에 기한이 급한 고객사 인사노무·급여 메일과 월말 결산용 법인 자체 세금계산서·공과금·렌탈 청구서, 사무실 잡무 메일이 한데 섞여 긴급 고객사 메일이 청구서 더미에 묻히는 문제가 있었음.

## 해결 내용
1. **담당자함 개인 소분류 탭 바 (`mbSubBarHtml`, `mbSubMobileBarHtml`)**:
   - 공용 폴더(`담당자 10`, `업무별 22`)는 그대로 유지한 채 개인 담당함(`@직원`) 상단에 `⚡ 고객사 노무·급여`(기본 첫 화면), `🧾 법인회계·청구서`, `🏢 법인총무·잡무`, `전체`, `✅ 처리완료` 탭 제공 및 옆 탭 건수·안읽음 수 실시간 표시.
   - `⚙ 탭 관리`(`openMbSubMgr`)에서 개인별 맞춤 탭 추가·이름 변경·순서 조정·기본 첫 탭 변경 지원.
2. **3단 정밀 자동 분류 (`mbSubTabOfRow`)**:
   - ① 개별 메일 지정 → ② 개인 학습 규칙(제목·첨부 단어 규칙 / 발신자 주소 규칙) → ③ 문맥 기반 자동 분류(같은 세무회계법인 발신이라도 고객사 원천징수·급여 메일은 `고객사 노무·급여`로, 우리 법인 앞 세금계산서·한전·통신·카드·이카운트 청구서는 `법인회계·청구서`로 자동 분기).
3. **원클릭 규칙 학습 및 드래그 이동 (`mbSubMoveMenu`, `mbSubApplyMove`, `mbSubTabDrop`)**:
   - 메일 줄의 소분류 알약(`▾`) 클릭 또는 탭으로 끌어다 놓기로 즉시 분류하고, 발신자·단어 자동규칙 체크 시 과거·신규 메일까지 자동 반영.
4. **원클릭 처리완료 체크 (`mbSubToggleDone`, `mbSubDonePicked`)**:
   - 처리 끝난 노무·회계 메일을 `✓` 한 번으로 진행중 탭에서 비워 `✅ 처리완료` 탭으로 정리.
