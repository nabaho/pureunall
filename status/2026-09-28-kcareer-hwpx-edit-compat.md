# 경력관리 HWP/HWPX 편집 호환성 개선

- 자동 채움 뒤 제거된 줄 배치 정보를 완성본에서 다시 계산하고, 다시 열리는지 검사한 뒤 저장한다.
- 빈 칸에 값을 넣거나 도장 그림을 붙일 때 원본 문단의 글자 모양을 이어받아 글꼴·줄 높이가 달라지지 않게 했다.
- `(날인)`, `서명란`, `날인란`, `서명 및 인`도 안전한 도장 자리로 인식한다.
- 웹 편집기·한글 프로그램·완성본이 같은 HWPX 바이트를 사용하도록 자동채움의 모든 경로를 같은 마무리 관문으로 모았다.
- 전체 검사 20,191개 중 20,140개 통과, 51개 건너뜀, 실패 0을 확인했다.
