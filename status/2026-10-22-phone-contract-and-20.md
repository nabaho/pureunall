# 2026-10-22 폰 — 업무 목록 20건 제한 · 계약 창 세로깨짐/단추 밀림

대표 지시: 「폰에서 사업장 20개밖에 못 본다 모든 데이터 다 보게 해달라」 ·
「폰화면 고쳐라 너무 길게 아래로 내려왔다 푸른이알피 계약관리 모든 부분 검토해서 ui 이상한 거 찾아 고쳐라」

## 고친 것 (pu-erp.html · css/pu-erp.css ?v=25)
1. **컨설팅·기금·기타(현장클리닉 등) 폰 목록이 20건에서 끝나던 것** — `ProjectManagementShared` 가 한 쪽 20건으로
   자르는데, 쪽 넘김 단추는 PC 표 쪽에만 있었다. 폰 카드는 이제 거른 «전부»를 그린다. PC 표는 그대로 쪽을 나눈다.
   (사건·업체 목록은 폰에도 쪽 넘김 단추가 있어 손대지 않음. 계약관리 목록은 원래 쪽을 안 나눔.)
2. **「CMS 자동이체」·「개인입금」 글자가 한 자씩 세로로** — 폰 CSS `.fld input{width:100% !important}` 가
   체크박스까지 100% 로 늘렸다 → checkbox·radio 를 뺐다(PC 규칙도 같이). 계약유형 0개일 때 CMS 줄을
   `.fld`(라벨 110px) 밖으로 꺼냈다 — 같은 이름을 두 번 적던 바깥 라벨도 없앴다.
3. **취소·이전·다음 단추가 화면 아래로 밀림 · 「취/소」 두 줄** — 폰에서 계약 창을 세로 상자(94vh)로 두고
   본문만 남은 높이를 채워 구르게 했다(`.modal[data-phone-fit]`). 바닥 단추는 nowrap, 모자라면 «다음»만 … 로 줄어든다.
4. **「기업담당자」 제목이 단추 둘에 밀려 세로로** — 제목 nowrap, 단추가 대신 아랫줄로.

## 점검 도구 (tools/phone-audit — 개발용, 배포 안 됨)
- `--font=1.4` 새로 — 폰 «글자 크게»(접근성 배율) 흉내. 보통 크기에서는 위 2~4가 안 보였다. 대표 폰이 글자를 크게 쓴다.
- erp 시드에 계약 창 세 탭 + `contract-nokind`(새 계약, 유형 0개) 화면을 더했다.
