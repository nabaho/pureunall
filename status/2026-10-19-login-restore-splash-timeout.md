# 로그인 복원 중 포털 로그인 화면 자동 노출 제거 (2026-10-19)

- 제보: 카카오 로그인 뒤 앱에서 돌아올 때 포털의 노란 로그인 화면이 잠깐 나타난다.
- 확인: 포털 부팅 스크립트가 인증 결과를 받지 못해도 40초가 지나면 가림막을 자동으로 걷는다. 이전 휴대전화 측정에서 Firebase 저장 로그인 복원은 40초를 훨씬 넘었다.
- 수정: 인증 결과 전에는 시간만으로 가림막을 걷지 않는다. 실제 미로그인은 인증 알림에서 즉시 열고, 인증 도구가 멎으면 8초 뒤 제공되는 단추로 사람이 직접 로그인 화면을 열 수 있다.
- 검사: 보이는 탭과 숨은 탭에서 60~95초를 가짜 시계로 흘려도 자동 노출하지 않으며 수동 단추는 작동하는지 확인한다.
- 남은 확인: 대표 휴대전화에서 앱 뒤로 가기 및 카카오 재로그인 시 실제 노란 화면 재출현 여부를 확인한다. 다시 나타나면 `pu_login_flash_log`의 원인·시각을 보고 인증 알림 경로를 따로 진단한다.
