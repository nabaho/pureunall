# 2026-09-20 fix/cal-darker-text

## 무엇을 했나

대표 지시 「한글과 숫자가 좀더 진했으면 좋겠다」.

- `.dnum`(달력 칸 날짜 숫자) `font-weight:400` → `600`. 색(`--ink` #1e293b)은
  이미 짙었지만, 12px에 보통 굵기라 연해 보였다.
- `chipHtml`의 「남의 것」 글자색 — 밝은판만 `mixHex(사람색,"#000000",.58)` →
  `.72`로 검정을 더 섞었다. 재 보니 대비도 오히려 좋아졌다(최악 5.86:1 → 9.15:1,
  실제 색 27가지로 확인). 어두운판(.50)은 이미 흰 쪽이라 안 건드렸다 — 더 섞으면
  색이 지워진다.

## 「주의 요함」 문의

같이 여쭤 주신 크롬 주소창의 「주의 요함」 표시 — pu-cal.html 이 부르는 자료를
전부 다시 받아 확인했다(개발자 도구 콘솔·네트워크). 전부 `https://` 로 200
받아지고, 섞인(HTTP) 자료나 콘솔 오류가 없다. 우리 페이지 자체의 문제는
아니다 — 크롬이 «자주 안 가 본 사이트」로 보고 붙이는 표시일 가능성이 크다.
대표님 크롬에서 그 표시를 눌러 보시면 정확한 문구가 나온다(내가 대표님
크롬을 직접 볼 길이 없어 확인은 못 했다).
