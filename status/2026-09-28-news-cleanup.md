# 뉴스레터 — 중복·죽은 코드 정리

대표 지시 2026-09-28 「뉴스레터 전체적으로 중복 불필요한 코딩 죽은코딩등 검토하고 정리해라.
단 다른 앱과 연결되어 있는곳에 문제되면 안된다.」

## 어떻게 찾았나 — 셈으로

뉴스레터 파일 20개(약 1만 6천 줄)의 함수·상수·내보낸 이름을 **저장소 전체**(다른 앱·서버·검사)에서
몇 번 부르는지 셌다. 주석 안의 이름은 부름으로 안 쳤다. 몸통이 같은 함수도 짝지어 찾았다.

| 본 것 | 결과 |
|---|---|
| 화면 함수·상수 225개 | 아무도 안 부르는 것 **1개**(`늘어놓기`) |
| 두 번 선언된 함수 · 쓰기만 하는 App 칸 · 없는 자리를 찾는 부름 | 없음 |
| 모듈 안의 죽은 함수 | 없음 |
| 서버 창구(함수) 14개 | 모두 누가 부르거나 예약으로 돈다 — 죽은 창구 없음 |
| 안 쓰는 꾸밈(CSS) | **9개** |
| 같은 일을 두 벌로 하는 곳 | 화면 ↔ 금요일 준비(서버) **8가지** · 지역판 끼우기 · 확정본 도장 |

## 지운 것 (죽은 것)

- `늘어놓기` — 받는 명단 표가 회사 단위로 바뀐 뒤 줄 세우기는 `사업장으로묶기` 가 한다. 옛 도우미만 남아 있었다.
- 꾸밈 9개 — `.way.on` · `.law-ok/mid/bad` · `.grid2`/`.wide` · `.sect` · `.pad.g3`/`.w2`/`.w3`(설정이 반 폭 2열로 바뀐 뒤 안 씀).

## 한 벌로 줄인 것 (겹친 것)

금요일 자동 준비(서버)가 화면 코드를 **베껴** 들고, 검사가 «둘이 같은가»를 지켜보던 것들 —
이제 **Core 한 곳**에 두고 화면·서버가 같은 것을 부른다(서버는 `functions/news-lib/` 사본으로).

| 옮긴 곳 | 무엇 |
|---|---|
| `Core` | 자료·판례 줄 세우기(`값어치순`·`최근것`) · 추적 번호(`새추적번호`) · AI 지시 셋(`기사초안지시`·`한마디지시`·`밑줄지시`) · 한마디 거리·자르기(`한마디거리`·`한마디다듬기`) |
| `Tpl` | 지역판 끼우기(`지역판씌우기`) — 화면 시험 발송 · 금요일 검토 메일 |
| 서버 월요일 문지기 | 확정본 도장 두 번째 벌을 걷고 Core 사본의 `바탕도장` 을 부른다 — 2026-09-27 빈 목록 고장이 «두 벌이라 한쪽만 고치면 확정본이 버려지는» 바로 그 자리였다 |

- 화면 `pu-news.html` −125줄 · 서버 `news-friday.js` −105줄 · `news-ready.js` −52줄 (옮긴 몸통은 Core 에 설명과 함께).
- 검사 7곳은 **규칙은 그대로, 보는 자리만 Core 로** 옮겼고, «화면·서버가 그 한 벌을 실제로 부르는가»를 더 본다.
  서버 것이 Core 사본의 «바로 그 함수»인지(===)까지 본다 — 또 베끼면 걸린다.

## 일부러 둔 것 (다른 앱과 이어진 곳)

- `골고루`(뉴스 모으기 ↔ Core) · `날짜꼴`(판례 ↔ 자료) — 한 벌로 만들면 **홈페이지 자동 브리핑**을
  올리는 서버 함수(weeklyNewsBrief)·아침 모으기까지 다시 올려야 한다. 몇 줄 얻자고 이어진 곳을 흔들지 않는다.
- `esc`(글자 막기) — 화면과 서버에서 따로 돈다. 몇 줄짜리라 합치면 오히려 서로 묶인다.
- 모듈의 «밖에서 안 쓰는 내보내기» — 전부 안에서 쓰는 함수다. 검사가 쓰는 것도 있다. 목록만 헐거울 뿐 죽은 코드가 아니다.

## 검사
