# 2026-11-22 · claude/gov-pursue

대표 지시 「정부사업 신청에서 컨설턴트 모집이나 연구사업 일을 진행한다면 … 푸른노무법인에서 사업 진행 아니면 컨설턴트 모집 지원과 관련되는 클릭을 만들어 주고 … 진행했다면 정부사업 신청에서는 푸른노무법인 지원사업으로 표시를 해주고 사업 신청서 그리고 관련되는 서식을 다 끌어오고 모으고 … 경력관리에 정부사업 신청 항목(기존에도 있었을 것)」 · 「프로세스나 프로그램을 만들고 싶으니 이와 같이 반영해 달라」.
대표 결정(같은 날, 질문 셋): ① 법인 진행은 경력관리 **기존 «🏢 사업관리»**에 담는다 ② 정부사업신청에 **별도 탭 + 딱지** ③ 서식은 **이름·링크 모으기**(파일은 사람이).

## 한 것
- **공고 줄의 「📝」 → 고르는 창**(`pursueAsk`) — 공고 모아보기·📍 충청권·🤖 AI·🧑‍💼 컨설턴트 모집(예전 ☐ 지원 → 📝 진행) 모두 같은 창.
  - 🏢 **푸른노무법인 사업으로 진행**(`pursueCorp`) — 표시하고, 나라장터 공고면 첨부 서식 링크를 모아 결과 창(「🏢 경력관리 사업관리에 담기」).
  - 👤 **컨설턴트로 지원 준비** — 예전 「📝 지원 준비」 길 그대로(`toForm`·`applicationFromHit` → 경력관리 지원 작업함). 넘길 때 표시도 한다(`applicationHandoff` → `purMarkSource`, 🎯 ☐ 지원 포함). 이미 🏢 로 고른 공고의 갈래는 바꾸지 않는다.
- **「🏢 푸른 지원사업」 탭**(폰 「지원사업」) — ☐ + № · 갈래(🏢 법인 진행/👤 컨설턴트 지원) · 출처 · 제목 · 기관 · 진행일 · 마감 · 서식(📎 N) · 할 일(🏢 사업관리/👤 작업함 · ✕ 그만둠). 보기: 진행 중 · 마감 지난 것 · 그만둔 것 · 전체. 고르면 「N건 선택 · ✕ 그만둠으로 / ↩ 다시 진행」(건수 묻고 한 번에 저장). 탭에 진행 중 건수.
- **딱지** — 공고 모아보기·충청권·AI·컨설턴트 모집·🎯·공고 상세 창에 「🏢 푸른 진행」/「👤 지원 준비」.
- **기록** `gov/{uid}/pursue/{id}`(GovSync `pursue`, 줄마다 영구 id `PS-…`, `entityType:'Project'`) — 판정은 `js/gov-pursue.js` 한 곳. 공고 줄이 정리돼도 탭이 그려지게 제목·기관·마감을 베껴 둔다. **지우지 않는다** — 「그만둠」으로 옮기고 사람이 되살린다.
- **서식 링크 모으기**(나라장터) — `GovG2b.specFiles`(stdNtceDocUrl + ntceSpecDocUrl1~10 · ntceSpecFileNm1~10) · `GovG2b.filesFrom`(그 공고일 «하루치» 목록에서 번호·차수로 찾기 — 매일 받기와 같은 조회라 7일 제한 안, 한두 번 호출). http(s)만·아이디 박힌 주소 버림·같은 주소 한 번. 못 모으면 까닭(`filesErr`: 인증키 없음·공고일 모름·오류·목록에 없음)을 남긴다. 기업마당·알리오·모집 글은 «원문 공고에서»로 밝힌다.
- **경력관리 받는 문** `kcareer.html?go=biz` → `kcBizFromGov` — 같은 사이트 localStorage `pu_kc_biz_handoff`(10분, 읽으면 지움)로 받아 **사업 창을 채워 열기만**(저장은 사람이). 칸 짝은 `KcareerBiz.fromGov`(단계 「준비」·구분: 나라장터·알리오 입찰·용역 / 기업마당 공모·바우처 / 모집 글 수행기관 · 마감 · 금액 · 메모 · `govRef`). 같은 공고는 `govRef`(정부사업신청 기록 id)로 찾아 그 사업을 열고 새 서식 링크만 더한다(`mergeGovFiles` — 사람이 고친 갈래는 안 덮음).
  - 사업 창에 「🔗 공고 첨부 서식 N개」(갈래 짐작은 `guessDocKind`) — 그릴 때 주소를 다시 거른다. 파일은 내려받아 「＋ 파일 올리기」로 담아야 비교·다시 쓰기·서류 찾기에 든다.
- 캐시 번호: gov-g2b 13 · gov-sync 11 · gov-pursue 1 · kcareer-biz 10. 서버 사본 `functions/vendor/gov-g2b.js` 같이(서버 동작은 안 바뀜 — 새 함수는 화면만 쓴다).
