## 확인 결과 (공식 문서와 구글 CDN 의 실제 파일)

- **문서로는 «된다»**: 구글 CDN 에 `firebase-data-connect.js`(13.2.0) 가 있고 질의 함수 · 로그인 증표 붙이기가 들어 있다.
  권한은 기본이 «아무도 못 씀»이며 `auth.token.staff == true` 로 재직자만 열 수 있다. 서버 집계(합계·개수·평균·묶음)와 서울 지역을 지원한다.
- **조건 셋**: ① 구형 compat 판이 없다(`js/pu-mfa.js` 가 선례) ② [실제 시험] 생성 도구 없이 `queryRef` 를 직접 부르는 길
  ③ [실제 시험] 판이 다른 두 로그인(구형 10.13.2 · 새 13.x)이 같은 로그인 상태를 읽는지.
- 올리기 도구에 경고를 무시하는 `--force` 가 있어, 우리 올리개에서 막아야 한다(검토 문서 7절 5번).
