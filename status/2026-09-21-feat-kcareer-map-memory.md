## 왜 필요했나

2026-09-20 에 대표 계정을 열어 보니 AI 짝짓기가 **21개** 쌓여 있었고,
그중 여섯이 «목록 표가 아닌 것»을 목록으로 만들고 있었다(평가기준표가 «경력 목록»이 되는 식).

그런데 **무엇이 쌓였는지 볼 길이 아예 없었다** — 대표도, 나도.
그래서 「계속 이상하다」가 몇 주 되풀이됐고, 나는 자료 탓이라 짐작해 대표께 두 번이나
「학력이 중복이냐」고 되물었다(틀린 짐작이었다).

## 무엇을 만들었나

환경설정 › **데이터 관리**에 **「🧠 서식 기억」** 카드.

- 기억해 둔 **열 짝짓기**와 **칸 짚기**를 표로 보여 준다
- 줄마다 **쓰임**을 적는다 — `✓ 씀` 또는 `🚫 …`
- 하나씩 지우기 · **「🧹 막힌 것만 지우기」** · 「🗑 모두 지우기」

### ★ 「안 쓰임」의 까닭을 «셋 다» 본다

채우는 쪽에는 빗장이 셋이다. 화면이 하나만 보고 「씀」이라 하면
**대표가 엉뚱한 것을 지우게 된다.**

| 화면에 적히는 것 | 뜻 |
|---|---|
| `🚫 머리줄이 아님` | 빈 칸·칸 안 라벨·한 글자 이름 — 울타리가 막는다 |
| `🚫 사전이 이미 앎` | 사전이 알아보는 줄이라 AI 답을 안 쓴다 |
| `🚫 열쇠가 둘 미만` | 목록 표로 안 본다 |
| `✓ 씀` | 셋을 다 지났다 — 이것만 실제로 쓰인다 |

실제 대표 기억으로 돌려 본 결과:

```
🚫 머리줄이 아님   ← 현근무처|기관명:부서명:직위:
🚫 머리줄이 아님   ← A|B|C|D|E|점수
🚫 사전이 이미 앎  ← 자격및면허|종류|취득년월일|상벌|상벌사항|상벌기관
🚫 열쇠가 둘 미만  ← 생년월일|1900.00.00
✓ 씀             ← 복무기간|수행단체|맡은일
```

## ⚠ 지키는 것

- ⚠★ **판정은 채우는 쪽과 «같은 자»** — `KcareerHwpxFill.isHeaderishText` 를 그대로 쓴다.
  두 벌로 만들면 「화면엔 쓰인다는데 실제로는 막히는」 어긋남이 생긴다.
- ⚠★ **글자로 보는 자와 칸(XML)으로 보는 자가 같은 답**을 내야 한다.
  화면은 XML 이 없고 기억해 둔 «머리줄 글자»만 들고 있다. 그래서 `머리행답나(cells)` 가
  `머리행답나글자(names)` 를 부르게 «하나로» 모았다.
- ⚠ **지우는 것은 기억뿐**이다 — 대표 자료(학력·경력)를 건드리지 않는다.
- **「막힌 것만 지우기」는 쓰이는 것을 안 지운다** — 지워도 손해가 없는 것만 지운다.
