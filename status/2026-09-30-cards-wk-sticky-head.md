# 2026-09-30 · 기업정보함 — 근로자 표 머리줄 틀고정

- 대표 지시: 「틀고정」(근로자 화면 캡처). 기업 상세·명함 표는 이미 머리줄이 붙어 있었고 근로자 표만 빠져 있었다.
- 원인: `.wktbl` 의 `overflow:hidden`(둥근 모서리용) 때문에 표 자신이 스크롤 틀이 되어 sticky 가 헛돈다.
- 한 것: `.wktbl th` sticky · 표의 overflow:hidden 을 빼고 모서리는 머리 칸 양 끝에 · `#pcWk` 위 여백(14px)만큼 올려 붙임.
- 확인: 실제 CSS 로 60줄 표를 그려 900px 내려도 머리줄이 맨 위(0px)에 붙는 것을 봤다. 검사 `tests/cards-wk-sticky-head.test.js`(3) · 전체 20,672 통과.
