# 휴대전화 카카오 로그인 지연·재진입 보완 (2026-10-17)

- 대표 폰 진단: 카카오 복귀 뒤 Firebase 로그인 120,444ms 중 인증 네트워크 684ms(2건), 저장된 로그인 복원 317,427ms. 서버 처리 1,496ms. 저장소 초기화·화면 복원 지연이 유력하며 실기기 원인은 배포 후 재측정해야 확정할 수 있다.
- 포털의 Firebase compat 스크립트 네 개를 12.19.0으로 통일했다. 공식 릴리스에는 IndexedDB 초기화 교착 방지 및 pagehide 뒤 재연결 수정이 포함된다.
- 포털 인증 알림이 일시적으로 비었을 때 기존 화면을 가리고 최대 15초 복원을 기다린다. 명시적 로그아웃과 다른 계정 전환은 즉시 처리한다.
- 카카오 인가코드 교환과 포털 타일 준비 중에는 자동 새 버전 적용을 연기한다. `pu-version.js`를 쓰는 화면의 캐시 번호를 함께 올렸다.
- 다음 확인: 배포 뒤 대표 폰의 `설정 → 휴대폰 로그인 속도 → 시간 보기`에서 Firebase 로그인·인증 통신·저장된 로그인 복원을 각각 다시 측정한다. 실제 폰 측정 전에는 해결 완료로 단정하지 않는다.
