## 한 것
- 서버 `monthlyHomepageAuto` — 매달 1일 08:00(서울). 퇴사(`retired`)한 직원의 구성원 글,
  거래 종료(`closed`)한 업체의 자문사현황 로고 글을 라이믹스 «휴지통»으로 보낸다.
- 서버 `homepageAuto` — 총괄관리자만. 보기(미리 보기)·돌리기(지금 돌리기)·승인(멈춘 목록 그대로).
- 고르는 규칙은 `functions/homepage-auto.js` 한 곳. 휴직은 안 내림 · 이어 둔 것만 · 남기기(사유 있음)는
  안 내림 · 글 번호 겹치면 안 내림 · ERP 를 못 읽거나 비었으면 아무것도 안 함 · **한 번에 5건 넘으면 0건(멈춤)**.
- 화면: 왼쪽 기둥 «자동 연결» 카드, 할 일(멈춤·못 돎·못 내림·안 이은 글/로고),
  구성원 편집칸 «푸른ERP 직원» 줄(잇기), 자문사 편집칸 «자동 연결» 줄(로고 잇기·남기기), 로고 잇기 창, 기록 창.
- 고친 고장 둘:
  - 창 제목 함수 `modalHead` 가 **한 번도 정의된 적이 없어** 「구성원 넣기」·「푸른ERP 채우기」·「자문사 로고」
    창이 오류로 안 열렸다(검사가 가짜를 넣어 돌려서 못 잡았다). 정의하고, 부르는 창 함수가 다 정의돼 있는지 검사한다.
  - 자문사 표시 저장 셋(표시·한 번에 고르기·표시 지우기)이 업체 자리를 «통째로» 덮어 → 칸 단위로 바꿈.

## ⚠ 되돌리지 말 것
- 이름으로 잇지 말 것 — 자동은 `homepage/members/{key}.sid`, `homepage/partners/{id}.boardSrl` 로 이어 둔 것만.
- 휴직을 퇴사로 묶지 말 것. 멈춤 문턱을 크게 올리지 말 것(검사가 10 이하를 지킨다).
- 자동 내리기 게시판은 `people_board`·`partner_board` 둘뿐(`HW.내릴게시판`). 휴지통 말고 다른 type 금지.
- `homepage/partners/{id}` 를 set/remove 로 통째로 쓰지 말 것 — 이은 번호·남기기·내린 표시가 사라진다.

## 남은 일
- 대표님이 처음 한 번 «잇기»: 구성원(할 일의 「한 번에 잇기」 + 동명이인은 편집칸) · 로고(할 일의 「로고와 잇기」).
- 이은 뒤 «미리 보기»로 게시판 확인(`ok`)을 한 번 본다 — 관리자 로그인으로 실제 글을 열어 보는 첫 정찰이다.
- 2단계(새 거래처 로고 올리기) · 3단계(새 노무사 올리기) · 4단계(일반직원 줄) — 각각 라이믹스 «새 글 쓰기»·쪽 본문 정찰부터.
- 서버 되살리기는 아직 없음 — 기록 창의 «휴지통 열기»가 라이믹스 관리자 휴지통을 연다.
