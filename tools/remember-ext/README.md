# 푸른 리멤버 연결 (크롬 확장)

리멤버에서 새로 받거나 고친 명함을 **30분마다** 푸른사진첩·기업정보함으로 옮깁니다.
(2026-10-24 대표 지시 「반드시 자동으로」 — 옛 명함은 이미 다 들어와 있어 «새것·고친 것»만)

## 한 번만 설치

1. 크롬 주소창에 `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → `C:\Users\fair0\Documents\pu-remember-ext` 폴더를 고릅니다.
4. 「푸른 리멤버 연결」이 켜지면 끝입니다. 1분 뒤 두 탭이 «고정 탭»으로 열립니다.
   - 리멤버(card.rememberapp.co.kr) — **로그인되어 있어야 합니다**
   - 푸른 「📇 리멤버 받기」 — **푸른 포털에 로그인되어 있어야 합니다**

## 어떻게 도나

- 30분마다 리멤버 탭을 새로 고치고, 리멤버 화면이 스스로 부르는 명함 목록을 «수정순»으로 받아
  지난번 뒤에 새로 생기거나 고친 명함만 받는 화면에 건넵니다.
- 받는 화면이 사진첩(「서류 › 명함」, 판독 결과를 미리 적어 다시 판독하지 않음)과
  기업정보함(사진첩에서 보낼 때와 같은 문 — 같은 사람이면 빈 칸만 채움)에 담습니다.
- 첫 회차는 «기준»만 잡고 아무것도 넣지 않습니다.

## 지키는 것

- 리멤버 비밀번호·로그인 열쇠를 저장하지 않습니다. 리멤버 화면이 쓰는 것을 그 탭 안에서만 빌립니다.
- 리멤버 쪽은 읽기만 합니다. 우리 쪽도 지우지 않습니다.
- PC·크롬이 꺼지면 쉬고, 켜지면 밀린 것을 가져옵니다.
- 리멤버 로그인이 풀리면 받는 화면에 빨간 띠가 뜹니다 — 리멤버에 다시 로그인하면 이어집니다.

## 멈추지 않게 — 세 겹 (2026-11-07)

11/5 18:00 뒤로 확장의 «다음 때» 알람이 사라져 이틀 가까이 멈췄다(크롬·받는 화면은 멀쩡했다).

| 겹 | 누가 | 무엇을 |
|---|---|---|
| ① 스스로 | 확장(bg.js) | 30분마다 지킴이 알람이 «다음 때» 알람을 본다 — 없거나 밀렸으면 다시 맞추고 지금 돈다. 새 판도 이때 본다 |
| ② PC 가 깨움 | 예약 작업 「푸른 리멤버 확장 갱신」(sync-ext.js, 30분마다) | 서버의 마지막 확인이 예정보다 15분 넘게 늦으면 크롬에 깨우기 화면(kick.html)을 연다. 일꾼이 답이 없으면 확장을 다시 시작한다. 크롬이 꺼져 있으면 켠다 |
| ③ 사람에게 | 같은 예약 작업 | 깨워도 한 시간 넘게 그대로면 대표 「⚠ 장애 알림」에 할 일을 올린다. 리멤버 로그인이 풀렸으면 곧바로. 다시 돌면 그 알림을 «해결»로 닫는다 |

기록: `C:\pu-remember-ext\sync.log`(갱신·깨움·알림) · 서버 `pucards/remember/status`(마지막 확인) · `pucards/remember/trace`(회차 단계)

## 멈췄을 때 할 일

「⚠ 장애 알림」에 「📇 리멤버 연결이 … 뒤로 멈췄습니다」가 뜨면 차례대로:

1. 크롬(프로필 «권형하»)이 켜져 있나 — 꺼져 있으면 켠다
2. 고정 탭 「📇 리멤버 받기」(푸른)가 로그인돼 있나 — 빨간 띠면 그 탭에서 로그인
3. 고정 탭 리멤버(card.rememberapp.co.kr)가 로그인돼 있나 — 풀렸으면 다시 로그인(QR·카카오 등)
4. 크롬 오른쪽 위 「푸른 리멤버 연결」 아이콘을 한 번 누른다
5. 그래도 안 되면 클로드에게 「리멤버 점검」 — 서버 기록·sync.log·크롬 프로필을 읽어 어디서 멈췄는지 찾는다

⚠ 갱신기(sync-ext.js) 자신은 스스로 바뀌지 않는다 — 고쳤으면 설치 폴더(`C:\pu-remember-ext`)에 손으로 복사한다.
   (갱신기가 깨지면 고칠 길이 사라지므로 일부러 그렇게 둔다)

⚠ 이 폴더(tools/)는 배포(인터넷)에 올라가지 않습니다(.github/workflows/deploy-pages.yml).
