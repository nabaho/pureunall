# 정부사업신청 «매일 카톡 요약» (scripts/gov-digest)

대표 지시 2026-11-22 「정부 지원사업 관련해서 카카오톡으로 매일 받고 싶다 — 내 개인톡으로. 다 주는 것은 필요 없고 수의계약 제외하고
필요할 만한 것들, 컨설턴트 모집도 대전·충청 지역 것, AI 사업은 전국, 노무사가 직접 하거나 노무 프로그램으로 충분히 가능한 사업으로」.

서버가 매일 아침 모아 둔 공고(`gov_feed/rows`, 07:40)와 기관 게시판 모집 글(`gov_watch/hits`, 07:20)을 읽어, **정부사업신청 화면과 같은 규칙**으로 추린 글을
대표 **«나와의 채팅»** 으로 보냅니다. 이 폴더(`scripts/`)는 배포본에서 지워집니다 — 인터넷에 공개되지 않습니다.

## 무엇을 보내나 (규칙은 `digest.js` 맨 위 `RULES` 한 곳)
| 갈래 | 들어가는 것 | 안 들어가는 것 |

- 줄마다 «왜 걸렸는지»(지역·걸린 낱말·AI 갈래)와 마감을 붙입니다. 마감일·지역을 모르면 «모름»이라 씁니다 — 지어내지 않습니다.
- **새로 걸린 것만** 보냅니다. 이미 보낸 줄은 다시 안 보내고, 마감이 3일 안으로 다가온 줄은 **한 번만** 더 알립니다(⏰). 새 것이 없으면 아무것도 안 보내고 `digest.log` 에만 적습니다.
- 갈래마다 한 번에 8줄까지 — 넘는 줄은 보낸 것으로 치지 않아 다음 날 이어서 나갑니다.
- 이 글은 «알림»입니다 — 지원 여부는 원문을 보고 정합니다(틀릴 수 있습니다).

## 쓰는 법
| 명령 | 하는 일 |
|---|---|
| `node scripts/gov-digest/main.js` | **미리보기** — 서버를 읽어 오늘 보낼 글만 화면에 보여 줍니다. 보내지도, 기록하지도 않습니다. `--all` 을 붙이면 새 것만이 아니라 오늘 걸린 것 전부. |
| `node scripts/gov-digest/main.js --send` | 보냅니다. 설정이 **실전**이 아니면 **시험 모드** — `%APPDATA%\pureun-gov-digest\outbox\` 에 글만 적고 카톡은 한 번도 건드리지 않습니다(기록도 안 남겨 실전 첫 통에 전부 들어갑니다). |
| `node scripts/gov-digest/main.js --probe` | PC 카톡이 켜져 있고 창을 찾을 수 있는지만 봅니다(아무것도 보내거나 열지 않습니다). |
| `--dir <폴더>` | 서버 대신 폴더의 `gov_feed.json`·`gov_watch.json` 을 읽습니다(점검용). |

## 설정 — 저장소 밖 `%APPDATA%\pureun-gov-digest\config.json`
```json
{ "liveEnabled": false, "selfChat": false, "room": "나와의 채팅 방 이름", "project": "pureun-erp" }
```
- `liveEnabled: true` · `room` · `selfChat: true` **셋이 다 있을 때만** PC 카톡을 건드립니다. 하나라도 없으면 시험 모드입니다.
- `selfChat: true` 는 «그 방이 **내 나와의 채팅**이라고 내가 직접 확인했다»는 표시입니다. PC 카톡 창 제목만으로는 같은 이름의 다른 방(동명이인·단톡방)과 구분되지 않아, 설정이 틀리면 남에게 갈 수 있습니다(2026-11-22 보안 검토).
- 설정 파일이 **깨져 있으면** 조용히 시험 모드로 넘기지 않고 오류로 멈춥니다(파일이 없을 때만 기본값).
- `room` 은 PC 카톡 창 맨 위 제목 그대로(나와의 채팅은 보통 본인 프로필 이름) — 제목이 다르면 `kakao-agent` 가 보내지 않습니다.
- 같은 때 두 번 돌지 않게 `run.lock`(30분 넘으면 자동으로 치움)을 쓰고, 보낸 기록(`sent.json`)은 **통마다 바로** 적습니다(중간에 멈춰도 이미 간 줄은 다시 안 나갑니다). 기록이 **깨져 있으면** 지난 글이 전부 다시 나가므로 멈춥니다.
- 서버(RTDB)는 **읽기만** 합니다(`gov_feed/rows`·`gov_watch/hits`). 쓰는 곳은 이 PC 의 `sent.json`(보낸 기록)·`digest.log`·`outbox/` 뿐입니다.

- [ ] `--probe` 로 PC 카톡이 켜져 있는지 본다.

- [ ] PC 카톡에서 **나와의 채팅**을 열어 창 맨 위 제목을 확인하고, `config.json` 에 `liveEnabled: true, selfChat: true, room: "<그 제목 그대로>"` 를 쓴 뒤 `--send` 로 한 번 보내 본다.
- [ ] `powershell -ExecutionPolicy Bypass -File scripts\gov-digest\install-task.ps1 -RepoDir <오래 두는 저장소 폴더>` — 매일 08:30 에 알아서 돕니다(PC 설정을 바꾸므로 대표 확인 뒤에). 되돌리기: `... -Remove`

## 알아 둘 것
- **카카오 약관** — 프로그램이 PC 카톡을 조종하는 것은 약관상 계정 제한 위험이 있습니다(대표 «알고 진행» 2026-10-31, 컨설팅정산 카톡 심부름꾼과 같은 길). 본인 «나와의 채팅»에만 보냅니다. 방을 열면 그 방의 안 읽은 글이 읽음이 됩니다.
- PC 가 꺼져 있거나 카톡이 꺼져 있으면 그날은 못 보냅니다. 켜진 뒤 다시 돌리면 **밀린 것까지** 한꺼번에 나갑니다(보낸 기록이 없으니까요).
- 서버 수집은 Firebase 에서 PC 와 상관없이 돕니다 — 이 PC 는 «받아 보는 일»만 합니다.
- 설계 근거: 규칙은 `js/gov-pick.js`(🎯 지원할 만한 것) · `js/gov-region.js`(📍 지역) · `js/gov-ai.js`(🤖 AI 사업) 위에 얹었습니다. 화면 규칙을 고치면 이 요약도 따라갑니다.
- 지킴: `tests/gov-digest.test.js`
