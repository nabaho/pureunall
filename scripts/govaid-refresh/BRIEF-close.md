# 정부지원사업 «접수 중인가» 확인 지침 (푸른노무법인 — 2026-10-12 처음 씀, 매월 정기 조사에 씀)

확인 기준일: **조사하는 날**(부르는 쪽이 알려 준다 — 아래 예시의 날짜는 2026-10-12 첫 조사 때의 것). 그해 사업이 지금 신청을 받고 있는지, 예산 소진·조기 마감·접수 기간 종료로 끝났는지 확인한다.

## 꼭 지킬 것
- **공식 공지로 확인한 것만 «종료»로 적는다.** 짐작·오래된 기사·작년 공지로 판정하지 않는다. 확인하지 못하면 `state: "unknown"`.
- 좋은 출처: 고용24(work24.go.kr) 공지·기업지원금 안내, 고용노동부(moel.go.kr) 보도자료·공지, 지방고용노동청·고용센터 공지,
  기업마당(bizinfo.go.kr) 공고(접수기간·마감), 중소벤처24(smes.go.kr), 중진공(kosmes.or.kr) 정책자금 «예산 소진에 따른 접수 마감» 공지,
  소진공·KOTRA·NIPA·한국산업인력공단·근로복지공단 등 운영기관 공지, 운영기관(상공회의소 등) 안내문.
- 고용장려금처럼 «연중 상시 접수, 예산 소진 시 조기 마감»인 사업은 마감 공지가 없으면 `open`(근거: 상시 접수 안내) 또는 `unknown`.
- 접수 기간이 정해진 공고형 사업은 공고의 접수기간 끝날이 확인 기준일 이전이면 `closed`, `reason: "deadline"`.
  추가 모집(2차·3차) 공고가 있으면 그 접수기간을 본다.
- 지역·운영기관마다 다르면(예: 일부 운영기관만 배정 소진) `state: "partial"` 로 하고 note 에 어디가 마감됐는지 적는다.
- 출처마다 `url`·`title`, 공지 날짜(`date`)를 적는다.

## 결과 모양 — JSON 배열, 사업 하나에 한 원소 (대상 파일의 모든 id)
```
{ "id": "gp-r71", "state": "open|closed|partial|unknown",
  "reason": "budget|deadline|abolished|other|",   // closed·partial 일 때: budget=예산 소진, deadline=접수기간 끝, abolished=폐지·통합
  "closedAt": "2026-08-31",                          // 알면 마감일(YYYY-MM-DD), 모르면 ""
  "note": "한두 문장 — 무엇을 보고 판정했는지, 재개·추가 모집 예정 여부",
  "sources": [ { "title": "", "url": "", "date": "" } ],
  "confidence": "high|medium|low" }
```
결과는 지정된 JSON 파일 하나에 쓴다(UTF-8). 끝나면 state 별 개수와 확신도 분포만 3줄 이내로 보고한다.
