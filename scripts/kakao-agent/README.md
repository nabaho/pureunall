# 카톡 심부름꾼 (scripts/kakao-agent)

포털 «🧾 컨설팅정산 › 💬 카톡 문구»에서 **«카톡 보내기»** 를 누르면, 이 프로그램이 대표 PC 의 **PC 카톡**으로 그 글을 보냅니다.
설계: `docs/superpowers/specs/2026-10-31-consult-settle-design.md` §7. 이 폴더(`scripts/`)는 배포본에서 지워집니다 — 인터넷에 공개되지 않습니다.

## 한눈에
| 모드 | 하는 일 |
|---|---|
| **시험 모드** (기본) | PC 카톡을 **한 번도 건드리지 않습니다.** 보낼 글을 `%APPDATA%\pureun-kakao-agent\outbox\<줄>.txt` 에 적고, 포털에는 «시험 모드» 표시만 남깁니다. |
| **실전 모드** | `config.json` 에 `"liveEnabled": true` 가 있을 때만. PC 카톡의 그 사람 방을 열어 글을 넣고 보냅니다. |
| **시험 방으로만** | 실전 모드 + `"redirectRoom": "내 이름"`(나와의 채팅 방 이름) — **모든 글을 그 방으로만** 보냅니다. 첫 시험에 씁니다. |

`--dry-run` 을 붙이면 설정과 상관없이 **항상 시험 모드**입니다.

## 보내기 전에 꼭 확인하는 것 (하나라도 어긋나면 보내지 않습니다)
- 받는 사람의 방 이름이 포털 «카톡 방»에 등록된 것과 **똑같다**(카톡 창 제목도 그 이름과 똑같아야 보냅니다).
- 그 글이 **확정된 정산표**의 것이다.
- 대기열에 넣은 사람이 **관리자(대표)** 다.
- 그 방 입력칸에 누가 쓰던 글이 남아 있으면 건드리지 않습니다.

## 처음 한 번
1. Node 와 firebase CLI 가 이 PC 에 있고 `firebase login` 이 되어 있어야 합니다(대기열을 읽고 결과를 적는 데 씁니다).
2. 설정 파일을 **저장소 밖**에 만듭니다: `%APPDATA%\pureun-kakao-agent\config.json` (`config.example.json` 을 복사).
3. PC 카톡이 켜져 있고 로그인되어 있는지 확인: `node scripts/kakao-agent/main.js --probe`
   (아무것도 보내거나 열지 않습니다 — 카톡이 켜져 있는지, 채팅 검색칸을 찾을 수 있는지만 봅니다.)
4. 한 바퀴만 시험: `node scripts/kakao-agent/main.js --once --dry-run`
5. 계속 돌리기: `node scripts/kakao-agent/main.js`

## 실전으로 넘어가기 (대표 확인 뒤에)
- [ ] 포털 «카톡 방»에 담당마다 카톡 방 이름을 등록했다(PC 카톡 창 맨 위 제목 그대로, 예: `박재원 공인노무사(푸른노무법인)`).
- [ ] `config.json` 에 `"liveEnabled": true, "redirectRoom": "<나와의 채팅 방 이름>"` 을 쓰고 한 통 보내 본다 → 나와의 채팅에 글이 잘 들어갔다.
- [ ] 화면이 잠긴 상태에서도 보내지는지 본다(안 되면 «화면이 잠겨 있습니다»로 기다렸다가 풀리면 보냅니다).
- [ ] `redirectRoom` 을 비우면 그때부터 진짜 받는 사람 방으로 갑니다.

## 알아 둘 것
- **카카오 약관** — 프로그램이 PC 카톡을 조종하는 것은 약관상 계정 제한 위험이 있습니다(대표 «알고 진행» 2026-10-31). 등록된 방에만, 대표가 누른 글만, 대화는 읽지 않습니다.
- **방을 열면 그 방의 안 읽은 글이 읽음이 됩니다.**
- PC 카톡은 한 대에만 로그인됩니다 — 카톡이 로그인된 대표 PC 에서 돌립니다. 카톡이 꺼져 있으면 실패로 치지 않고 기다렸다가 켜지면 보냅니다.
- 마우스·키보드·클립보드를 쓰지 않습니다(창 메시지만) — 그 PC 로 일하는 중에도 섞이지 않습니다.
- PC 카톡 설정에서 «Enter 로 보내기»가 꺼져 있으면(Ctrl+Enter) 보내지지 않습니다 — 그때는 «입력칸이 비지 않음»으로 실패가 남고 넣었던 글은 다시 지웁니다.
- 같은 줄은 3번까지만 다시 해 봅니다. 방을 못 찾거나 창 제목이 다르면 곧바로 실패로 둡니다.
- 이 프로그램이 포털 데이터베이스에 쓰는 곳은 두 곳뿐입니다: `settle/kakaoQueue/<줄>`(그 줄의 상태) · `settle/agent`(마지막 응답).

## 자동 시작 (PC 설정을 바꾸므로 대표 확인 뒤에)
`powershell -ExecutionPolicy Bypass -File scripts\kakao-agent\install-task.ps1 -RepoDir <오래 두는 저장소 폴더>`
- 로그온한 사용자 세션에서 돌아야 합니다(PC 카톡 창과 이야기하므로).
- 오래 두는 폴더에서 `git pull` 로 최신을 유지하세요. 되돌리기: `...install-task.ps1 -Remove`

## 문제 해결
| 증상 | 확인 |
|---|---|
| 포털에 «심부름꾼 응답 없음» | PC 가 꺼졌나? `firebase login` 이 풀렸나? 로그: `%APPDATA%\pureun-kakao-agent\agent.log` |
| «PC 카톡이 꺼져 있거나 로그인되지 않았습니다» | PC 카톡을 켜고 로그인 — 대기 중인 글은 그대로 남아 있다가 나갑니다 |
| «방 이름이 등록된 것과 다릅니다» / «제목이 방 이름과 다름» | 포털 «카톡 방»의 이름을 PC 카톡 창 제목과 똑같이 고친 뒤 다시 «카톡 보내기» |
| «입력칸이 비지 않음» | PC 카톡 설정 › 채팅 › «Enter 로 보내기»를 켭니다 |
