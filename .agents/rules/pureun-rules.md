# 푸른 저장소 규칙 — Antigravity 가 «언제나» 지키는 것

> 대표 지시 2026-11-08 「안티그래비티가 AGENTS.md 를 읽게 하는 설정」.
> Antigravity 는 이 폴더(`.agents/rules/`)의 규칙을 작업마다 자동으로 싣는다.
> 아래는 «최소한»이다 — 규칙 전부는 저장소 뿌리의 `AGENTS.md` 에 있고, 원본은 `CLAUDE.md` 다(어긋나면 `CLAUDE.md` 가 이긴다).

1. **대답은 늘 한국어로 한다 (Always respond in Korean).** 주석·커밋·PR 설명도 한국어.
2. **일을 시작하기 전에 `AGENTS.md` 를 끝까지 읽는다.** 손대는 앱이 있으면 `STATUS.md` 의 「되풀이된 실수」도 읽는다.
3. **main 에 직접 올리지 않는다.** 새 가지 → 고치기 → `node --test tests/*.test.js` 통과 → PR. 합치기는 저장소의 자동 병합이 한다.
   검사가 빨가면 PR 을 만들지 않는다. 사람이 보고 합쳐야 하면 PR 제목 앞에 `[보류]`.
4. **다른 AI 방(Claude·Codex)이 같은 저장소를 동시에 고친다.** 끝낼 때 기록은 `status/날짜-가지이름.md` 새 파일 하나로 남긴다.
5. **저장소는 공개다** — 열쇠·비밀번호·토큰을 파일에 넣지 않는다. 실제 고객·직원 이름·주민번호·연락처·금액도 넣지 않는다(시험 자료는 지어낸 것만).
6. **파이어베이스 규칙은 `scripts/make-firebase-rules.js` 에서만 고친다.** JSON 을 손으로 고치거나 콘솔에 직접 붙이지 않는다.
7. **로그인된 브라우저에서 보내기·저장·삭제·제출을 누르지 않는다** — 초안까지만, 누르는 것은 사람이다.
8. **검사는 «지금 값»이 아니라 «규칙»을 박는다.** 표의 한 칸은 한 줄, 목록 맨 왼쪽은 ☐ + 번호, 폰은 `@media` 안에서만 고친다.
