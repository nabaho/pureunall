# 노사 인생 타이쿤 (LaborLaw Arena · `labor-law-arena/`)

설치 없이 웹 브라우저(PC · 스마트폰 · 태블릿)에서 바로 실행되는 단일 파일 노동법·생활경제 시뮬레이션 게임입니다.

## 포함된 파일
- `index.html`: 웹 접속 시 바로 실행되는 메인 게임 파일 (한 창씩 넘기는 스마트폰 앱 모드, 🍚 밥·🛍️ 쇼핑·🏠 월세 생활경제 & 매일⚡/월🌟 듀얼 에너지 순환, 🧾 연장·야간·휴일 급여명세서 탐정 & 고용노동부 진정 협상, 14단계 최저임금→시말서→징계→승진→결혼→주식·파업폭락·회사부도→창업 스토리, 실시간 5테마 배경음악 포함)
- `labor_law_arena.html`: 동일한 원본 백업 파일
- `manifest.json`: 스마트폰 홈 화면 추가(PWA) 설정 파일
